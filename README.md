# 123 — ファンタジーTRPG世界「クロスロード」設定リポジトリ

TRPG 世界「123」の設定データベース兼・正典（137 ファイル / 約 42 万文字）。
AI にセッションを回してもらうための資料集です。

## AI に読ませるとき

**AI の能力に合わせて渡し方を変えます**（詳細は [`START_HERE.md`](START_HERE.md) 冒頭）。

| AI の能力 | 渡すもの | 補足 |
|---|---|---|
| zip を展開できる | **`123.zip`** ＋ `INDEX.md` を地図に個別ファイル | 分割のまま読めて最も精度が高い |
| zip を読めない | **`123_all.md`**（全部載せ） | 先頭に圧縮版の正典＋目次を配置済みで読み落ちにくい |
| 核だけ先に渡したい | **`DIGEST.md`**（約 2 万字） | 詳細は場面ごとに個別ファイルを追加で渡す |
| 最初に必ず | **`START_HERE.md`** ＋ `CLAUDE.md` | 入口＋圧縮版正典＋GM運用ルール |

zip と全部載せの 2 本立てなのは、**zip を読み込めない AI のために全部載せを用意しておく**ため。
全部載せが「読み込まれづらい」問題は、先頭に正典と目次を置くことで緩和している。

## メンテナンス用ツール

```bash
bash tools/build.sh            # INDEX.md / 123_all.md / DIGEST.md / 123.zip をまとめて再生成
python3 tools/count.py --budget # 文字数を計測、入口の肥大を警告
```

ファイルを追加・編集したら `tools/build.sh` を実行すれば、**各ファイル冒頭の TL;DR**・索引・
全部載せ・ダイジェスト・zip がすべて最新に揃います。TL;DR の文面は `tools/summaries.tsv` で
一元管理しており、新規ファイルを足したらこの tsv に 1 行追記してから `build.sh` を実行します。

> **`123_all.md` と `123.zip` はリポジトリに保存していません**（`.gitignore` 対象）。
> 古い版を誤って渡さないよう、AI へ渡す直前に `bash tools/build.sh` で最新版を生成してください。
> `DIGEST.md` と `INDEX.md` は小さく参照性が高いため、リポジトリに保存しています。
