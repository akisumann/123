# ストーリー / 世界観 骨子（AI 実行用）

このリポジトリは、**AI にストーリーを回してもらう**ための世界観・キャラクター・物語の
骨子（設定資料）を管理する場所です。まだ中身はほとんど空なので、ここから少しずつ
書き足していきます。

## 使い方（ざっくり）

1. `world/`（世界観）→ `characters/`（登場人物）→ `story/`（物語）の順に埋めていく
2. AI に読ませるときは `ai/system-prompt.md` を土台にして、必要な設定ファイルを一緒に渡す
3. 迷ったら、各ファイル冒頭のテンプレート項目を上から埋めるだけで OK

> 「完璧に書いてから」ではなく、**空欄のまま置いておく**のも骨子として正しい状態です。
> 決まっていない所は `TODO:` と書いておけば、後で AI に埋めてもらうこともできます。

## ディレクトリ構成

```
.
├── README.md              … このファイル
├── world/                 … 世界観
│   ├── overview.md        … 世界の概要（一番最初に読むべき要約）
│   ├── setting.md         … 舞台・地理・時代
│   ├── history.md         … 歴史・年表
│   ├── factions.md        … 勢力・組織・種族
│   └── rules.md           … 世界のルール（魔法/技術/禁則など）
├── characters/            … 登場人物
│   ├── _template.md       … キャラ作成用テンプレート
│   └── protagonist.md     … 主人公（記入例）
├── story/                 … 物語
│   ├── premise.md         … 一行あらすじ・テーマ
│   ├── synopsis.md        … あらすじ（全体の流れ）
│   └── arcs.md            … 章・エピソード構成
└── ai/                    … AI に回すための設定
    ├── system-prompt.md   … AI に渡すシステムプロンプト雛形
    └── style-guide.md     … 語り口・トーン・禁止事項
```

## 書くときの原則

- **一次資料はここに集約する。** AI との会話ログではなく、この Markdown 群を「正」とする。
- **矛盾したら world/ を優先。** キャラや物語より、世界のルールが上位。
- **固有名詞は初出で定義する。** 読み方や別名があれば併記しておくと AI がぶれない。
