# Lv97 火山龍

> **TL;DR:** 五龍の一柱・火山龍(Lv97)。火山地帯を形作った最強格。

- 種族：古龍／五龍の一柱(`world/02_alvein_continent.md`)
- 役割：火山形成・鉱脈生成・灼熱支配

セリフ：「炎は破壊ではない。新たな礎を鍛える力だ」

## ステータス

| 項目 | ランク | 内容 |
|---|---|---|
| HP | B | 古龍としては小柄な体躯だが、十分な生命力を持つ。 |
| MP | A | 大陸の一部を火山地帯へ変え続ける膨大な魔力。 |
| ATK | SS | 火力の上限値は理論上存在しない。無限に等しい破壊力を持つ(`rules/02_status_system.md`の例外ランク)。 |
| DEF | C | 防御は並程度だが、灼熱そのものが近づく者を拒む。 |
| INT | C | 熱、圧力、鉱脈の理を理解する古龍の知性。 |
| SPD | D | 俊敏ではないが、火山地帯を自在に巡る。 |
| DEX | S | 規格外の火力を精密に制御し、鉱脈や希少鉱石を生み出すほどの精密性を持つ。 |

## プロフィール

神代より火山地帯を巡り続ける五龍の一柱。

その規格外の熱量と精密な制御によって、大陸の五分の一を火山地帯へと変え、数多の鉱脈と希少鉱石を生み出したと伝えられている(`world/nations/23_volcanic_forge_empire.md`のヴォルカニック・フォージ帝国の鉱業・鍛冶産業の源)。

現在もなお、地下深くから新たな鉱脈や超高温・超高圧によって鍛え上げられた希少鉱石が次々と発見されており、火山龍は今なおマグマの中で活動を続けていると考えられている。

しかし、その姿を目撃した者は存在せず、生きていることだけが鉱脈という"痕跡"によって証明され続けている。

クロスロード中央区・大神殿には、五龍を比較して学べる資料区画があり、大地龍と並んで火山龍についても紹介されている(`world/crossroad/48_grand_temple_dragon_records.md`)。
