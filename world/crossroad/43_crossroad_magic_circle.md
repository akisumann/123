# クロスロード民間魔法サークル(クロスロード民間術師会)

## 概要

クロスロードには、魔法学園や王立魔術院のような大規模な専門機関は存在しない。その代わり、街で暮らす魔法使い、錬金術師、魔道具職人、治療術師、冒険者などが集まり、小規模な魔法サークルを運営している。

正式な学校や研究機関というより、共同の作業場・魔法使い同士の交流所・初歩魔法の練習場・資料や道具の共有所・民間相談窓口を兼ねた寄り合い所帯である。

## 立地

東区の住宅地と南区の職人区(`world/crossroad/20_crossroad_city_districts.md`)の境目にある。周囲には一般住宅、小さな工房、薬屋、雑貨屋などが並んでおり、外見も大きな研究塔ではなく、少し広い民家や集会所に近い。

建物は二階建て。

- 一階：交流室、受付、共同作業室
- 二階：資料室、小型実験室、仮眠室
- 裏庭：魔法練習場、素材乾燥場
- 地下：危険物を一時保管する小型保管庫

大規模な爆発や高位魔法を扱える設備はない。

## 参加者

所属者は十数人から数十人程度。常に全員が集まるわけではなく、普段施設にいるのは数人程度。

主な参加者：個人営業の魔法使い、冒険者の魔法職、治療術師、錬金術師、魔道具職人、占術師、結界術師、魔法を学びたい一般人、引退した元冒険者など。

専門分野も実力も統一されていない。一流の魔法使いもいれば、生活魔法しか使えない者もいる。

会員内では「オタクのエルシア」と呼ばれる内気な幻術研究者もその一人(`characters/npcs/21_elsia.md`)。会員たちは彼女が夜の顔を持つことを想像もしていない。

東区の学校に通う少女ララ(`characters/npcs/27_lara.md`)も、幼い頃からここへ出入りしている一人。もっとも今では教わる側ではなく、会員の術式の無駄を容赦なく指摘する側になっており、第四階位の指摘役として名前が知られている。

## 運営

特定の代表者が強く支配する組織ではなく、複数人による共同運営。

施設費は、月会費・魔法相談料・講習料・道具の貸出料・素材の共同販売・小規模な依頼・寄付によって賄われている。

会員は施設の掃除、備品管理、結界点検なども分担する。

取りまとめ役はミレイ(`characters/npcs/18_milei.md`)。代表というより、鍵・帳簿・講習予定・備品を管理する世話役に近く、会員より偉いわけではない。重要事項は会員同士の相談で決められる。

## 主な機能

### 魔法相談

一般市民から魔法に関する相談を受ける。

例：家の中で妙な音がする、魔道具が動かない、子供が魔力を暴発させた、畑に魔力異常がある、小さな呪いを受けた疑いがある、魔法契約の内容を確認したい。

危険な案件は騎士団、神殿、冒険者ギルドへ回される。

### 初歩魔法の講習

生活魔法や魔力制御を教える。扱う内容：火種を作る、水を少量出す、灯りを作る、魔力を感知する、魔道具へ魔力を流す、魔力暴発を抑える、簡単な結界を張る、など。

専門的な戦闘魔法や高位魔法までは教えられない。

### 魔法階位の学習

魔法階位理論(`rules/05_magic_theory.md`)についての基礎知識と、低階位魔法の実践を学べる。魔法学園のような専門教育機関ではないため、高位魔法を本格的に修得する場所ではない。

**第一階位(魔力認識)**：基礎から実技まで学べる。魔力を感知し、外へ出し、狙った方向へ動かすための基礎段階。学べる実例：自分や他人の魔力を感じ取る、指先に小さな光を灯す、魔力を小さな弾として飛ばす、少量の火や熱を発生させる、近くの水や小物を少し動かす、魔道具へ正しく魔力を流す。魔法を学び始める者はまずここから練習する。術師会の設備だけでも十分な指導が可能。

**第二階位(魔力操作)**：一般的な実技まで学べる。既に存在する物質や魔力を操作し、形を保ったまま扱う段階。学べる実例：火を消えないよう維持する、水流や風の向きを変える、地面の土や小石を動かす、魔力の刃を飛ばす、小型の盾や壁を作る、縄や水で簡単に相手を拘束する、小物を宙に浮かせたまま動かす。生活魔法だけでなく初歩的な戦闘魔法もこの辺りから増える。裏庭の練習場で、安全な規模の実習が行われる。

**第三階位(性質変換)**：初歩的な内容と基礎実習まで学べる。魔力を炎、水、冷気、治癒力など、別の性質へ変える段階。学べる実例：魔力から小さな炎を生み出す、魔力から少量の水を作る、冷気を発生させて物を冷やす、浅い傷の治りを少し早める、軽い毒や汚れを弱める、物質の性質を一時的に変える。術師会では小規模で安全な変換のみ扱う。本格的な攻撃魔法、治療魔法、大量の物質生成などは専門の師匠や施設が必要。

**第四階位(術式付与)**：基本理論と簡単な術式まで学べる。魔法に命令や条件を組み込み、自動的または継続的に働かせる段階。学べる実例：扉が開いたときに鳴る警報術式、火が広がったときに反応する防火術式、武器へ一時的な強化を付ける、小型魔道具へ簡単な機能を組み込む、家庭用結界の一部を補修する、決められた動きだけを行う小型ゴーレム、一定条件で作動する灯り。術師会で扱えるのは小規模で構造の単純なものに限られる。複雑な魔道具や防衛結界は南区の専門工房(`world/crossroad/42_crossroad_artisan_goods.md`)へ回される。

**第五階位(外部接続)**：概要や事例を学ぶ程度。自分の魔力だけでなく、土地、精霊、信仰、契約相手など、外部の力へ接続する段階。学べる実例：地脈から魔力を借りる、精霊と契約して力を使う、神殿や信仰を介して加護を受ける、召喚契約を結ぶ、特定の土地と術者を繋ぐ、多人数で魔力を集めて儀式を行う。術師会では契約の読み方や過去の事例、危険性を学ぶ程度。実際の契約や大規模儀式は召喚術師、神殿、専門組織などが担当する。

**第六階位(時空間・改変)**：資料を用いた基礎知識のみ学べる。空間や距離そのものへ干渉する段階。学べる実例：短距離転移、遠距離転移、空間収納、離れた場所同士を一時的に繋ぐ、空間を切断する、小さな隔離空間を作る、空間を利用した封印。術師会に実技設備はなく、基本理論、事故例、転移痕の見分け方などを学ぶだけ。実際に扱える術師も非常に少ない。

**第七階位(自然合一)**：伝承や記録として触れる程度。術者個人の範囲を越え、土地や自然環境そのものと一体化する段階。学べる実例：森全体と繋がり植物を動かす、大地と一体化して地形へ干渉する、河川や湖と繋がり水域全体を扱う、天候へ継続的に影響を与える、広大な土地へ加護や変質を与える、特定の領域そのものを支配する。術師会では歴史、伝承、災害記録などを読むのみ。修得方法を教える者も設備も存在しない。

### 術師会での目安

| 階位 | 目安 |
|---|---|
| 第一階位 | 一から学べる |
| 第二階位 | 実用段階まで学べる |
| 第三階位 | 入口まで学べる |
| 第四階位 | 簡単な術式を扱える |
| 第五階位 | 仕組みと注意点を学ぶ |
| 第六階位 | 存在と基本知識を学ぶ |
| 第七階位 | 伝承や記録として知る |

本格的な魔法使いを育成する場所ではないが、魔法を学び始める者や、自分の魔法がどの階位に当たるか知りたい者には十分な施設となっている。本格的に第三階位以上を修めたい場合は、専門の師匠、工房、神殿、魔術院などを紹介してもらう形になる。

### 共同作業場

個人では揃えにくい道具を共同利用できる。小型錬金釜、魔力測定器、術式刻印台、素材乾燥棚、魔力遮断箱、魔法陣用の床、基本的な実験器具。

ただし高価な設備や危険な装置はない。

### 資料室

基礎的な魔法書、魔物資料、素材図鑑、古い講義録などを保管している。蔵書は多くないが、会員が持ち寄ったため内容は雑多。

高度な理論書よりも、実用魔法・魔物対策・魔道具修理・薬草知識・結界の補修・魔力事故の対処といった実践的な資料が多い。

### 魔法使いの交流

仕事や冒険仲間を探す場でもある。錬金術師が素材を探す、冒険者が補助魔法使いを探す、職人が術式担当者を募集する、初心者が師匠を探す、魔法使い同士で情報を交換する。

正式な人材紹介所ではないが、自然と仕事が集まる。

### 適性検査

頼めば、第一・第二・第三階位(`rules/05_magic_theory.md`)それぞれについて簡単な適性を診てもらえる。魔力測定器や簡単な実技を通して、火・水・風・治癒など、どの性質に向いているかを大まかに判定する。

既にその系統の魔法を実際に使いこなしている者(相応のステータス・スキルを持つ者)であれば、その実力がそのまま結果に反映される。

一方、その分野の魔法を実際に扱ったことがない者については、魔法の総合力(MP量や他分野の熟練度)が高くても、検査対象の分野そのものは未経験扱いとなり、結果は補正なしのランダム判定(1d100など)で出される。

階位理論は同じ魔力を土台にしていても、実際に使えるかどうかは分野ごとに別の練度・経験が必要であり、ある分野の実力が別の分野の適性を保証するわけではない。

第三階位(性質変換)の検査では、火・水・風・雷・氷・光・闇など、大まかにどの属性に向いているかも合わせて分かる。ただし、この属性判定は、本人のプロフィール上で何らかの属性に紐づく設定(種族・出自・既存の魔法経験など)を既に持っている場合を除き、ランダムになる。そうした設定を持たない者にとっては、「たまたま検査で出た属性」以上の意味はない。

第四階位(術式付与)についても、簡単な適性を軽く見てもらえる。判定方法は第一〜第三階位と異なり、実際に簡単な魔法の術式(条件と動作を組み込んだ簡易プログラムのようなもの)を組んでもらい、その出来を見る形で行う。

ただし、その結果は基本的にランダムである。頭の良さや知識量が高いからといってうまく組めるとは限らず、逆に過去の実務経験や場数がそのまま活きるわけでもない。魔力へ命令を書き込む感覚は、知性や経験とは別の、生まれつきの相性に近い要素で決まる。そのため検査結果は、本人の頭脳や経歴を裏付けるものではなく、あくまでその場限りの出目として扱う。

### 受けられる小規模依頼

冒険者ギルドへ出すほどではない小さな依頼が持ち込まれる。

例：家庭用結界の補修、魔道具の簡単な修理、魔力漏れの調査、紛失物の魔力探知、小型使い魔の捕獲、店舗の防火術式点検、子供の魔力適性確認、農地の魔力状態調査、低級呪物の鑑定、魔法素材の仕分け。

報酬は数十Gから数千G程度(`world/06_economy.md`の金額感覚を参照)。大きな危険があると判明した時点で、冒険者ギルドなどへ正式依頼として引き渡される。

## 冒険者との関係

冒険者ギルド(`world/14_adventurers_guild.md`)とは競合せず、扱う依頼の規模が異なる。

魔法サークルが行うのは、魔法知識の提供・簡単な素材鑑定・魔法装備の相談・魔力事故の応急処置・魔法使いの紹介など。逆に、戦闘や危険地帯の調査が必要な場合は冒険者ギルドへ依頼する。

冒険者が採取した珍しい素材を持ち込み、会員たちが集まって調べることもある。

## 職人区との関係

魔道具職人や錬金術師の多くが参加しているため、南区の工房(`world/crossroad/20_crossroad_city_districts.md`、`world/crossroad/42_crossroad_artisan_goods.md`)とも繋がりが深い。

サークル内で試作品を作り、問題がなければ職人区で本格的に製造する場合もある。ただし魔法サークル自体は商店ではなく、完成品を大量販売する設備も権利も持たない。

## 街での立ち位置

一般市民からは「魔法で困ったら、ひとまず相談する場所」として認識されている。高度な問題を解決できるとは限らないが、適切な専門家や組織を紹介してくれる。

住民にとっては、役所や神殿より気軽に頼れる魔法相談所に近い。

## 雰囲気

施設内は学術機関のように厳格ではない。魔法使いが茶を飲みながら議論する、冒険者が素材を机に並べる、初心者が裏庭で火花を散らす、錬金術師が薬の匂いを漂わせる、誰かの失敗で小さな煙が上がる、使い魔が室内をうろついている。

専門家集団ではあるが、良くも悪くも民間の寄り合い所帯である。

## 制限

施設の規模が小さいため、以下には対応できない：高位魔法の研究、大規模儀式、広域結界、転移門の運用、強力な呪いの解除、高位魔物の封印、国家機密級の魔法研究、大量の魔道具製造。

こうした案件は、大都市の魔術院、専門組織、神殿、国家機関へ依頼する必要がある。

## 代表的な呼ばれ方

正式名称より、住民には以下のような俗称で呼ばれる：魔法サークル、魔法寄合、術師会館、魔法使いの集会所、東南の魔法屋敷。

正式名称を付ける場合でも、少し大げさな名前より「クロスロード民間術師会」程度が似合う。
