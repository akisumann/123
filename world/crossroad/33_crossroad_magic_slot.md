# 魔導スロット

> **TL;DR:** カジノの遊技台・魔導スロット(三本リールの絵柄揃え)。

クロスロード・カジノ(`world/crossroad/28_crossroad_casino.md`)にある遊戯機。三本のリールに表示される絵柄を揃える魔導式の遊技台。

## 賭け金と回数

一回あたりの賭け金は100Gだが、一回ずつ遊ぶことはできない。最低10回から受け付け、その後も10回単位で回数を指定する。

| 回数 | 投入額 |
|---|---|
| 10回 | 1,000G |
| 20回 | 2,000G |
| 30回 | 3,000G |
| 50回 | 5,000G |
| 100回 | 10,000G |

開始前に、選択した回数分の賭け金をまとめて支払う。指定した回数をすべて回した後、各回の結果を合計して最終収支を精算する。

## 絵柄

各リールには、剣・盾・宝石・星・龍・王冠の六種類の絵柄が存在する。六種類はすべて同じ確率で出現し、三本のリールはそれぞれ独立して抽選される。

## 配当

| 結果 | 収支(賭け金100G差し引き後の純収支) |
|---|---|
| 三つとも異なる | -100G |
| 二つだけ一致(絵柄種類は問わない) | +50G |
| 剣・剣・剣 | +200G |
| 盾・盾・盾 | +300G |
| 宝石・宝石・宝石 | +400G |
| 星・星・星 | +1,000G |
| 龍・龍・龍 | +1,500G |
| 王冠・王冠・王冠 | +2,000G |

## 当選確率

全組み合わせは6×6×6=216通り。

| 結果 | 組み合わせ数 | 確率 |
|---|---|---|
| 三つとも異なる | 120通り | 約55.56% |
| 二つだけ一致 | 90通り | 約41.67% |
| 何らかの三つ揃い | 6通り | 約2.78% |
| 特定絵柄の三つ揃い | 各1通り | 約0.46% |

剣三つと王冠三つは、配当こそ異なるが出現確率は同じ。

## 期待値

一回あたりの平均収支は約-9.72G。プレイヤー還元率は約90.28%、カジノ側利益率は約9.72%となる。

### 回数ごとの平均損失

| 回数 | 投入額 | 平均損失 |
|---|---|---|
| 10回 | 1,000G | 約97G |
| 20回 | 2,000G | 約194G |
| 50回 | 5,000G | 約486G |
| 100回 | 10,000G | 約972G |

実際の結果は大きく上下する。低位三種(剣・盾・宝石)の三つ揃いは小当たり、高位三種(星・龍・王冠)は大当たりとして扱われ、比較的収支の振れ幅が大きい。

## 演出

絵柄によって三つ揃い時の演出が異なる。

- **剣**：金属音と共に剣の幻影が交差する。
- **盾**：魔法の盾が展開される。
- **宝石**：色とりどりの魔法光が弾ける。
- **星**：台の周囲に星明かりが舞う。
- **龍**：龍の咆哮と幻影が現れる。
- **王冠**：鐘が鳴り、黄金の光と王冠の幻影が台全体を包む。

龍と王冠が揃った場合は、周囲の客にも分かるほど派手な演出が発生する。

## 実際の進行ルール

遊技時には、選択された回数分を一括して抽選する。抽選結果は、各回の絵柄・各回の収支・三つ揃いの回数・総投入額・総獲得額・最終収支をまとめて表示する。

ランダム処理は文章上で決定せず、必ずPythonによる乱数処理を実行する。実行した処理と結果が確認できる形で提示し、文章上の演出と実際の抽選結果を区別する(`world/crossroad/28_crossroad_casino.md`の「運用ルール:キャラクターがカジノで遊ぶ場合」に準拠)。
