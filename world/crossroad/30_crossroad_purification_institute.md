# クロスロード浄化院

> **TL;DR:** 中央区の浄化院。土地浄化・呪物処理・結界維持・対アンデッド支援。
> ここに登場・所属するNPCは`world/crossroad/72_place_character_map.md`(場所×キャラ対応マップ)で一覧・逆引きできる。

- **場所**：中央区・神殿街寄り(`world/crossroad/20_crossroad_city_districts.md`)
- **役割**：土地浄化・呪物処理・結界維持・瘴気対策・鎮魂儀式・対アンデッド支援

## 概要

クロスロード浄化院は、中央区にある宗教系施設(`world/nations/18_religious_organizations.md`の浄化院に属する)。

主な役割は、土地の浄化、呪物の処理、結界の維持、瘴気への対策、死者の鎮魂、アンデッド発生地の後処理である。

神殿というより、現場対応と儀式管理に強い実務寄りの宗教施設。墓地、遺跡、呪われた家屋、瘴気の溜まった土地、死者の出た街道などに関わることが多い。

## 直接戦闘は専門外

クロスロードには、直接戦闘を専門とする修道院や聖騎士団が常駐していない。

そのため、浄化院はアンデッドや魔物を直接討伐する組織ではない。浄化院の本分は、戦うことではなく、土地と死者を整えることである。

浄化院が担当するのは、原因調査、浄化手順の判断、結界、封印、鎮魂、聖水散布、儀式管理、治療補助など。

戦闘が必要な場合は、冒険者、衛兵、騎士団、外部の戦闘系修道院(`world/nations/19_twin_hammer_order.md`の双槌の聖戦修道女団など)に任せる。骨鳴り墓原(`world/crossroad/63_bone_toll_moor.md`)の誘導結界維持は、この役割分担が最も分かりやすい形で表れている現場である。

## 冒険者ギルドとの関係

クロスロードでは、アンデッド系の依頼が冒険者ギルドに回されることが多い。これは浄化院が無力だからではなく、役割が違うためである。

- **浄化院**：原因調査、浄化、結界、鎮魂、呪物処理、儀式。
- **冒険者・衛兵**：現場護衛、アンデッド討伐、危険区域の制圧、呪物回収、遺跡封鎖。

浄化院が依頼内容を整理し、ギルドに戦闘・護衛・回収系の仕事として回すことが多い。

代表的な依頼：

- アンデッド討伐
- 浄化院職員の同行護衛
- 呪物回収
- 瘴気源調査
- 墓地巡回
- 結界設置補助
- 遺跡や墓所の一時封鎖
- 鎮魂儀式中の現場防衛

## 販売品

浄化院では、対アンデッド系のアイテムも多く扱っている。

冒険者向けに、聖水、浄化札、簡易結界具、魔除け香、鎮魂鈴、対霊用の護符、呪物封印布などが販売されている。

これらは高級な神器ではなく、現場で使いやすい実用品が中心。アンデッド依頼を受ける冒険者が、事前準備として購入していくことが多い。

| 品目 | 用途 |
|---|---|
| 聖水 | アンデッドや瘴気に対して使う基本アイテム。散布、投擲、武器への塗布、簡易浄化に使える。効果の等級と、武器へ塗った場合の扱いは`world/crossroad/76_artifacts.md`「消耗品と、自分のスキルへ乗せる使い方」を参照。 |
| 浄化札 | 扉、棺、墓石、呪物箱、武器、防具などに貼る簡易札。弱い瘴気や低位アンデッドの接近を抑える。 |
| 簡易結界具 | 小範囲に簡易結界を張る道具。夜営、負傷者保護、儀式中の防衛補助に使う。 |
| 魔除け香 | 焚くことで弱い霊や瘴気を遠ざける香。屋内調査や墓所探索に向く。 |
| 鎮魂鈴 | 音で霊を落ち着かせる小さな鈴。戦闘用というより、鎮魂や儀式補助に使う。 |
| 対霊護符 | レイスや霊体系に対する簡易防御札。完全防御ではないが、一度だけ干渉を弱めることがある。 |
| 呪物封印布 | 呪物や汚染物を包んで持ち運ぶための布。回収依頼では必需品。 |
| 聖油 | 武器や結界具に塗ることで、一時的に対アンデッド効果を高める油。 |
| 浄化粉 | 床、入口、棺周りなどに撒く粉。瘴気の流れを可視化したり、弱い汚染を抑えたりする。 |
| 祈祷火種 | 浄化儀式用の火種。野外での鎮魂や、呪物処理の初期段階に使われる。 |

## 施設内の機能

- **受付**：住民相談、冒険者依頼、呪物持ち込み、儀式予約を扱う。
- **浄化室**：呪物、汚染品、瘴気を帯びた装備などを処理する部屋。
- **祈祷室**：鎮魂、祈り、死者への儀式を行う静かな部屋。
- **結界具保管庫**：簡易結界具、聖水、護符、封印布などを保管する。
- **小治療室**：軽傷、瘴気酔い、精神的な不調への応急対応を行う。
- **販売窓口**：冒険者向けに対アンデッド用品を販売する窓口。

## セリアの立ち位置

セリア(`characters/npcs/09_celia.md`)は、クロスロード浄化院の若手神官。

上層部ではなく、冒険者や住民と直接やり取りする窓口担当。アンデッド系依頼、呪物相談、瘴気調査、聖水や護符の販売案内などに関わる。

戦闘職としては頼りないが、浄化手順、呪物の扱い、アンデッド化の兆候、結界維持には詳しい。

危険な現場では冒険者の護衛を必要とするが、専門知識が必要な場面ではきちんと役に立つ。

## 浄化院の本質

クロスロード浄化院は、戦う宗教組織ではなく、土地と死者を整える宗教施設である。

アンデッドを倒すことよりも、アンデッドが発生し続ける原因を鎮めること、死者を正しく弔うこと、瘴気を抑え、土地を再び汚染させないことを重視する。

直接戦闘は冒険者や衛兵に任せ、浄化院はその後ろで、浄化、結界、鎮魂、呪物処理を担う。

そのため、クロスロードではアンデッド系の依頼がギルドに多く流れ、浄化院はその依頼の発生源であり、専門的な支援窓口でもある。
