# クロス医院

> **TL;DR:** 中央区・東区境の総合医院クロス医院。世俗の回復魔法(非教会系)を主軸に日常医療を担い、聖属性・対アンデッドは扱わない。あかりが衛生担当。名前あり4人+モブ職員(大枠)。

中央区と東区の境に建つ、**世俗の回復魔法を主軸とする総合医院**。神殿系の浄化院とは別系統で、純粋な負傷・病・出産などの「普通の医療」を担う、クロスロードの日常医療の受け皿である。

> ※本ファイルは現時点では**大枠**。看板となる名前ありスタッフ(4人・あかり含む)のうち3人、および費用・規模・入院設備などの細部は今後詰める。

## 立地・位置づけ

- **中央区(行政)と東区(生活)の境**に建つ。両区の住民が使いやすい場所で、行政の目が届きつつ、生活区の暮らしにも近い。
- **領主家の後ろ盾を持つ公共寄りの医院**。市場相場(`world/06_economy.md`の医療費目安、魔法治療10,000G以上など)より手頃に、市民が回復魔法の治療を受けられることを旨とする。領主家お抱えの浄火精霊あかり(`characters/npcs/57_akari.md`)が衛生担当として関わるのも、この領主家との繋がりによる。

## 回復魔法を主軸に(浄化院・双槌との違い)

クロス医院の治療の主軸は、**世俗の回復魔法(治療術)**である。担い手は神官ではなく、医療魔導士。

- 回復魔法は、魔力を治癒力へ変換して傷口や身体へ作用させる魔法で、体系上は**第二階位＋第三階位(必要に応じて第四階位)**にあたる(`rules/05_magic_theory.md`「回復魔法」)。神格や加護元と接続する**神聖魔法(第五階位)**とは別系統である。
- そのため、クロス医院は**聖水・浄化・呪い/霊障・対アンデッドといった神聖魔法の領分は扱わない**。それらは中央区の浄化院(`world/crossroad/30_crossroad_purification_institute.md`)や双槌の聖戦修道女団(`world/nations/19_twin_hammer_order.md`)へ回す。
- 同じ「治す」でも系統が別、という住み分け:

| 案件 | 担当 |
|---|---|
| 純粋な負傷・病・骨折・出産・体力回復 | **クロス医院**(世俗の回復魔法・医術) |
| 穢れ・呪い・霊障・アンデッド由来・呪物 | 浄化院(`world/crossroad/30_crossroad_purification_institute.md`)・双槌(`world/nations/19_twin_hammer_order.md`) |
| 薬(調合・処方) | ミルカ薬品工房(`characters/npcs/13_mika.md`) |
| 薬草の供給 | 豊根(`characters/npcs/56_toyone.md`) |
| 東区住民からの取次 | マリナ(`characters/npcs/11_marina.md`) |

## 診療の範囲

- 回復魔法による傷・病の治療、体力回復
- 産科(出産の介助)
- 外科処置(骨接ぎ・縫合・切開など、回復魔法だけでは片付かない実地の処置)
- 投薬(薬はミルカ工房や薬草から仕入れる)
- 看護・療養、応急処置

※入院・長期療養設備を持たせるか、日帰り診療中心にするかは今後詰める。

## 主な人員(名前あり4人＋無名の職員)

クロス医院の看板となる名前ありは**4人**を予定している(あかり＋今後設定の3人)。実際の常勤医療スタッフの多くは無名の職員で、その技能の目安は`rules/03_combat_system.md`「モブ味方の簡易戦力」に従う(例:熟練の医療魔導士はLv30前後、看護・受付はLv10〜20)。

- **あかり**(衛生担当・確定)…領主家お抱えの浄火精霊(`characters/npcs/57_akari.md`)。**直接の治療は行わず**、浄火で院内の消毒・防疫・清潔維持・照明・加温を担う裏方。あかりの浄火は燃焼を起こさず病原・腐敗・不潔だけを清める非攻撃の炎で、聖属性の浄化とは別物ゆえ、医院の衛生管理にはうってつけ。清潔な治療環境を支えることで、回復魔法の治療を下支えする。
- **治療の主力(3人・今後設定)**…回復魔法を主軸に、以下のような役どころを想定した枠(詳細・氏名は今後)。
  - 院長格の筆頭治療魔導士(重症・難症を診る)
  - 実地の治療役(外科処置など、魔法で治しきれない領域)
  - 産科・看護、または受付・院の運営を回す顔
- **無名の職員(モブ運用)**…上記以外の常勤医療魔導士・看護・薬係・受付は無名の職員で回す。
