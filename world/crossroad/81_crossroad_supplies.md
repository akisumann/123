# 道具屋と消耗品の値段

> **TL;DR:** 消耗品の値段表(回復薬・毒消し・閃光玉・煙玉・眠り玉・樹脂膏・携帯食・松明・油紙・罠・浄化院の聖具)と、北区の道具屋《辻の備え》。消耗品は使えば無くなるので同じLvでも耐久品より安い(Lv2は300〜800G、Lv3は1,000〜2,000G)。

## 値段の物差し

**消耗品は、使えば無くなる。** だから同じ付与スキルLvでも、武器や魔道具のような耐久品(`world/crossroad/76_artifacts.md`「量産品の等級」。並Lv2で5,000G〜)よりずっと安い。耐久品の等級表をそのまま消耗品に当てはめないこと。

| 付与スキルLv | 消耗品の値段の目安 | 位置づけ |
|---|---|---|
| Lv0 | 10〜150G | 付与の無い道具。松明、縄、油紙、携帯食 |
| Lv1 | 50〜150G | 効くには効く、という程度 |
| **Lv2** | **300〜800G** | **並。** 冒険者が一番よく買う帯 |
| **Lv3** | **1,000〜2,000G** | 良質。深い傷、強い毒、大型の相手に |
| Lv4 | 4,000G〜 | 上質。**店頭に常には無い。** 工房へ注文するか、入荷を待つ |

`world/06_economy.md`「医療・薬」の幅(一般薬300〜1,500G、回復薬500〜2,000G)は、この表のLv2〜Lv3にあたる。

**付与スキルの使い方は`world/crossroad/76_artifacts.md`「消耗品と、自分のスキルへ乗せる使い方」の通り。** そのまま使えば品のLvで振り、道具を扱う自分のスキル(例:抜刀道具術)へ乗せれば自分のLvで振る。

## 道具屋《辻の備え》

北区、**北門《王都門》から中央広場へ伸びる大通りの、北門寄り**に並ぶ道具屋の一軒。軒先に**薬瓶の看板**を下げている。旅装店と、縄と天幕と鍋ばかりの道具屋に挟まれた三軒目。

**冒険者が街を出る前に、消耗品をまとめて揃える店。** 上の①〜④をひと通り置いていて、値段は表の通り。浄化院の聖具は置いていないが、聞けば中央区の浄化院を教えてくれる。

- **店番は前掛けをした中年の男。** 名前は特に知られていない。品の使い方を短く添えて渡す(「湿気に弱いから油紙で包め」「四人で一泊なら普通の方を六から八本」)
- **安く上げたい客には、南の投げ売り市を自分から教える。** ただし「命を預ける物をあそこで買う度胸があるなら」と必ず付け足す
- 嵐で門が閉まった日も戸を開けている。足止めを食った商隊の人間が暇つぶしに覗きに来るからである

**北区に道具屋はいくらでもある。** 《辻の備え》は、その中で冒険者の消耗品が一通り揃う一軒として名前が付いているだけである(`world/crossroad/20_crossroad_city_districts.md`「名前のある店は、目立つ店にすぎない」と同じ扱い)。
