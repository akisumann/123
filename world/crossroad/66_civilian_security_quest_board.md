# クロスロード周辺・護衛と治安の依頼表

> **TL;DR:** 街道・都市が舞台の護衛・盗賊討伐・捕縛・警備の定番依頼例。

危険地域(`world/crossroad/64_danger_zone_quest_board.md`)やダンジョン(`world/crossroad/65_dungeon_quest_board.md`)のような特定の魔物・資源が舞台ではなく、街道・都市そのものを舞台にした、護衛・盗賊討伐・犯罪者の捕縛・警備の定番依頼の例。依頼主は商人、貴族、農村、興行主、衛兵隊など人間側であることが多い。

## 基本運用

- 基本報酬は`world/06_economy.md`の「1件の依頼で1人が受け取る平均的な金額」の基準に従う。以下の基本報酬はパーティーメンバー1人あたりの目安として扱う。
- 盗賊・野盗は野生の魔物と違い特定の場所に固定的に生息しない(`world/crossroad/11_crossroad_city.md`)。そのため街道自体に推奨レベルはなく、依頼ごとにその時点の脅威規模へ応じてランクが個別に割り振られる。
- 犯罪者の身柄は衛兵隊(`world/crossroad/31_crossroad_security_forces.md`)へ引き渡す。魔物討伐と異なり、身柄そのものは素材買い取りの対象にならない。ただし手配書に懸賞金が別途ついている場合は、引き渡し時にその分が上乗せされる。
- 黒針会(`world/crossroad/32_black_needle_society.md`)のような表向き存在しない裏組織そのものを標的にした依頼は、通常のギルド掲示板には出ない。掲示される犯罪者は、街を渡り歩く小悪党、指名手配中の逃亡犯、突発的に発生した野盗団など、裏社会の縄張りに属さない存在が中心。
- 相手が武装した人間である依頼では、戦闘力だけでなく、人質の有無・逃走経路・自白や証言の確保・無用な殺傷を避けられるかも評価対象になる。
- 護衛依頼では、依頼主・積荷・随伴者の安全が最優先で、道中の魔物討伐数は評価に直結しない。

## 特殊依頼の発生

通常の定番依頼とは別に、次の条件で臨時依頼が発生する。

- 大物の指名手配犯がクロスロードに潜伏しているとの情報が入った
- 特定の街道で隊商襲撃が立て続けに発生している
- 祭りやイベントの最中に不審な集団が確認された
- 衛兵隊だけでは手に負えない規模の暴動・騒乱が発生した
- 脱獄・護送中の逃亡が起きた
- 複数の盗賊団が縄張り争いで街道へ影響を及ぼし始めた

実際のセッションで依頼を提示する際は、次の形式を使う。

```
基本報酬(1人あたり)：

推奨人数：
依頼主：
期限：
注意事項：
```
