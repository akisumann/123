# クロスロード職人区・冒険者向け商品

> **TL;DR:** 南区職人区で危険地域の素材が加工された、冒険者向け商品の数々。

南区・職人区(`world/crossroad/20_crossroad_city_districts.md`)では、周辺の四大危険地域(`world/crossroad/11_crossroad_city.md`の「危険地域産の素材と買い取り」)から持ち込まれた素材が加工され、冒険者向けの商品として並ぶ。

店頭に並ぶのは完成品だけではなく、以下の四段階に分かれる。

- 一般素材で作った量産品
- 現地素材を一部使った実用品
- 冒険者が素材を持ち込んで作らせる特注品
- 希少素材を使った一点物

## ① 武器鍛冶

剣、槍、斧、短剣などを扱う一般的な武器職人。区画を代表するのが鍛冶師ガルム・フォージライト(`characters/npcs/06_galm_forgelight.md`)。

| 商品群 | 使用素材 | 特徴・買い手 |
|---|---|---|
| 赤根柄の武器 | 赤牙森林の赤根木材 | 剣・斧・槍の柄に使用。硬いうえに適度にしなり、強い衝撃でも柄が折れにくい。中級冒険者向けの定番 |
| 牙芯の短剣 | ホーンラビットの角、大型草食獣の角(`world/crossroad/61_red_fang_forest.md`) | 角や牙を削り金属の刃芯と合わせた短剣。金属製より軽く魔力を流しやすい。解体に使いやすく、魔法職でも携帯でき、破損しても素材交換が容易。安価で、最初に買う副武器として人気 |
| 灰岩鋼武器 | 灰岩峡谷の灰岩鉱 | 重く頑丈。切れ味より壊れにくさと重量を活かした打撃に優れる。大剣・戦槌・重斧・杭槍が主で、高い筋力の前衛向け |
| 黒鉄の霊断武器 | 死霊騎士の黒鉄、清め骨灰 | 浄化済みの黒鉄に清め骨灰を混ぜた対アンデッド武器。実体を持たない幽霊や霊体もそのまま斬れる。浄化院(`world/crossroad/30_crossroad_purification_institute.md`)の検査印がなければ販売不可 |

### 素材持ち込み鍛造

冒険者が自分で得た素材を持ち込み、武器を製作してもらう方式。工賃は必要だが、完成品を買うより安くなる場合がある。ただし、素材が粗悪だった場合は追加料金が発生する。

素材評価の基準：傷の少なさ、魔力の残存量、採取時の処理、腐敗や呪染の有無、必要量が揃っているか。希少素材を一本だけ持ち込んでも、それだけで武器一本が完成するとは限らない。

## ② 防具職人

金属鎧だけでなく、革鎧、外套、盾、魔物素材防具を扱う。

| 商品群 | 使用素材 | 特徴・買い手 |
|---|---|---|
| 平原狼の旅装 | ウルフの毛皮 | 防寒・野営・軽い防護を兼ねた外套や寝袋。安価で丈夫。低級素材を無駄なく使えるため初心者にも手が届く |
| 岩蜥蜴の軽甲 | ロックリザードの背甲 | 薄く削った背甲を革鎧に重ねた軽装防具。金属鎧より軽く、落石や打撃に強い。灰岩峡谷へ向かう冒険者自身がよく買う |
| 飛竜鱗の風鎧 | ワイバーンの鱗 | 軽量で強風を受け流しやすい高級防具。飛行中や高所で姿勢を崩しにくい。鱗の大きさや採取部位で品質が大きく変わる |
| ガーゴイルの守護盾 | ガーゴイルの石翼片、灰岩鋼 | 魔力を含む石翼片を埋め込んだ盾。衝撃を受けた瞬間だけ表面が硬化する。長時間の防御より、大型魔物の一撃を止める壁役向き |
| 墓守の防護具 | 清め骨灰、霊白石、浄化布 | アンデッドや霊障への対策を施した外套・胸当て・首飾りなど。物理防御力は高くないが、骨鳴り墓原では重装鎧よりこちらを優先する冒険者も多い |

## ③ 弓師・矢師

| 商品群 | 使用素材 | 特徴・買い手 |
|---|---|---|
| 赤根の狩猟弓 | 赤根木材 | しなやかで耐久性が高い。中級冒険者や森林狩人の定番 |
| 風切羽の矢 | ハーピーの風切羽 | 飛行が安定し、横風の影響を受けにくい。狙撃用・追風矢・鳴り矢など用途別に揃う。交易で得た自然脱落羽には「里印」が付き、討伐由来の羽根と区別される |
| 灰岩の徹甲矢 | 灰岩鉱 | 重く硬い矢尻の対装甲用。射程は少し落ちるが甲殻や盾に強い |

## ⑤ 魔道具工房

素材に術式を刻み、冒険用の補助道具を作る。

| 商品 | 使用素材 | 特徴・用途 |
|---|---|---|
| 風穴晶の送風筒 | 風穴晶 | 内部に空気を蓄え、短時間だけ強風を放つ筒。煙や毒霧を吹き飛ばす、落下速度を弱める、小型魔物を押し返す、火を強くする、換気する——攻撃専用ではなく用途の広い補助道具 |
| 遠吠え警報器 | 遠吠え狼の喉骨 | 一定以上の大きさの生物が近づくと低い遠吠えを発する。相手の種類までは判別できない。野営地や馬車の警戒用 |
| 霊白灯 | 霊白石 | 通常の光では見えにくい霊体や呪力の痕跡を、淡い光として浮かび上がらせるランタン。骨鳴り墓原の探索では定番品 |
| ガーゴイル警戒像 | ガーゴイルの石翼片 | 小型の石像型魔道具。近くで大きな振動や魔力変化を感知すると口から警告音を発する。高級品には侵入方向を示す機能もある |
| 魂縛の捕縛鎖 | 魂縛鎖の破片 | 霊体や召喚存在を短時間拘束できる危険な魔道具。**一般販売は禁止**。冒険者ギルド・浄化院・騎士団などの許可を得た者にのみ貸し出される |

## ⑥ 革細工・旅装職人

冒険に必要な鞄、靴、手袋、ベルト、採取道具を扱う。

### スライム防水鞄

使用素材：草原スライムの粘液。

内側に加工粘液を塗った防水鞄。薬草や書類を雨から守れる。

### 赤牙樹脂の滑り止め手袋

使用素材：赤牙樹脂。

武器や登攀具を握りやすくする手袋。雨天や峡谷探索で需要が高い。

### 岩蜥蜴の登攀具

使用素材：ロックリザードの背甲、灰岩鋼。

峡谷用の爪付き手甲と足具。岩壁を傷つけながら固定するため、市街地では使用禁止。

### 墓原封印鞄

使用素材：霊白石、清め骨灰、赤牙樹脂。

呪われた素材やレイスの残滓を一時保管する専用鞄。完全な封印具ではないため、帰還後すぐに浄化院へ持ち込む必要がある。

## ⑦ 解体師・素材処理業者

商品販売だけでなく、冒険者が持ち帰った素材を商品として使える状態にする職人。

主な仕事：魔物の解体、血抜き、牙や角の取り外し、毛皮の剥離、毒腺の摘出、魔力器官の保存、呪染検査、素材の等級判定。

解体に失敗すると、本来高価な素材でも価値が大きく落ちる。特に以下は専門家への依頼が推奨される。

- ワイバーンの風嚢
- レイスの残滓
- 死霊騎士の黒鉄
- トレントの生枝
- 毒性のある茸や器官

## 商品が生まれる流れ

### 例：赤牙森林

冒険者が赤根木材を採取 → 素材商が乾燥と品質検査 → 木工職人が柄や弓材へ加工 → 鍛冶屋や弓師が完成品にする → 冒険者が赤根槍や赤根弓を購入 → 再び赤牙森林へ向かう

### 例：灰岩峡谷

冒険者が灰岩鉱と風穴晶を採取 → 鉱石職人が精錬 → 鍛冶屋が武器や防具を製作 → 魔道具職人が風穴晶を組み込む → 峡谷向けの装備として販売される

### 例：骨鳴り墓原

冒険者が黒鉄や霊白石を回収 → 浄化院が呪染を検査 → 許可された素材のみ職人区へ流通 → 対アンデッド装備へ加工 → 墓原へ向かう次の冒険者が購入する
