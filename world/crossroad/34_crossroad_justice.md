# クロスロードの裁きと刑罰

> **TL;DR:** 捕まえた者が裁かれ牢に入るまで。刑は記録・賠償・労役・出禁・収監・追放、重罪は王都送り。

衛兵隊が犯人を捕らえた後、あるいは冒険者が捕縛依頼(`world/crossroad/66_civilian_security_quest_board.md`)で身柄を引き渡した後の話。捕縛までは`world/crossroad/31_crossroad_security_forces.md`を参照。

## 裁き

専門の裁判官はいない。**領主クラリス**(`characters/npcs/01_clarisse_weissfeld.md`)が最終決定権を持ち、都市行政の一部として裁く。

軽微なものは現場の衛兵がその場で処理し、被害届の出た事件は**衛兵隊長エイダ**(`characters/npcs/04_ada_lockwell.md`)が扱い、大きな事案が庁舎まで上がる。**殺人・誘拐・放火・反逆は、領主が事実を確定させて王都へ送る。** 死刑を出す権限は都市に無い。

## 牢

中央区・**衛兵本部の地下**にある。留置房と、長期の収監房が分かれている。

**脱走されないよう、様々な魔法で対策されている。** 具体的な手法は公開されていない。

看守の仕事は、生活の世話と記録である。

## 刑

軽い順。組み合わせて言い渡されることが多い。

| 刑 | 内容 |
|---|---|
| 叱責と記録 | その場で帰すが、**記録所(中央区)に名前が残る**。何度出ているかが以後の処分の重さを決める |
| 賠償 | 被害の弁済(`world/06_economy.md`の金額感覚に沿う)。払えなければ分割か労役 |
| 労役 | 下水道の清掃、街道の補修、市場の後片付けなど。数日から一月 |
| 出禁 | 特定の区画・施設への出入り禁止 |
| 収監 | 数月から数年。累犯・悪質な詐欺・傷害・組織的犯行など。収監中も労役には出す |
| 追放 | 主に余所者へ。四大門に人相が回る。**期限付きなら、期限が来れば戻ってこられる** |
| 王都送り | 重罪。身柄と記録を王都へ。護送は領主騎士団 |

## 覚えておく点

- **冒険者は冒険者カードに記録が付く**(`world/14_adventurers_guild.md`)。カードは世界共通なので、他都市の支部でも読まれる。冒険者にとっては追放より記録の方が重い。
- **民間の処分の方が実効が早い。** 娼館通り三軒の情報共有(`world/crossroad/50_crossroad_brothels.md`)、大カジノの出禁(`world/crossroad/28_crossroad_casino.md`)、歓楽街組合の締め出し。特に西区では、行政の裁きが出る前に組合が決着させていることが多い。
- **犯罪の大半はそもそも捕まらない**(`world/crossroad/31_crossroad_security_forces.md`「治安の前提」)。裁きに掛かるのは例外的なしくじりの方である。

## GM運用

- 捕まえた場面を書いたら、**その先を一段だけ示す**。記録か、過料か、収監か、追放か。
- **脱走を話の種にしない。** やりたい場合は牢の外(護送中、捕縛前、判決前)を狙う。
- **死刑を都市の判断で出さない。** 王都送りにする。
- 上の表に無い細部(捜査の手順、弁護、時効、種族ごとの扱いなど)は、**必要になった場面でその都度決めてよい**。
