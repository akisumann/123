# モンスター分類

## 基本モンスター分類

この一覧は、モンスターの基本種族を管理するための分類である。

この90種は現時点で記録されている代表的な基本種族に過ぎず、世界にはここに載っていない基本種族も数多く存在する。「一覧にない」ことは「世界に存在しない」ことを意味しない。新しい基本種族も、既存設定と矛盾しない限り自由に追加してよい。

火炎スライム、スライム亜種、黒曜ゴーレム、古代ドラゴンなどの名称は自由に作成できるが、分類上はそれぞれスライム、ゴーレム、ドラゴンとして扱う。

## モンスター命名規則

### 基本方針

モンスターは基本種族を基準として分類する。名前がどれだけ変化していても、分類は基本種族で統一する。

### 基本種族(例)

- スライム
- ゴブリン
- オーク
- ゴーレム
- ドラゴン
- ワイバーン
- トレント
- スケルトン

など。図鑑・生態分類・種族分類では、この基本種族名を使用する。

### 命名

基本種族の前後へ自由に名称を付けることができる。

**○○+基本種族**

- 火炎スライム
- 氷結スライム
- 黒曜ゴーレム
- 古代ドラゴン
- 森林ゴブリン
- 深海ワイバーン

**基本種族+○○**

- スライム亜種
- スライムキング
- ゴーレム試作型
- ドラゴン幼体
- オーク将軍
- ゴブリンシャーマン

**両方を組み合わせてもよい**

- 火炎スライムキング
- 古代黒曜ゴーレム
- 深海ドラゴンロード
- 氷結ワイバーン亜種

### 分類

名称が変化しても種族分類は変わらない。

| 名称 | 種族分類 |
|---|---|
| 火炎スライム | スライム |
| スライムキング | スライム |
| 黒曜ゴーレム | ゴーレム |
| ゴーレム試作型 | ゴーレム |
| 古代ドラゴン | ドラゴン |
| ドラゴンロード | ドラゴン |

### 特殊個体

特殊個体・ヌシ・突然変異・古代種・希少種なども、基本種族は変化しない。

例:

- スライムの特殊個体
- ドラゴンの古代種
- ゴーレムの試作型
- オークの英雄個体

## 巨人族について

基本種族「9. 巨人」は、モンスターとしての巨人種と、クリスタル・フロスト帝国のメイン種族である巨人を包括する分類として扱う。

オークやオーガ、トロールなどと同様、同じ基本種族の中でも知性・文化の発達度には大きな幅があり、国家を築くほど高度な知性を持つ個体群もいれば、野生のモンスターとして生きる個体群もいる。クリスタル・フロスト帝国の巨人は、その中でも高度な文明を築いた一派として位置づける。

## 運用方針

モンスター名は世界観や地域性に合わせて自由に命名してよい。

ただし、生態分類や図鑑上の種族は必ず基本種族で管理する。これにより、新たなモンスターを追加しても分類が煩雑にならず、世界全体で統一された命名規則を維持できる。
