# 盗人姉妹：ロゼとリゼ

> **TL;DR:** 盗人姉妹ロゼ&リゼ。色仕掛けとスリの小悪党、街の軽いトラブル役。

クロスロードの北区・西区・裏路地を中心に活動する盗人姉妹。

スリ、置き引き、軽い詐欺、情報の横流し、賭け場周辺の小銭稼ぎなどを行う。色仕掛けや甘い態度で相手を油断させ、その隙に金や小物を盗む手口も得意とする。

ただし大悪党ではない。殺し、誘拐、大規模犯罪、呪物売買、危険薬物などには関わらない。そこまで踏み込む度胸もなく、本人たちも「それは洒落にならない」と考えている。

街の衛兵や歓楽街組合からも目をつけられているが、致命的な悪事はしないため、捕まっても説教、罰金、短期拘束で済むことが多い。

裏の情報・暗殺組織「黒針会」(`world/crossroad/32_black_needle_society.md`)そのものではないが、その情報網に引っかかっている末端の一人。使えそうなら情報を拾われたり、使い走りとして利用されたりする可能性がある。

腕利き相手には明確に格下。ただし、駆け出し冒険者や観光客、酔った客相手なら普通に出し抜ける程度の腕はある。

ロゼが軽口と距離の近さで注意を引き、リゼがその隙に財布や札を抜く。二人で組んだ時の成功率は高いが、高レベル冒険者や感知能力持ちには通用しにくい。

## ロゼ

- 種族：人間
- 年齢：24歳
- レベル：25(冒険者ランク基準ではDランク相当。`world/14_adventurers_guild.md`)
- 役割：囮・交渉・色仕掛け・逃走補助・軽詐欺
- 通り名：囮のロゼ
- セリフ：「あら、怖い顔しないでよ。ちょっと楽しくお話ししたかっただけじゃない」
- 外見：明るい茶色の巻き髪と、人懐っこい笑顔。目を引く色使いの艶っぽい衣装を好んで着る。

### ステータス

| 項目 | ランク | 内容 |
|---|---|---|
| HP | D | 荒事から逃げ回れる程度の体力はある |
| MP | E | 魔法はほとんど使えない |
| ATK | D | 短剣で牽制する程度。正面戦闘は苦手 |
| DEF | D | まともに受けるより、逃げる・誤魔化す方が得意 |
| INT | C | 嘘、言い訳、相手の油断を読む勘はある |
| SPD | B | 逃げ足が速く、人混みに紛れるのが上手い |
| DEX | B | 小細工、すり替え、手癖の悪さに優れる |

ステータス合計：24(Lv25、diff-1で許容範囲内)

### スキル

- ◇ 軽口煙幕　Lv2(嘘と軽口で相手の注意を逸らす)
- ◇ 甘い囮歩き　Lv3(色仕掛けで油断を誘う歩き方・話しかけ)
- ◇ 人混み逃走　Lv3(雑踏に紛れて追跡を振り切る)
- ◇ 小物すり替え　Lv3(気付かれずに小物をすり替える)
- ◇ 悪運　Lv2(危ない場面で際どく切り抜ける強運)

スキルLv合計：13(Lv25の半分とほぼ一致)

### プロフィール

口が回り、軽口、嘘、距離の近さで相手の注意を引く囮役。酒場、歓楽街、カジノ周辺(`world/crossroad/28_crossroad_casino.md`)、コロッセオ帰り(`world/crossroad/27_crossroad_colosseum.md`)の浮かれた客を相手に、色仕掛けや甘い態度で油断を誘い、その隙に金や小物を盗む手口を得意とする。

盗みそのものもできるが、本領は相手の視線と意識を自分に向け、妹のリゼが動きやすい状況を作ること。

小悪党ではあるが、大悪党ではない。調子がよく、軽薄そうに見えるが、妹には甘い。

## リゼ

- 種族：人間
- 年齢：21歳
- レベル：25(冒険者ランク基準ではDランク相当。`world/14_adventurers_guild.md`)
- 役割：スリ・鍵開け・隠密・色香すり抜け・逃走
- 通り名：スリのリゼ
- セリフ：「……姉さんが喋ってる間に、もう終わってる」
- 外見：黒髪のショートヘアと、人混みに紛れやすい地味な色の装束。姉と違って目立つことを避けた身なりを好む。

### ステータス

| 項目 | ランク | 内容 |
|---|---|---|
| HP | C | 長時間の逃走や裏路地移動を涼しい顔でこなす持久力 |
| MP | E | 魔法はほとんど使えない |
| ATK | E | 戦闘は不得手。ナイフも護身用 |
| DEF | D | 打たれ強くはないが、捕まらない立ち回りをする |
| INT | C | 観察力が高く、盗む相手や逃走経路を冷静に見る |
| SPD | B | 素早く、狭い路地や屋根伝いの移動が得意 |
| DEX | B | スリ、鍵開け、紐解き、細かな手作業が得意 |

ステータス合計：25(Lv25、diff±0)

### スキル

- ◇ 指先抜き取り　Lv3(気付かれずに財布や小物を抜き取る)
- ◇ 色香すり抜け　Lv2(ロゼが作った隙に紛れて近距離から仕留める)
- ◇ 気配薄め　Lv3(息を潜めて存在感を消す)
- ◇ 裏路地走法　Lv3(裏路地・屋根伝いの逃走経路取り)
- ◇ 姉妹連携　Lv2(ロゼとの息の合った役割分担)

スキルLv合計：13(Lv25の半分とほぼ一致)

### プロフィール

無口気味だが観察力が高く、姉のロゼが注意を引いている間に財布、札、鍵、小物を抜き取る実行役。鍵開け、スリ、紐解き、裏路地逃走に長けており、駆け出し冒険者や観光客、酔った客なら普通に出し抜ける。

色香すり抜けは、ロゼが作った甘い空気や相手の油断を利用して、近距離から金品を抜く技術。リゼ本人も、控えめな仕草や無害そうな雰囲気で警戒を外すことができる。

小悪党ではあるが、大悪党ではない。腕利き相手には明確に格下だが、街の軽いトラブル役や裏路地案内役としては使いやすい。

## 日常

稼ぎ場はコロッセオ帰りやカジノ帰りの浮かれた客が多い西区周辺。北区の交易酒場「七つ樽」も、商隊関係者の懐が緩む店として時々狙い場所にしている。稼いだ金はその日のうちに二人で使い切ることが多い。

## GM運用:盗みは普通に成功させてよい

**二人の盗みを、毎回「未遂」「寸止め」「誰かに見咎められて失敗」で流さないこと。** 駆け出し冒険者・観光客・酔った客なら普通に出し抜ける腕前であり(上記プロフィール)、黒針会も小さな犯罪は泳がせている(`world/crossroad/32_black_needle_society.md`「黒針会と小悪党」)。つまりこの街では、二人の小さな盗みは**日常として実際に成功している**のが正しい姿である。

- **実行した盗みは10回中9回は成功して然るべき。** 失敗=捕縛か破滅の稼業では、分の悪い盗みを仕掛ける者はそもそも生き残れない。プロの選別は実行前に済んでいる——腕利き・感知持ち・警戒中の相手は**最初から狙わない**のであって、狙って見抜かれるのではない。そこらの子供のスリですらこの水準で選んでいる。
- 被害者が浮かれたモブ客・酔客なら、判定なしで描写として成功させてよい。財布や小物・小銭レベルの日常犯罪であり、毎回捕まえたり改心させたりしない。判定(`rules/03_combat_system.md`)を振るのは、獲物選びを誤った・状況が急変した、といった際どい例外の時だけ。
- しくじってエイダ(`characters/npcs/04_ada_lockwell.md`)に説教される日は、あくまで稀な例外として扱う(「捕まった時に説教される」関係はその頻度で成立している)。
- 「小悪党ではあるが大悪党ではない」の線は守る。稼ぎはその日のうちに消える程度で、被害が街の事件として積み上がるほどの規模にはしない。
