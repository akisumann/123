# 綴葉(つづりは)

> **TL;DR:** 中央区大神殿の資料区画の司書・綴葉(Lv30・人間・男性・41歳)、通り名「年繰りの綴葉」。祈祷や儀礼は担当せず、測って・書いて・綴じて・照らし合わせるのが仕事。値打ちは測る腕ではなく綴じてある年数の方にあり、何年ぶんもの記録を並べて初めて「伸びが止まった」と分かる(年繰りLv5)。低く遅い口調で、淀まず急がない。記録にないことは言わず、見込みも慰めも足さない。告げた後に相手が黙れば、こちらも黙って待つ。数字の誤りにだけは静かに食い下がる。行きつけは大神殿近くの茶屋《土香る庵》。

- 種族：人間
- 年齢：41歳　　性別：男性
- レベル：30(冒険者ランク基準ではDランク相当。`world/14_adventurers_guild.md`)
- 所属：中央区大神殿(`world/crossroad/48_grand_temple_dragon_records.md`)
- 立場：資料区画の司書。測定と記録を担当する神官
- 通り名：年繰りの綴葉

◆役割
測定・記録・照合・資料区画の管理

『十八の年にレベル二十六、二十二で二十九、二十六で三十。そこから四年、動いておりません』

## 外見

痩せて背の高い中年男性。神官服は洗いすぎて色が抜けており、袖口だけインクで黒ずんでいる。背をわずかに丸めて歩く癖があり、これは長年書見台に向かってきた形がそのまま残ったものである。

目を細めて物を見る。近くの字は問題なく読めるが、少し離れた人の顔は分かりにくいらしく、名を呼ばれてから誰か気づくことが多い。

**声が低く、動作が遅い。** 書架の前で振り向く時も、階段を下りる時も、急いでいるところを見た者がいない。**参拝者は、この男が慌てるところを想像できない。**

## ステータス

| 項目 | ランク | 内容 |

| HP | C | 書架の上げ下ろしと立ち仕事に耐える。丈夫ではないが、一日中続けられる |
| MP | B | 測定の設備を回すのに要る魔力を、一日ぶん切らさず出せる |

| DEF | D | 特別な鍛え方はしていない |
| INT | B | 何十年ぶんの記録の在り処と中身を、目録を引かずに辿れる |
| SPD | D | 急がない。急いだところで書架の場所は変わらない |
| DEX | B | 測定の手つきと筆写が正確。数字を書き違えたことがない |

ステータス合計：32(Lv30、diff+2で許容範囲内)

## スキル

- ◇ 年繰り　Lv5(**同じ人物の何年ぶんもの記録を並べ、伸びが止まった一点を見つける。** 一回の測定では絶対に分からないことが、並べると分かる。**レベルキャップは十の倍数で区切られている**ため(`rules/00_level_system.md`)、丸い数字で止まった者は疑いが濃くなるが、**止まったのか休んでいるだけなのかは、年数を並べなければ言えない**)
- ◇ 測定儀の運用　Lv4(大神殿の測定設備を扱う。レベル・ステータス・スキルを読み取り、数値として出す)
- ◇ 書架把握　Lv3(資料区画のどこに何があるかを頭に入れている。大地龍の記録、五龍の比較資料、古い石板、測定の綴じ本)
- ◇ 筆写　Lv2(読み取った数値を正確に写し、年ごとに綴じる)
- ◇ 応対　Lv1(窓口に立つ。**客あしらいはしない。** 用件は数字なので、それだけを扱う)

スキルLv合計：15(Lv30の半分と一致)

## プロフィール

中央区大神殿の資料区画を任されている神官。祈祷や儀礼はほとんど担当せず、**測って、書いて、綴じて、照らし合わせる**のが仕事である。

大神殿はもともと大地龍を実地で観察・測量・記録して石膏像を作った施設であり(`world/crossroad/48_grand_temple_dragon_records.md`)、資料区画にはステータス資料やスキル解説も展示されている。**測ることと残すことは、この神殿の元からの本業**である。綴葉はその一番地味な部分を、二十年以上担当し続けている。

**訪れるのは冒険者だけではない。** 一般市民、農民、学生、子供、親に連れられてきた者——誰でも測ってもらえる。大神殿は信者以外にも広く開放されている。

**綴葉の値打ちは、測る腕ではなく、綴じてある年数の方にある。** 一回測っても、その人が伸びている途中なのか、もう止まったのかは分からない。**何年もかけて同じ人を測り続けた記録を並べて、初めて分かる。** だからこの仕事は、代わりが利かないのではなく、**始めてから二十年経たないと使い物にならない**。

## 口調

一人称は「私」。**低く、遅い。淀まず、急がない。** 二十年ぶんの記録を背にして喋るので、言葉に重さがある。

- **数値は間を置かずに出る。** 年齢と数字を順に並べるだけで、飾らない
- **記録にないことは言わない。** 見込みも慰めも足さない。**それを誠実さだと思っている**
- **沈黙を埋めない。** 告げた後に相手が黙れば、こちらも黙って待つ。**二十年やっていれば、今は何も言われたくない者が分かる**
- **書架と記録の話だけは滑らかで、少し長い。** ここでは、聞かれた以上のことを答える
- **数字の誤りには静かに食い下がる。** 声を上げないまま、正しくなるまで引かない

例:

- 綴葉「十八の年にレベル二十六、二十二で二十九、二十六で三十。そこから四年、動いておりません」
- 綴葉「記録にあるのは、ここまでです。この先は、測っておりません」
- 綴葉「三十一ではありません。二十九です。綴じ本をお持ちします」
- 綴葉「三段目の左です。表紙が外れておりますので、すぐ分かります。隣が同じ年の写しになります」

## 日常

**行きつけ**：茶屋《土香る庵》(大神殿近く。`world/crossroad/49_crossroad_dining.md`)。

朝は資料区画の窓を開けて回り、湿気を見る。日中は測定と筆写。参拝者が途切れた時間に、古い綴じ本の傷んだ背を直している。

**大神殿の本殿脇にある大地龍の杖**(`world/crossroad/48_grand_temple_dragon_records.md`)の前を、一日に何度も通る。挑戦する参拝者を止めないし、笑いもしない。**抜けなかった者へ何と言えばいいのかは、二十年経っても分かっていない。**

## 街や組織での立場

**測ってもらった者からは覚えられているが、綴葉の側は相手を覚えていない。** 何百人ぶんの数字を扱ってきたので、顔と記録が結びつかない。名を言われて綴じ本を引けば、その人の十年前まで全部出てくる。

冒険者ギルド(`world/crossroad/20_crossroad_city_districts.md`)とは測定まわりで付き合いがあり、支部長のダリオ(`characters/npcs/07_dario_langford.md`)とは長い。ダリオは元鑑定士で人材を見る目があるが、**あちらは会って見抜き、綴葉は綴じて見つける**——同じことを別の側からやっている。
