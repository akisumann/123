# ガルム・フォージライト

> **TL;DR:** 南区の腕利き鍛冶師ガルム。武器修理・特注武具の窓口。

- 年齢：46歳　　性別：男性
- レベル：36(冒険者ランク基準ではCランク相当。`world/14_adventurers_guild.md`)
- 立場：鍛冶師・武具職人
- 所属：クロスロード南区・職人組合(`world/crossroad/20_crossroad_city_districts.md`)
- 関係：領主騎士団や冒険者ギルドに武具を納める職人
- 通り名：鍛冶頭のガルム

## 外見

白髪交じりの無精髭と、がっしりした体格。革のエプロンの下は煤と火花跡だらけの作業着で、着替えるより繕う方が早いといった様子。

## 概要

南区に工房を構える腕利きの鍛冶師。冒険者向けの武器修理、騎士団向けの装備整備、魔物素材を用いた特注武具の製作を請け負う。

クロスロードではかなり名の通った職人で、特に「実戦で壊れにくい武器」を作ることに定評がある。

### 一番多いのは武器。ただし何でも打てる

**商売の大半は武器である**(`world/crossroad/42_crossroad_artisan_goods.md`①)。剣・槍・斧・短剣。棚の大半は無銘の量産品(付与は「剣撃Lv2」程度、5,000G〜)で、その上に素材持ち込みの鍛造と修理が乗る。**「真っ当な武器を買う・直す」なら、まずこの工房**である。

**ただしガルムは武器職人ではなく、鍛冶師である。** 鉄と鋼と火で形になる物なら、頼まれれば大抵は打つ。

- **鎧の金属部**——イチカへ卸している(**打つのはガルム、体に合わせて組むのはイチカ**)
- **矢尻**——ニノへ卸している
- **鉄と鋼そのもの**——サンへ卸している
- 農具、蝶番、錠前、鍋、荷馬車の金具、炉の部品、門扉の補強といった、冒険と関係のない仕事も普通に受ける
- 騎士団の装備整備、冒険者ギルド経由の修理

**三軒の専門店に対して、ガルムの工房は「持っていけば大抵なんとかなる」場所**である。職人の通りで一番間口が広く、**何の店へ行けばいいか分からない時の既定の行き先**になる。

**ただし鍛冶屋はこの工房だけではない。** 通りには同業の店が何軒もあり、**ガルムは目立つから名前が付いているというだけ**である(`world/crossroad/20_crossroad_city_districts.md`「名前のある店は、目立つ店にすぎない」)。並の武器を買う・直すだけなら、名の無い店で足りる。

**それでも外れる仕事はある。** 魔法鍛冶そのものは専門外で、複雑な機構物はセレナ(`characters/npcs/26_serena_gearford.md`)か琥珀(`characters/npcs/52_kohaku.md`)へ回す。**回す先を持っていることも含めて窓口**である。

## 人物像

頑固で無愛想だが、仕事には誠実。口は悪いが、武器を粗末に扱う者や、自分の力量を見誤って過剰な武器を欲しがる者には容赦なく説教する。

一方で、武器を大切に扱う冒険者や、素材の性質を理解しようとする者には面倒見がいい。

## 口調

無愛想で言い切る職人の話し方。一人称は「俺」。**語尾を伸ばさず、用が済んだら黙る。** 返事は「おう」「ああ」で足りる。

- 普段は必要最小限。だが説教になると一気に長くなる:「その腕でこいつを振る気か。重さに振り回されて死ぬぞ」。
- 口は悪いが罵倒ではなく、危ないことを危ないと言っているだけ。
- 武器を大事に扱う相手には言葉が自然と丁寧になるが、本人は気づいていない。
- 褒め言葉は物に向けて言う。「いい鋼だ」で、持ち主を褒めたことにしている。

例:
- ガルム「おう。三日後に来い」
- ガルム「これは直せる。こっちは無理だ。無理なもんは無理だ」
- ガルム「……いい鋼だ。手入れしてやがるな」

## 能力傾向

戦闘者としては一線級ではないが、鍛冶師としてのDEXは非常に高い。金属加工、刃の調整、重量配分、柄の握り、使用者の癖に合わせた微調整に優れる。

魔法鍛冶そのものは専門外だが、魔石や魔物素材の扱いには一定の理解がある。

## スキル

- ◇ 高等級鍛冶士　Lv8(金属加工・刃の調整・重量配分に卓越した最上級の鍛冶の腕。実戦で壊れにくい武器を打つ。DEX:A)
- ◇ 武具整備　Lv4(武器の修理・研ぎ・調整。壊れにくく直しやすい仕上げ)
- ◇ 素材鑑定　Lv2(魔物素材・鉱石・木材の質と性質を見極める。INT:B)
- ◇ 使い手合わせ　Lv2(使用者の膂力・握り・癖に合わせた微調整)
- ◇ 魔物素材加工　Lv2(魔石・魔物素材を武具へ組み込む扱い。魔法鍛冶そのものは専門外)

スキルLv合計：18(Lv36の半分と一致)

## 工房：フォージライト工房

**職人の通りに面した鍛冶工房**で、南区の防火・防爆設計区域にあたる一角を占めている。**炉が大きいぶん場所も取る**ので、通りの中でも建物が離して建てられている側にある。少し先に《サン小物店》から始まるハイドウェルの三軒が並んでいる(`characters/npcs/67_ichika_hidewell.md`)。

炉、金床、素材倉庫、試し斬り用の裏庭、騎士団装備用の保管棚を備えている。

火災対策には厳しく、炉の周囲には耐火壁、消火砂、水槽、排熱溝が整備されている。職人組合の安全規則を守らない客は即座に追い出される。

### 弟子が数人いる(無名)

**この工房は一人では回っていない。** 名の出ない弟子が数人おり、ふいご、研ぎ、下ごしらえ、荷運び、棚の量産品、簡単な修理まではこの者たちの仕事である。**ガルム自身が槌を握るのは、注文品と騎士団の仕事、それと持ち込み素材の見立て。**

**ハイドウェルの三軒とはここが決定的に違う。** 三姉妹は弟子も雇い人もいない一人親方で、扱う物を絞ることで回している。**ガルムは人を入れることで間口を広げている。** 騎士団と冒険者ギルドの両方へ納めながら、農具や鍋の修理まで受けられるのはそのためである。

弟子への当たりは客より厳しい。**危ない手つきを見た時だけは怒鳴る**が、それ以外は黙って手元を見ている。**褒める時は物に向けて言う**ので、弟子の側は自分が褒められたのかどうか毎回分からない。

素材の主な仕入れ先は、赤牙森林の赤根木材・灰岩峡谷の灰岩鉱など周辺危険地域産の木材・鉱石(`world/crossroad/11_crossroad_city.md`の「危険地域産の素材と買い取り」)。冒険者が持ち込む素材の質が、そのまま工房の在庫の質に直結する。

赤根柄の武器、灰岩鋼武器など、フォージライト工房が仕入れた素材を実際にどんな商品へ加工しているかは`world/crossroad/42_crossroad_artisan_goods.md`を参照。

## 納期と、断る仕事

| 用件 | いつ上がるか |
|---|---|
| 棚の量産品 | その場で持って帰れる |
| 研ぎ・軽い修理 | 弟子が回すので当日〜翌日 |
| 普通の修理 | **三日**(「三日後に来い」) |
| 持ち込み鍛造・注文品 | 素材が揃っていて十日前後 |
| 騎士団のまとまった整備 | 先に期日を切り、その間は新しい注文を止める |

断るのは次の四つ。**断り方は毎回同じで、理由を一つ言って終わる。**

- **持ち主の腕に合わない武器**——説教になる
- **安全規則を守らない客**——工房から追い出す
- **出所の分からない素材**——浄化院の検査印が無い黒鉄など(`world/crossroad/42_crossroad_artisan_goods.md`)
- **急かされて手を抜くことになる仕事**——「無理なもんは無理だ」

## 動線(どういう時にこの人が出てくるか)

**行き先に迷ったら、まずここ。** 職人の通りで一番間口が広いので、他の店の話へ繋ぐ中継点にもなる。

| きっかけ | 何が起きるか |
|---|---|
| **武器が欠けた・折れた・鈍った** | 修理と研ぎ。**一番多い用件** |
| **最初の武器を買う** | 無銘の量産品(剣撃Lv2、5,000G〜。`world/crossroad/42_crossroad_artisan_goods.md`) |
| **素材を持ち帰った** | 持ち込み鍛造。**素材の質がそのまま出来に出る**ので、鑑定の場面になる |
| **身の丈に合わない武器を欲しがる** | **説教が始まる。** 「その腕でこいつを振る気か」——止めているだけで罵倒ではない |
| **武器と関係ない金物が要る** | 農具、蝶番、錠前、鍋、荷馬車の金具。**冒険と無関係な依頼でも成立する** |
| **騎士団の装備整備** | 騎士団との接点。**納期と安全規則は相手が騎士団でも譲らない** |
| **手に負えない品** | 機構物はセレナ、複雑すぎる物は琥珀へ回す。**回し先を持っている** |
| **防具・矢・小物が要ると分かった** | ハイドウェルの三軒へ送り出す。**通りの案内役になる** |

**弟子が数人いるので、ガルム本人が出てこない場面も作れる。** 修理の受け取りや棚の買い物は弟子が相手をし、**奥の炉から怒鳴り声だけが聞こえている**、という描き方ができる。

## 行動方針

「武器は持ち主の命を預かる道具だ。飾りじゃねえ。」

見た目の派手さより、実用性、耐久性、修理しやすさ、使用者との相性を重視する。強い武器を作るよりも、「その人間がちゃんと扱える武器」を作ることを大切にしている。

## 日常

**行きつけ**：仕事終わりは南区の職人酒場《赤釘亭》。**壁の古い釘の一本は若い頃の自分が打ったと言うが、真偽は定かでない。** 素材の話が長引く日は東区との境の茶屋《芽吹き棚》へ流れる。北区へ鋼を仕入れに出た帰りは《旅籠前茶屋・一服》。**大物の武具を納めた祝いだけ、やや高級《五つの地平》へ行く。**(`world/crossroad/49_crossroad_dining.md`)。

仕事終わりは南区の職人酒場「赤釘亭」に立ち寄るのが習慣。壁に打ち込まれた古い釘の一本は、若い頃のガルム自身が打ったものだと本人は語るが、真偽は定かでない。
