# 織部(おりべ)

> **TL;DR:** 東区の学校の教師・織部。全身を白い霊布で巻いて壁と天井を這う、街の面白名物。昔どこかの小国で退魔師をしていた。布を操る一本だけで積み上げた対策が、そのまま生徒への教材になっている。

- 種族：人間
- 年齢：40歳　　性別：男性
- レベル：40【上限】(冒険者ランク基準ではCランク相当。`world/14_adventurers_guild.md`)
- 所属：クロスロード東区・学校
- 配置：クロスロード東区(`world/crossroad/20_crossroad_city_districts.md`)
- 立場：教師(読み書き・計算・街の規則・生活で使う程度の魔力の扱い)
- 通り名：布ゴキブリの織部

◆役割
東区の学校の教師／元・退魔師

『合理的ですので。それ以外の理由はありません』

## 外見

一目で分かる。全身に大量の白い布を巻いていて、顔も手も出ていない。布は常に蠢いていて、周りに極細の糸が漂っている。

人型に見えない。腕の位置も、どちらを向いているかも分からない。一箇所に長く留まらず、急に動いて急に止まる。壁や天井にいることが多い。

布の中で、本体の体は一切動いていない。動いているのは布だけである。

布を解けば、痩せた普通の中年男が出てくる。素顔を見た者はそこそこいるが、見ても天井のあれとは結び付かない。

## スキル

- ◇ 布ゴキブリ　Lv6(身体中に大量の布を巻き、カサカサと不規則で変則的に移動する。翻弄し、逃げる)
- ◇ 霊布操作　Lv4(捕縛。包んで動きと能力行使を止める。数十メートル先の布で戸を開ける遠隔操作も)
- ◇ 極細霊糸接触索敵　Lv4(布から分離した極細の糸を空間へ漂わせる接触感知。通称「イソギンチャク」)
- ◇ 特殊条件看破対応　Lv3(相手が何を条件に動いているかを読み、外す。屁理屈と口八丁を含む)
- ◇ 高位退魔技術　Lv3(組織で習った正式な技術。浄化・封印・鎮魂)

スキルLv合計：20(Lv40の半分と一致)

## コア特性：布を操る一本だけで積み上げた対策

**織部の能力は「布を操る」一つしかない。** 以下は全部その上に積み上げた対策であり、**一つ一つがそのまま生徒への教材になっている。**

### 動きから

| | |
|---|---|
| 狙撃・予測射撃・単体攻撃が通らない | 不規則な三次元移動 |
| 普段しない角度の攻撃を強要される | 天井・壁にいる。慣れない動きは精度が落ちる |
| 注意力が散る | 微細フェイントの連続 |
| 罠や条件が成立しない | 人がしない経路と動き |

### 形と持ち物から

| | |
|---|---|
| 人間と判定されにくい | 人型のシルエットが崩れている。人を対象に絞った術式・呪い・罠・索敵の条件から外れる |
| まず観察を選ばされる | 敵とも味方とも判別できない。初手が丸ごと遅れる |
| 弱点も中心点も見つからない | 上下左右が判別できない布の塊 |
| 意図が読めない | 顔も向きも出ていない |
| 即時敵対化されにくい | 武器を持たない。縄張りの奥へ入っても排除から始まらない |

### 本体が動いていないことから

| | |
|---|---|
| 金縛り・麻痺が無意味 | 止められて困る体を、そもそも使っていない |
| 糸へ集中を全部回せる | 四肢の処理が要らない |

### 目を使わないことから

| | |
|---|---|
| 幻覚が効かない | 見ていない |
| 視線を条件にするものが成立しない | 同上 |
| 暗所と夜が関係ない | 明るさが判定に入らない |

### 糸から

| | |
|---|---|
| 相手の次が読める | 微細な動きを感知して先読みする |
| 見えない位置の敵が分かる | 大量の糸が空気の流れを拾う |
| ステルスが通らない | 四方八方に糸が漂っている。隠れていても触れれば分かる |
| 迷い系が無意味 | 垂らした糸で経路が確定している |
| 三次元の地図が頭に出る | 上空から俯瞰したような形で。本人は慣れだと説明する |

**繋がっている糸だけが効く。ちぎれたら、そこから先は何も分からない。** ただし糸は細すぎて、そこにあると気づかれること自体が稀である。

なお糸を切っても本体には近づけない。情報が減るだけで狙う所は増えず、情報が減った織部は逃げる。

### 布で触れる・巻くことから

| | |
|---|---|
| 接触発動系が空振りする | 触れているのは布。相当離れた位置から布だけを届かせる |
| 掴まれても掴まれていない | 掴んだのは外層。切り離して抜ける |
| 汚染・侵食・毒が本体へ届かない | まず布に作用する |
| 異常探知 | 布の表面が先に喰らうので、そこで気づく。目に見えない汚染も分かる |
| 体温が誤魔化される | 大量の布に覆われている |
| 毒・瘴気・ガスを濾す | 布越しに呼吸している |
| 憑依返し | 常に内側にいるので、入られた時点で相手が浄化術式の中にいる |

### 効かない相手

開けた平地、広範囲の大火力、精神干渉、条件を持たない相手。**そして倒す手段は一つもない。**

## プロフィール

東区の学校の教師。読み書き、計算、街の規則、生活で使う程度の魔力の扱いを教えている。

昔、東のどこかの小国で退魔師をしていた。国名も組織名も本人が言わない。役所の一部署で、課員は全員ほかの職と兼任だったという形だけが分かっている。**レベルキャップに到達したので辞めた。** `rules/00_level_system.md`のとおりキャップ到達者はそこが完成形なので、現場に居続ける理由が無くなった、というだけである。暗い話は一つも無い。

ヘンテコな教師として有名で、生徒に親しまれている。授業で昔の話を笑い話や教訓として聞かせる。たいてい「なんでそれで生き残ったんですか」と聞かれる話になる。

条件が全部積み重なった場所の話をすることがある。見たら死ぬものが歩き、触れたら終わるものが生え、館そのものが敵の腹の中で、廊下が繋がっておらず、時間も当てにならず、踏めば帰れない条件が至る所にあり、魂を取り込むものがいる——そういう場所である。Lv50や60が束で入っても死ぬ。織部は中心を探り当てて踏破した。倒したものは一つもない。

## 何を教えているか

読み書き、計算、街の規則、生活で使う程度の魔力の扱い。教える中身は他の教師と変わらない。

変わっているのは、何を聞かれても同じ物差しで答えるところである。**相手が何を条件に動いているかを見る**、という一つのやり方を、話題を問わず当てはめる。

友達が急に怒った。約束が食い違った。店で言われた値段が違う。規則が理不尽に思える。——どれも、相手の条件が見えると形が変わる。こちらが相手に反応して動くと大概ろくなことにならない、関心を示さないでいる方が案外こじれない、という話もここに入る。

できることとできないことを見極めて、これはやらないと決めるのも教える。万事には対応できないし、金にも限りがある。織部自身は精神防御をやらないと決めている。独自の防御が要る割に使う相手が少なく、無駄に高価で、しかも使う相手はそれを遥かに上回る出力を持っているためである。

一つに絞ると、案外新しい使い道が見つかる。全属性を扱える者が全部を雑に使うだけだったのに対し、雷だけに絞った者が電磁の障壁から脳波の読み取りまで到達した例がある。

魔物や霊障の話も同じ枠に入っている。**子供が聞きたがるので出てくる回数が多いだけで、主眼ではない。** 昔の話は、その物差しが極端な場所でも通ったことの実例として使われる。

## 装備

**霊布。** 浄化院の販売窓口で売っているものを買っている(`world/crossroad/30_crossroad_purification_institute.md`)。特注品でも遺物でもない。使えるものは洗って使い回し、無理なものだけ捨てる。

布の内側に弁当や道具を入れている。**これは能力ではなく、ただ内側に入れているだけ**である。かさばる物は入らないし、入れれば動きに出る。食べる前に浄化するのが基本で、毒があると危ない。

毒は自分では作らない。既存のものを買う。知識はそこまでない。

## パペッターコア

下水道のガラクタの山にある人形(`world/crossroad/76_artifacts.md`)を扱える、街で数少ない一人。

**一目見れば操作方法が看破できる。** 由来も内部構造も分からないまま動かせる。琥珀が解析して分かったうえで動かすのに対し、**織部は分からないまま動かす。**

起動には大量の糸を同時に、それぞれ別々へ通す技が要る。DEX:Sの天雷・セレスティナ・カスミは器用さの向きが違い、糸の技を持つ真白はDEX:Aで届かない。**両方を満たしているのが織部である。**

## 口調

**ですます。理路整然としている。** 一人称は「私」。要点と根拠を順に並べ、余計な感情が乗らない。

**天井に張り付いた布の塊が、書類を読み上げるような丁寧語で喋る。** 見た目と言葉遣いが噛み合っていない。

- 必ず理由が後ろに付く。「〜します。〜ですので」。詰められると理由が長くなる。短くはならない
- 誰に対しても同じ言い方をする。教壇でも、領主相手でも、妖怪相手でも変えない
- 声を荒らげたところを誰も見たことがない
- 見た目を指摘されると返事が毎回同じ。「これが一番死にません」
- 布ゴキブリと呼ばれても「そうですね」で終わる。否定しない

例:
- 織部「合理的ですので。それ以外の理由はありません」
- 織部「これが一番死にません」
- 織部「今のは霊布に触れました。私にではありません」

## 日常

**行きつけ**：東区の茶屋《ひだまり縁側》(`world/crossroad/49_crossroad_dining.md`)。放課後に隅で茶を一杯だけ飲んで帰る。

授業が終われば普通に街を歩く。買い物もするし、井戸端も通る。**布のまま市場で野菜を選び、布のまま値段を聞く。** 東区の店はもう慣れていて誰も何も言わない。

住まいは東区の長屋の一室。休みの日は布の手入れをしている。洗い、干し、繋ぎ直し、数え直す。

## 街や組織での立場

**街の面白名物として、ちょっと有名。** 白い布の塊が学校の天井を這っている、という一点で通じる。

怖がられてはいない。面白がられている。クロスロードにはカマイタチの外科医も雷獣の街娼も木に住む妖精もいるので、人に見えないものが歩いていること自体が珍しくない。

驚くのは外から来た冒険者だけで、「東区に妖怪が出た」という通報は時々ある。そのたびに「あれは学校の先生だ」と説明されて終わる。

**実力を知っている者はほとんどいない。** 本人が昔の話を笑い話としてしか出さないので、聞いた側も笑い話として受け取っている。**面白い先生**で止まっている。

## ララとカーラ

二人の師匠筋にあたる。**魔法そのものは教えられないが、戦闘のイロハを教えている。** 魔法の先は琥珀と術師会、剣は銀雪、現場への足は小夜——その中で、**どう見て、どう逃げて、何をやらないかを教えているのが織部**である。

**抜け道も含めて教えた。** 世の中が綺麗事で回らないことを教えるのも教師である。ララがギルドの受注制限を出し抜いている手口(`characters/npcs/27_lara.md`「東区での立場」)も、元はここから出ている。

ララには「**卒業までに一発でも不意打ちの罠を成立させてみろ**」と言ってある。ララはそれを本気で受け取っており、年単位の宿題になっている。

## 扱いの注意(GM運用)

**強いキャラとして動かさない。** ATK:E・HP:E・DEF:Eで、**倒す力は無い。** 見せ場は勝つ場面ではなく、終わらない場面である。

- **上の二十五項目は「教材の在庫」であって、授業の中身そのものではない。** 普段教えているのは読み書きと計算と街の規則で、魔物の話は子供が聞きたがるので出てくる回数が多いだけ
- **特殊条件看破対応は万能ではない。** 条件を持たない相手には丸ごと死ぬ。ここを甘くすると壊れる
- **条件を外す時は、その場で条件をでっち上げない。** 先に「それがどういう条件で起きるか」を場面へ出してから外す
- **もう現役ではない。** 頼まれれば動くが、自分から仕事を探しに行かない
- **見た目と喋り方のギャップを毎回使う。** 天井の布の塊が、丁寧語で理路整然と喋る
