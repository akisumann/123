# ロックウェル冒険者ギルド支部

> **TL;DR:** 冒険者ギルドのロックウェル支部。職員5〜6人・登録200人で分布は壺型、A級はいない。深層の依頼は出さずクロスロードへ送る。

街規模なので支部にあたる(出張受付所は村・小集落向け。`world/14_adventurers_guild.md`)。規模は小さい。

- 職員5〜6人(支部長1、受付2〜3、鑑定・買い取り1〜2)。登録冒険者約200人(定住の約3%)
- 業務は一通り——登録、カード管理、依頼受付、報酬支払い、素材買い取り、地域情報、宿・店の紹介

## 運用

| | |
|---|---|
| 深層依頼 | **掲示しない。持ち込まれてもクロスロード支部へ送る。** B級最上位でも深層の下端に並ぶだけで、後詰めを呼べる先が街道の何日も先にしかない。担当は中層まで |
| 査定 | **現地の裁量で通す。** 街道の往復に日数がかかり、本部の裁定を待つ間に事情が変わる |
| 買い取り | **魔物素材とダンジョン産の肉。** 鉱石・金属は鉱山方→選鉱・精錬→荷方へ流れる(`09`)。浅層の肉は日々持ち込まれ駆け出しの日銭になる。捨石丘陵の拾い物は安価。雷鳴山地の素材は職人との直取引もある |
| 掲示 | 捨石丘陵、雷鳴山地、坑道の浅層・中層(`08`)、山と道の現況、達成報告と報酬 |

依頼票を`world/crossroad/`へ書き足さない。支部長と職員は未設定(`01`)。
