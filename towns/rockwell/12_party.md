## 一党の性格

| | |
|---|---|
| 人数 | 4人 |
| ランク | **B帯(Lv41〜50)。** 支部にA級はいないので、**この4人が町の最高戦力**(`07`) |
| 組み方 | **半分固定くらいの一党。** 普段は連れ立ち、仕事によって組み合わせが変わる |
| 受け方 | **なんでも屋。** 捨石丘陵から大モグラ坑道の中層まで、出た依頼を順に受ける |
| 仕上がり | **チームとして組み上がっている**(構成が定石通りかは未定) |

**深層(Lv50〜60)には届かない。** B級最上位でも下端に並ぶだけで、奥のLv60帯には手が出ない(`07`)。**町で一番強い連中が、町の一番深い所へ行けない。**

`rules/03_combat_system.md`——**4人は通常戦闘にちょうどよく、同水準の敵との継続戦闘には足りない**(6人が要る)。湧き場の依頼が出た時、この一党だけでは数字が足りない。

## メンバー

### 1人目(名前未定)

- **女性**
- **ヤニカス**(喫煙者。切らせない)
- **パンクなファッション**
- **ガトリング持ち**

**ガトリングは火薬式。着火は常に咥えているタバコの火で、火種を切らさない。** ヤニカスであることが、そのまま武器の運用条件になっている。

火器はこの世界に既にある——水城の`水の長銃`(`characters/npcs/31_mizushiro.md`)、白峰の治癒砲(通り名が「回復大砲の白峰」)、南区の最終兵器の巨大砲(`characters/npcs/30_ultimate_patchwork_iron_kun.md`)、アクア・フロウ連合の水膜武装(`world/nations/25_aqua_flow_union.md`)。**火薬で撃つ機械はこれが最初になる。**

**坑内で火薬を使うのは本来まずい**(ガスと粉塵)。大モグラ坑道の中層で撃てるかどうかは、その場の判断になる。
