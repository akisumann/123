# ロックウェルの冒険者一党(チーム名未定)

> **TL;DR:** 作成中。ロックウェル唯一の冒険者一党(チーム名未定)。B帯4人で町の最高戦力だが深層には届かない。半分固定のなんでも屋。1人目は「煙草弾のニコレット」(Lv47・人間・ヤニカスのガトリング使い。タバコ火空気精査Lv9)。2人目はウサギの獣人の女性(Lv48・29歳)で近接カチ割り火力担当で、武器は「ガンハンマー」(元は大型木槌。先はリボルバー内蔵のハンマー)。リボルバー形式でデカい弾丸が6発入り、背中にも同じ弾丸を背負っている。振って叩きつけると本体が止まり、慣性で抜けた弾丸が対象へ食い込んで割る。一振りで一発減り、6発で撃ち切って背中から詰め替える。残り2人は未設定。

## 一党の性格

| | |
|---|---|
| 人数 | 4人 |
| ランク | **B帯(Lv41〜50)。** 支部にA級はいないので、**この4人が町の最高戦力**(`07`) |
| 組み方 | **半分固定くらいの一党。** 普段は連れ立ち、仕事によって組み合わせが変わる |
| 受け方 | **なんでも屋。** 捨石丘陵から大モグラ坑道の中層まで、出た依頼を順に受ける |
| 仕上がり | **チームとして組み上がっている**(構成が定石通りかは未定) |

**深層(Lv50〜60)には届かない。** B級最上位でも下端に並ぶだけで、奥のLv60帯には手が出ない(`07`)。**町で一番強い連中が、町の一番深い所へ行けない。**

`rules/03_combat_system.md`——**4人は通常戦闘にちょうどよく、同水準の敵との継続戦闘には足りない**(6人が要る)。湧き場の依頼が出た時、この一党だけでは数字が足りない。

### 2人目

**作成中。ユーザーが決めたのは以下だけ。**

- レベル：**48**(冒険者ランク基準ではBランク相当。`world/14_adventurers_guild.md`)——ユーザー指定「40後半のどこか」を1d4で振った
- 種族：**ウサギの獣人**　　性別：**女性**　　年齢：**29歳**(「好きなように」の指定によりAI裁量。差し替え可)
- 役割：**近接カチ割り火力担当**——一党の前で殴って通す枠
- 武器：**ガンハンマー**
  - **リボルバー形式。デカい弾丸が6発入っている**
  - **背中にも同じ弾丸をいくつも背負っている**
  - **弾丸は硬いものをかち割るためのもの。** 撃ち出して遠くを狙う弾ではなく、**当てた硬い物を割りにいく弾**

**元は大型木槌だったものを、今回この形にした。** 大きく振る槌という輪郭はそのままで、**先はリボルバー内蔵のハンマー。**

**使い方**

**振って、硬い物へ叩きつける。当たった瞬間に本体が止まり、中の弾丸だけが慣性で前へ抜け出て、対象へ食い込んで割る。** 打撃が割るのではなく、**打撃で押し出された弾丸が割る。**

**一度振れば一発減る。6発で撃ち切り、背中から詰め替える。**

**決めること**

- 名前・性別・年齢・ステータス・スキル・通り名・性格・口調
- ニコレット(土魔法で弾と火薬を作る)との関係。**弾を作る者と、弾を叩き出す者が同じ一党にいる**

**役割が二つ埋まった。** ニコレットが**面で押さえる射撃**(`弾幕射撃Lv5`)、2人目が**近接の火力**。**残り2人で、斥候と治療役を入れて定石にするか、外して別の形にするかが決まる**(銀鴉の羽根と被らせるかどうかは上記「既存の一党との差」)。
