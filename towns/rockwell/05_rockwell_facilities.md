# ロックウェルの施設と組織

> **TL;DR:** 鉱山はクロスロード領主家(クラリス)の持ち物で、町は代官が回している。組織は代官所・鉱山方・荷方・神殿の四つ、施設は治療院・水場・墓地。治療院では回復魔法を扱う。コロッセオ・カジノ・劇場・娼館・浄化院・商業組合・黒針会に相当する物は無い。

町の作り(どこに何があるか)は`towns/rockwell/02_rockwell_town.md`。ここは**誰が回しているか**を扱う。

## 鉱山は領主家の物である

**採掘権はクロスロード領主家が持っている**(領主クラリス、`characters/npcs/01_clarisse_weissfeld.md`)。ロックウェルは峡谷の向こうにあるが、**領は都市の城壁で終わらない。** 町ごと領主家の管轄下にある。

- **クラリスが直接見に来ることはまず無い。** 峡谷を越える距離があり、彼女の時間は都市の五区画で埋まっている。**この町は報告書の上にある**
- **報告は荷の便に乗る**(`towns/rockwell/02_rockwell_town.md`)。**急ぎでも数日遅れる**のが前提で、だから現場の裁量が広い
- **街道はヴァレリアの管轄にあたる**(街道と都市外の防衛、`world/crossroad/11_crossroad_city.md`)。鉱石を積んだ荷が峡谷を越える以上、この道が止まることは領主家にとって収入が止まることでもある

**クラリスの統治方針「街道を止めない。商いを腐らせない。住民を飢えさせない。」が、この町では三つとも同じ一本の道の話になる。**

## 組織は四つ

| 組織 | 何を持っているか |
|---|---|
| **代官所** | **町の統治。** 領主家から派遣された代官が長。税、戸籍、揉め事の最終決着、鉱山の帳簿。**衛兵もここの下に付く** |
| **鉱山方** | **坑の現場。** 代官所の下に置かれた現場責任者と、その配下。掘る場所の割り振り、支柱と換気の判断、**賃金と順番の裁定** |
| **荷方** | **峡谷を越える荷。** 鉱石と精錬した金属を出し、飯・道具・木炭を入れる。親方が束ねる。**町の生命線がここ一本にかかっている** |
| **神殿** | **大地龍を祀る小さな神殿**(`world/dragons/37_earth_dragon.md`)。国の教会組織が担う治癒・福祉・弔い・読み書きを、この町ではここが一手に引き受ける(`world/nations/15_central_haven_kingdom.md`) |

**冒険者ギルド支部**(`towns/rockwell/07_rockwell_guild.md`)は町の四組織とは別系統である。ギルドは国家直属ではない独立組織なので(`world/14_adventurers_guild.md`)、代官所の下には付かない。

### 揉め事は鉱山方で終わる

**町で一番多い揉め事は賃金と順番の話である**(`towns/rockwell/02_rockwell_town.md`)。どの切羽を誰が掘るかで出る量が変わるので、割り振りがそのまま稼ぎの差になる。

- **大半は鉱山方の裁定で終わる。** 代官所まで上がるのは、額が大きい時か、怪我人が絡んだ時だけ
- **代官所を通り越して領主家へ訴えることは、できるが割に合わない。** 峡谷の向こうへ人を出して、返事が来るまで待つことになる

## 施設は三つ

| 施設 | |
|---|---|
| **治療院** | 神殿に併設。**怪我人が日常にいる町なので、これが無いと町が成り立たない** |
| **水場** | 山の斜面から引いた水。**飲む分と精錬に使う分の両方**が要る。坂の上手で精錬所が先に取るので、**下手の住まいは細い** |
| **墓地** | 町の外れ。**落盤で人は死ぬ。** 弔いは神殿が出る |

### 治療院

**怪我人が日常にいる町なので、治療院は毎日動いている。**

- **回復魔法を扱う者がいる。** 神殿が担う治癒(`world/nations/15_central_haven_kingdom.md`)と、鉱山を持つ町として要る分の両方で、**坑から担ぎ込まれた怪我をその日のうちに診る**
- **手当ての本体は止血・洗浄・縫合・骨接ぎ・寝かせること**で、そこへ回復魔法が乗る
- **怪我明けにはダンジョン産の肉が回される**(`towns/rockwell/04_rockwell_mogura_tunnel.md`)。効くのは町の共通認識である

## 無い物

**六千人の町なので、都市の設備は揃わない。** 以下に相当する物は**置かない**。

- コロッセオ、カジノ、大劇場、娼館、大衆浴場
- 浄化院(穢れ・呪い・アンデッド絡みは神殿が手に負えず、クロスロードへ回す)
- 商業組合、鍛冶師組合
- 黒針会に相当する裏の組織——**峡谷が間にあるので、そもそも裏稼業が食える人数がいない**
- 学校。読み書きは神殿が教える程度で、`world/crossroad/78_east_district_school.md`のような建物は無い

## GM運用

- **町の話は代官所と鉱山方で完結させる。** クラリスやヴァレリアを毎回出さない。**峡谷の向こうは遠い**(`towns/rockwell/01_rockwell.md`)
- **領主家が出てくるのは、道が止まった時と、帳簿が合わない時だけ**でよい
- **鉱山方の長はガレス・ドルン**(`towns/rockwell/06_gareth_dorn.md`)。**代官・荷方の親方・司祭に名前は付けていない**ので、必要になった時に決める(`towns/rockwell/01_rockwell.md`「まだ決めていないこと」)
