# ロックウェルの施設と組織

> **TL;DR:** ロックウェルの組織と施設。鉱山はクロスロード領主家の物で、町は代官が回している。組織は代官所・鉱山方・荷方・神殿の四つ。

町の作り(どこに何があるか)は`towns/rockwell/02_rockwell_town.md`、設備そのものは`towns/rockwell/09_rockwell_works.md`。ここは**誰が回しているか**を扱う。

## 鉱山は領主家の物である

採掘権はクロスロード領主家が持っている(領主クラリス、`characters/npcs/01_clarisse_weissfeld.md`)。ロックウェルは街道を南へ下りきった所にあるが、**領は都市の城壁で終わらない。** 町ごと領主家の管轄下にある。

クラリスがこの町を直接見に来ることはまず無く、彼女の時間は都市の五区画で埋まっている。**この町は報告書の上にある。** 報告は荷の便に乗って数日遅れるので、そのぶん現場の裁量が広い(`towns/rockwell/01_rockwell.md`)。

街道そのものはヴァレリアの管轄にあたる(街道と都市外の防衛、`world/crossroad/11_crossroad_city.md`)。鉱石を積んだ荷がこの道を通る以上、道が止まることは領主家にとって収入が止まることでもある。クラリスの統治方針「街道を止めない。商いを腐らせない。住民を飢えさせない。」が、この町では三つとも同じ一本の道の話になる。

## 組織は四つ

| 組織 | 何を持っているか |
|---|---|
| 代官所 | 町の統治。領主家から派遣された代官が長。税、戸籍、揉め事の最終決着、鉱山の帳簿。衛兵もここの下に付く |
| 鉱山方 | 坑の現場。代官所の下に置かれた現場責任者と、その配下。掘る場所の割り振り、支柱と換気の判断、賃金と順番の裁定 |
| 荷方 | 街道を行き来する荷。鉱石と精錬した金属を出し、飯・道具・木炭を入れる。親方が束ねる。**町の生命線がここ一本にかかっている** |
| 神殿 | 大地龍を祀る小さな神殿(`world/dragons/37_earth_dragon.md`)。国の教会組織が担う治癒・福祉・弔い・読み書きを、この町ではここが一手に引き受ける(`world/nations/15_central_haven_kingdom.md`) |

冒険者ギルド支部(`towns/rockwell/07_rockwell_guild.md`)は町の四組織とは別系統である。ギルドは国家直属ではない独立組織なので(`world/14_adventurers_guild.md`)、代官所の下には付かない。

### 揉め事は鉱山方で終わる

町で一番多い揉め事は賃金と順番の話である。どの切羽を誰が掘るかで出る量が変わるので、割り振りがそのまま稼ぎの差になる。

- 大半は鉱山方の裁定で終わる。代官所まで上がるのは、額が大きい時か、怪我人が絡んだ時だけ
- 坑の中では鉱山方の長の判断が最終である(`towns/rockwell/06_gareth_dorn.md`)。ただし賃金の額そのものは代官所が持つ
- 代官所を通り越して領主家へ訴えることは、できるが割に合わない。街道の先へ人を出して、返事が来るまで待つことになる

## 施設は三つ

| 施設 | |
|---|---|
| 治療院 | 神殿に併設。怪我人が日常にいる町なので、これが無いと町が成り立たない |
| 水場 | 山の斜面から引いた水。飲む分と精錬に使う分の両方が要る。**坂の上手で精錬所が先に取るので、下手の住まいへ回る分は細い** |
| 墓地 | 町の外れ。落盤で人は死ぬ。弔いは神殿が出る |

### 治療院

怪我人が日常にいる町なので、治療院は毎日動いている。手当ての本体は止血・洗浄・縫合・骨接ぎ・寝かせることで、そこへ回復魔法が乗る。

**回復魔法を扱う者がいる。** 神殿が担う治癒と、鉱山を持つ町として要る分の両方で、坑から担ぎ込まれた怪我をその日のうちに診る。ここの術者は精度が要る魔法を持っており、火力だけで選ばれる精錬所の炉番とは別物である(`towns/rockwell/09_rockwell_works.md`)。

怪我明けにはダンジョン産の肉が回される(`towns/rockwell/04_rockwell_mogura_tunnel.md`)。効くのは町の共通認識である。

## 無い物

六千人の町なので、都市の設備は揃わない。以下に相当する物は**置かない**。

- コロッセオ、カジノ、大劇場、娼館、大衆浴場
- 浄化院(穢れ・呪い・アンデッド絡みは神殿が手に負えず、クロスロードへ回す)
- 商業組合、鍛冶師組合
- 黒針会に相当する裏の組織
- 学校。読み書きは神殿が教える程度で、`world/crossroad/78_east_district_school.md`のような建物は無い

## GM運用

- **町の話は代官所と鉱山方で完結させる。** クラリスやヴァレリアを毎回出さない
- 領主家が出てくるのは、道が止まった時と、帳簿が合わない時だけでよい
- 鉱山方の長はガレス・ドルン(`towns/rockwell/06_gareth_dorn.md`)。代官・荷方の親方・司祭に名前は付けていないので、必要になった時に決める(`towns/rockwell/01_rockwell.md`「まだ決めていないこと」)
