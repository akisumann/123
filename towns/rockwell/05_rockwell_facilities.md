# ロックウェルの施設と組織

> **TL;DR:** ロックウェルの組織と施設。鉱山はクロスロード領主家の物で、運営は町が任されている。長は現地上がりの町長(ガレス)。組織は代官所(町の役所)・鉱山方・荷方・神殿の四つ。

町の作りは`02`、設備は`09`。ここは**誰が回しているか**。

## 統治

- 採掘権も町の管轄もクロスロード領主家(領主クラリス、`characters/npcs/01_clarisse_weissfeld.md`)。**領は都市の城壁で終わらない**
- 現地統治は**町長**。現地上がりの首長で、現在は**ガレス・ドルン**(`06`)。**クラリスは見に来ず、この町は報告書の上にある**
- 報告は荷の便で数日遅れるため、現場裁量が広い
- 灰岩街道など都市外の防衛はヴァレリアの管轄。**道が止まる＝領主家の収入が止まる**

## 組織

| | 役割 |
|---|---|
| 代官所 | **町の役所。長は町長**(`06`)。統治、税、戸籍、揉め事の最終決着、衛兵、鉱山帳簿 |
| 鉱山方 | 坑の現場、差配、支柱・換気、賃金と順番の裁定 |
| 荷方 | 鉱石・金属の搬出、食料・道具・坑木・炭にする木の搬入。親方が束ねる |
| 神殿 | 大地龍信仰(`world/dragons/37_earth_dragon.md`)、治癒、福祉、弔い、読み書き |

ギルド支部は独立組織なので代官所の下には付かない(`07`)。

**揉め事の大半は賃金と順番で、鉱山方の裁定で終わる。** 代官所へ上がるのは額が大きい時か怪我人が絡んだ時。坑の中では鉱山方の長の判断が最終。賃金の額は代官所が持つ。

## 施設

| | |
|---|---|
| 治療院 | 神殿併設。回復魔法、止血、洗浄、縫合、骨接ぎ。**術者は精度が要る魔法を持ち、火力で選ばれる炉番(`09`)とは別物**。怪我明けにはダンジョン産の肉 |
| 水場 | 山の斜面から取水。**精錬所が上手で先に取るため下手の住居は細い** |
| 墓地 | 町外れ。落盤で人は死ぬ。弔いは神殿 |

## 無い物

コロッセオ、カジノ、大劇場、娼館、大衆浴場、浄化院(穢れ・呪い・アンデッドはクロスロードへ回す)、商業組合、鍛冶師組合、黒針会相当の裏組織、学校。

## 進行メモ

- **町の問題は代官所と鉱山方で処理する。クラリスやヴァレリアを毎回出さない**
- 領主家が出るのは街道が止まった時と帳簿が合わない時
- 荷方の親方・司祭は未設定(`01`)
