# ロックウェルの町の作り

> **TL;DR:** ロックウェルの町の作り。坑口から街道へ下る一本の坂に沿って伸びる。飯・酒・宿は相場のまま。

坑口から灰岩街道へ下る一本の坂に沿って伸びている。上が山、下が街道。

| 位置 | あるもの |
|---|---|
| 一番上 | 坑口(稼働約12本)、巻き上げ小屋、道具番、鉱夫詰所 |
| 上手 | 選鉱場、精錬所(`09`) |
| 中ほど | 鍛冶場、木炭焼き、荷車修理場、鉱夫の住居 |
| 下手 | 宿、飯屋、酒場、市 |
| 一番下 | 荷置き場、秤、灰岩街道 |

- 朝夕は坑口側が混む。飯屋は夜明け前に開き、昼は空き、夕から夜が本番
- **炉は止まらないので煙が絶えない。煙が細い時は何かあった目印**
- 価格は`world/06_economy.md`の通常相場のまま。街道の先だからといって割高にしない
- 冒険者ギルド支部は職員5〜6人、登録約200人(`07`)
- 衛兵は少数。多いのは賃金・順番の揉め事と、荷と坂の事故。荒事は町の外
