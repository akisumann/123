# ロックウェルの町の作り

> **TL;DR:** ロックウェルの町の作り。区画ではなく坑口から街道へ下る一本の坂。飯・酒・宿は相場のまま。

区画制ではなく、坑口から灰岩街道へ下る一本の坂に沿って町が伸びる。上が山、下が街道、その間が町。

| 位置 | 主なもの |
|---|---|
| **一番上** | 坑口、巻き上げ小屋、道具番、鉱夫詰所 |
| **上手** | 選鉱場、精錬所 |
| **中ほど** | 鍛冶場、木炭焼き、荷車修理場、鉱夫の住居 |
| **下手** | 宿、飯屋、酒場、市 |
| **一番下** | 荷置き場、秤、灰岩街道 |

朝夕は坑口側が混み、夕方以降は下手の飯屋・酒場が賑わう。坑口は稼働中のものだけでおよそ12本あり、巻き上げ小屋も詰所も坑の数だけ並ぶ(`towns/rockwell/09_rockwell_works.md`)。

## 精錬所

町の心臓。選鉱と精錬を行い、運べる金属にしてから荷へ回す(設備は`towns/rockwell/09_rockwell_works.md`)。

- 炉は交代で焚き続け、止まらない
- **町のどこからでも煙が見える。煙が細い時は何かあった目印になる**

## 宿と飯屋

朝は早い。山へ上がる組が夜明け前に動くため飯屋は暗いうちから開き、昼は空き、夕から夜が本番になる。

**価格は`world/06_economy.md`の通常相場に従う。街道の先だからといって割高にしない。** 大モグラ坑道の肉が入った料理もこの帯の中で出る。

## 冒険者ギルド支部

職員5〜6人、登録冒険者およそ200人の小さな支部(`towns/rockwell/07_rockwell_guild.md`)。

## 治安

衛兵は少数。町中で多いのは賃金・順番の揉め事と、荷と坂の事故。荒事は町の外で起きる。外から人が増えた時だけ、宿と酒場の勝手が変わる。
