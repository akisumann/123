# ロックウェルの町の作り

> **TL;DR:** ロックウェルの町の作り。区画ではなく坑口から街道へ下る一本の坂で、上から坑口・選鉱場と精錬所・鍛冶場と住まい・宿と市・荷置き場。炉は止まらず煙が細ければ何かあった合図。ギルドは職員5〜6人の小さな支部。

**区画に分かれていない。** クロスロードのような五区画の構造を持つ規模ではなく、**坑口から街道へ下る一本の坂**に沿って町が伸びている。上が山、下が街道、その間が町である。

## 坂の上から下へ

| 位置 | 何があるか |
|---|---|
| **一番上(坑口側)** | 坑口、巻き上げ小屋、道具番、鉱夫の詰所。**朝と夕にここが一番混む** |
| **上手** | **選鉱場と精錬所。** 町で一番大きい建物で、一番煙い |
| **中ほど** | 鍛冶場、木炭焼き、荷車の修理場、鉱夫の住まい |
| **下手** | 宿、飯屋、酒場、市 |
| **一番下(灰岩街道側)** | 荷置き場と秤。**送り出す荷が、ここで最後に検められる** |

## 精錬所

**町の心臓。** 掘った鉱石から不要な岩を落とし、運べる形にしてから荷車へ積む。**設備の規模と仕組みは`towns/rockwell/09_rockwell_works.md`。**

- **炉は止まらない。** 一度落とすと立ち上げに日数がかかるため、交代で焚き続けている
- **町のどこからでも煙が見える。** 煙が細ければ何かあった、というのが住民の共通認識になっている

## 宿と飯屋

**数は多くない。** 行商と荷方と、たまに来る冒険者で回っている程度で、**まとまった人数が来ると簡単に埋まる。**

- **朝は早い。** 山へ上がる組が夜明け前に動くため、飯屋は暗いうちから開く
- **昼は空く。** 働き手は全員山にいる
- **夕から夜が本番。** 下りてきた鉱夫が座り込み、そのまま遅くまで居る

## 冒険者ギルド支部

**街規模なので支部が置かれている**(`world/14_adventurers_guild.md`)。**ただし職員5〜6人の小さな支部**で、登録冒険者はおよそ200人。詳しくは`towns/rockwell/07_rockwell_guild.md`。

**峡谷の向こうにあるので、クロスロード支部との行き来には日数がかかる。** 急ぎの連絡は荷の便に乗せる。

## 治安

**衛兵はいるが、数は少ない。** 揉め事の大半は賃金と順番の話で、**荒事は町の外で起きる。**

- **町の中で一番多い事故は、荷と坂である。** 転がった、挟まれた、落とした
- **外から人が増えた時だけ、勝手が変わる。** 普段いない人数が宿と酒場へ入るので、そこだけは別の話になる
