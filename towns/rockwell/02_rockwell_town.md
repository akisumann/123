# ロックウェルの町の作り

> **TL;DR:** ロックウェルの町の作り。区画ではなく坑口から街道へ下る一本の坂。飯・酒・宿は相場のまま。

区画に分かれていない。クロスロードのような五区画の構造を持つ規模ではなく、坑口から街道へ下る一本の坂に沿って町が伸びている。上が山、下が街道、その間が町である。

誰が回しているかは`towns/rockwell/05_rockwell_facilities.md`、設備の規模は`towns/rockwell/09_rockwell_works.md`。

## 坂の上から下へ

| 位置 | 何があるか |
|---|---|
| 一番上(坑口側) | 坑口、巻き上げ小屋、道具番、鉱夫の詰所。**朝と夕にここが一番混む** |
| 上手 | 選鉱場と精錬所。町で一番大きい建物で、一番煙い |
| 中ほど | 鍛冶場、木炭焼き、荷車の修理場、鉱夫の住まい |
| 下手 | 宿、飯屋、酒場、市 |
| 一番下(灰岩街道側) | 荷置き場と秤。送り出す荷が、ここで最後に検められる |

坑口は一つではなく、稼働中のものだけでおよそ12本ある。巻き上げ小屋も道具番も詰所も坑の数だけ並ぶので、坂の一番上が町で一番混む(`towns/rockwell/09_rockwell_works.md`)。

**煙は町のどこからでも見える。** 精錬所の炉は止まらないため、煙が細ければ何かあった、というのが住民の共通認識になっている。

## 宿と飯屋

朝は早い。山へ上がる組が夜明け前に動くため、飯屋は暗いうちから開く。昼は空き、夕から夜が本番になる。下りてきた鉱夫が座り込み、そのまま遅くまで居る。

**値段は普通。** 飯も酒も宿も`world/06_economy.md`の相場のままで、街道の先だからといって割高にはならない。

| | |
|---|---|
| 飯一食 | 100G前後 |
| 肉入り料理 | 200〜500G |
| 酒場での食事 | 300〜700G |
| 酒一杯 | 50〜100G |
| 安宿一泊 | 300G |
| 平均的な宿一泊 | 500G |
| 上等な宿一泊 | 1,000G〜 |

大モグラ坑道の肉が入った料理も、この帯の中で出る。日々の飯に回る出歯ネズミは安い側、オオモグラは上の側(`towns/rockwell/04_rockwell_mogura_tunnel.md`)。

## 冒険者ギルド支部

街規模なので支部が置かれている(`world/14_adventurers_guild.md`)。ただし職員5〜6人の小さな支部で、登録冒険者はおよそ200人。詳しくは`towns/rockwell/07_rockwell_guild.md`。

## 治安

衛兵はいるが数は少ない。揉め事の大半は賃金と順番の話で、これは鉱山方の裁定で終わる(`towns/rockwell/05_rockwell_facilities.md`)。荒事は町の外で起きる。

- 町の中で一番多い事故は、荷と坂である。転がった、挟まれた、落とした
- 外から人が増えた時だけ勝手が変わる。普段いない人数が宿と酒場へ入るので、そこだけは別の話になる
