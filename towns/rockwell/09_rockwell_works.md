# ロックウェルの採掘場と精錬施設

> **TL;DR:** ロックウェルの採掘場と精錬施設。普通の金属が全種類出る(魔法金属は出ない)。稼働坑口12本・炉14基・鉱業2,000人。金属精錬は溶岩系魔人達が主流で、炉は第三階位の魔法で焚く。金属はクロスロードへ一括納入。木炭は町で焼き、原料の木は南東街道から入る。

町の作りは`02`、組織は`05`。ここは**設備そのもの**。

## 産出

**鉄・銅・銀・鉛・錫。** 一つに偏らず普通の金属が揃って出る。ほかに石材。

**魔法金属は出ない。** ミスリル・アダマンタイト・ヒヒイロカネ・オリハルコンは火山帝国の産、灰岩鋼の原料は灰岩峡谷の領分(`world/crossroad/45`・`42`)。ここは峡谷とは別鉱脈。

## 採掘場

複数の坑口からなる。

- **稼働坑口およそ12本**(鉄が半数近く、残りを銅・銀・鉛・錫)。手入れ中の坑もあるため番号は12より先まで続く
- **番号がそのまま何が出るかを指す。** 町の人間は番号から主産物が分かる(ガレスの「今日は三番」)
- 坑ごとに癖が違う(硬い層、水の出る坑、支柱を組み直したばかりの坑)
- 坑内運搬は**トロッコ**。軌道の敷き直しと台車整備が坑の数だけ常に走る

## 選鉱・精錬

| | |
|---|---|
| 選鉱場 | **三棟**。①粗く割る ②篩と水で分ける ③金属ごとに仕分ける。屑石は捨石丘陵へ送られ、**丘の大きさは稼働量そのもの**(`03`) |
| 精錬所 | **炉およそ14基**——鉄7、銅3、銀2、鉛・錫2。金属ごとに専用炉、それぞれに専任の炉番。交代で手入れしつつ全体は止めない(落とすと立ち上げに日数) |

**炉の主火力は第三階位の炎への変換**(`rules/05_magic_theory.md`)。炭では届かない温度が出る。

- **炉番はMPで選ばれる。** 階位は第三階位1〜2で足りる
- 狙う・飛ばす・形を保つ必要がなく、**巨大で安定した火が一つあればいい**。精度が要る治療院の術者(`05`)とは別物
- 技術は職場で覚えるので、**炉番は炉の形をした魔法しか持っていない**

**木炭は町で焼く。原料の木は南東街道から入る**(`01`)。使い道は炉・火種・保温・鍛冶・生活用で、木炭焼きが独立した商売として成り立つ。水は山の斜面から引き、精錬所が上手で先に取る。

## 働き手——約2,000人(定住6,000のうち)

| 持ち場 | 人数 |
|---|---:|
| 採掘員(坑道に入る) | 800〜1,000 |
| 運搬 | 400〜500 |
| 選鉱・精錬 | 300〜400 |
| 坑道整備・機材・監督 | 200〜300 |

家族を数えれば町の全部がここに乗る。ほかに木炭焼き、鍛冶、水路整備、荷方。

## 納入

**精錬した金属は荷方が灰岩街道でクロスロードへ一括納入する。** 鉱山は領主家の物なので金属も領主家へ入り、**代官所の帳簿はこの納入の帳簿**。町内では鍛冶場と道具番が使う分だけ残り、金属は商いにならない。

**クロスロードの日々の鉄と銅の出所がここ。** `world/crossroad/42`の素材の流れは危険地域の特産を冒険者が採る形で、普通の金属の出所は書かれていない。**南区が丸ごと職人区画である以上、この規模の供給元は前から必要だった。**

## 進行メモ

- **稼働中の通常産業。毎回事件の舞台にしない。** 落盤や炉の事故は起きるが異変扱いしない(`rules/13_scene_and_incident.md`)
- 鉱夫はLv20〜30。能力が絡む行動は**年数で付いた腕前**として描く
- 煙は町のどこからでも見えるので、遠くから町の様子を示せる
- 坑番号を会話で使うと現場感が出る
