# 大モグラ坑道

> **TL;DR:** ロックウェル固有のダンジョン・大モグラ坑道(全25階・Lv20〜60)。四種が掘り続けるので地図が保たず、中枢のマグニファイコアで奥ほど個体が大きくなる。肉は町の食料庫。

町固有のダンジョン。生成は`world/09_dungeon_generation.md`。

| | |
|---|---|
| 階層 | 全25階。浅層1〜8=Lv20〜30／中層9〜16=Lv35〜45／深層17〜25=Lv50〜60 |
| ランク | E〜A |
| コア | **マグニファイコア**。位置と姿は決めない |
| 主 | 《底を掘る奴》(名称は仮) |

入口は人が掘った四角い坑道(試掘の放棄跡)、奥は獣が掘った丸い穴。

## 四種が掘り続けている

| 魔物 | 掘り方 | 基本種族 |
|---|---|---|
| オオミミズ | 土ごと食って進む | 魔蟲 |
| オオモグラ | ミミズを追って掘る | 魔土竜 |
| 大アリ | 隙間へ側道を増やす | 魔蟲 |
| 出歯ネズミ | 硬い層や岩混じりを歯で削る | 魔鼠 |

魔土竜・魔鼠は`world/04_monster_taxonomy.md`の一覧に無い基本種族。

- **地図が保たない**(忘れられた鉱山は記憶の問題、こちらは物理的に穴が動く)。測量依頼が繰り返し出る
- 掘削音が反響して方向が掴めない。**静かになった時が一番危ない**

## 大型化

**中枢に近いほど個体が大きくなる。深さではなく中枢からの距離で決まる**ため、浅くても中枢の真上では階に見合わない大きさが出る。大きい個体の掘った穴ほど太く、**細い横穴が逃げ場になる。**

コアを壊せば坑道は安全になるが、大きさから来ている素材の値打ちも同時に消える。**町の人間はコアを知らず、「奥ほど大きいのが出る坑道」と認識している。**

## 各層

| 層 | |
|---|---|
| 浅層 | 旧坑道が残り足場はまとも。大アリと出歯ネズミが多い。**出歯ネズミが支柱を削るため、外見が残っていても中が空の柱がある。崩落の主因** |
| 中層 | 獣の穴。丸く上下する通路。オオミミズが地中から直接出る。柔らかい所は踏み抜く |
| 深層 | 広く逃げ場が無い。四種が争い、戦闘中に別種が入る。**町の戦力では手に余る**(依頼は掲示しない。`07`) |

**《底を掘る奴》**——中枢近くを掘り続ける最大のオオモグラ。土中を移動して回り込むため壁も床も安全ではないが、ミミズが目的なので人を執拗に追わない。

## 資源

| 素材 | 用途 |
|---|---|
| オオミミズ：体液、環帯 | 薬品、接着 |
| オオモグラ：毛皮、前爪 | 前爪は掘削具の刃。町の道具屋が買う |
| 大アリ：顎、蟻酸 | 顎は小型刃物、蟻酸は精錬の下処理 |
| 出歯ネズミ：前歯 | 鑢や小刃。数が出るので安い |
| 土に混じる鉱石 | 掘る手間なしで出るが、拾えば何かと当たる |
| 四種の肉 | 下記 |

## 肉

**四種とも食用可。マグニファイコアで大きくなる影響も込みで栄養価が高く、鉱夫の食事として好まれる。**

| | |
|---|---|
| 出歯ネズミ | 最も安く最もよく食われる。日々の飯 |
| オオミミズ | 下処理すれば量が取れる |
| 大アリ | 扱いやすい |
| オオモグラ | 最も旨い。祝いや振る舞い |
| 深層産 | 数が出ず高級品。祝いの席、怪我明け、潜行の支度 |

**普通の肉も普通に仕事になる。** 坑道の肉でないと保たないのではなく、量が取れて効きがいいから選ばれている。浅層の狩りは持ち込めば買い取られる常設の稼ぎ口で、この町で最も数の多い仕事。
