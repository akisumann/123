# ロックウェルの危険地域

> **TL;DR:** ロックウェル固有の危険地域。捨石丘陵(Lv10〜20・屑石の人工丘・駆け出しの出発点)と雷鳴山地(Lv25〜35・金属を持つと狙われる)。

町固有の二箇所。どちらも町の先にあり、クロスロードとは共有しない(灰岩峡谷・忘れられた鉱山の本体は`world/crossroad/`)。生成は`world/08_danger_zone_generation.md`、依頼例は`08`。

## ① 捨石丘陵

| | |
|---|---|
| 推奨 | Lv10〜20／F〜E |
| 地形 | 採掘屑を積み上げた人工丘陵。**今も掘るたびに成長中**(`09`) |
| 資源 | 見落とし鉱石、割れた結晶片、鉄錆、草 |
| 主 | 《崩し》——斜面をわざと崩して獲物を埋めるコボルトの頭 |

| 魔物 | |
|---|---|
| 屑石コボルト | 群れ。斜面を崩して埋める |
| 鉄錆スライム | 溜め込んだ錆で刃と鎧を傷める |
| 隙間蟲 | 石の隙間に巣。手足を入れると刺される |
| 石喰い甲虫 | 質の落ちた鉱石を腹に溜める。害は薄く腹の石が売れる |

**足場が最大の危険で、戦闘より先に地面が敵になる。** 町の駆け出しが最初に行く場所(さざめき平原は街道を何日も戻った先)。捨石は町の廃棄物なので拾い物に持ち主はいないが、実入りは小さい。

## ② 雷鳴山地

| | |
|---|---|
| 推奨 | Lv25〜35／D〜C |
| 地形 | 尾根の鉱脈そのものが帯電。天候に関わらず落雷が絶えない |
| 資源 | 帯電鉱石、避雷素材、雷に灼かれた石 |
| 主 | 《棟木落とし》——尾根筋の大型獣。近づくと周囲の落雷が増える |

| 魔物 | |
|---|---|
| 雷牙の魔狼 | 群れ。帯電した毛は触れただけで痺れる |
| 鳴岩の魔鳥 | 金属を掴んで持ち去る |
| 避雷ガーゴイル | 落雷を吸う。動かない間は岩と見分けが付かない |
| 石癒えの魔熊 | 焼けた体表が岩のように固く、刃が通りにくい |

**金属を持つと狙われる。** 剣も鎧も荷も落雷を引き寄せるため、木・革・石の装備へ持ち替えるのが前提。**持ち替えるかどうかがこの山の最初の判断。** 入るのは冒険者と避雷素材を採る職人。

## 進行メモ

- 依頼票を`world/crossroad/`へ書き足さない
