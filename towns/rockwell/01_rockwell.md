# ロックウェル

> **TL;DR:** 鉱山町ロックウェル(街規模・人口6,000)の総合設定。灰岩街道を南へ下りきった所にある行き止まりの町で、遠いのは危険ではなく距離。未設定の一覧もここ。

- **規模**：街。定住人口およそ6,000人(クロスロード3.5万人のおよそ六分の一)
- **所属**：セントラル・ヘイヴン王国
- **管轄**：町の統治も鉱山の採掘権もクロスロード領主家(`towns/rockwell/05_rockwell_facilities.md`)
- **産物**：鉄・銅・銀・鉛・錫、石材、木炭。**魔法金属は出ない**(`towns/rockwell/09_rockwell_works.md`)
- **接続街道**：灰岩街道一本のみ。ほかは鉱山・坑道・山地へ向かう作業道で、町から先は他都市へ抜けない

自前の鉱脈で普通に栄えている鉱山町。鉱脈は枯れておらず、仕事は年中ある。

## 位置関係

```text
クロスロード
   │
   │ 灰岩街道(南へ伸びる主要街道・危険度 低〜中)
   │
   ├─ 脇道 → 灰岩峡谷(Lv40〜50)
   ├─ 脇道 → 忘れられた鉱山(ダンジョン)
   │
   ↓
ロックウェル
   │
   └→ 捨石丘陵 / 雷鳴山地 / 大モグラ坑道
```

**街道そのものは整備されていて比較的安全。** 灰岩峡谷も忘れられた鉱山もそれぞれ別の脇道の先にあり、街道を通るぶんには寄らない。

**遠いのは危険ではなく距離である。** クロスロードとの往来には日数がかかり、急ぎは荷の便に乗せる。ここから、現場裁量の広さ(`05`)、ギルドの自前査定とA級不在(`07`)、領主が見に来ないこと(`05`)、駆け出しがさざめき平原ではなく捨石丘陵で始めること(`03`)が出る。

灰岩街道・灰岩峡谷・忘れられた鉱山は共有地理として`world/crossroad/`側を参照する。ロックウェル固有の危険地域とダンジョンは町の先にある。

## 自前の鉱山

町の主要産業。稼働中の通常鉱山であり、危険地域でも冒険地でもない。**ここで事件を起こさないこと**(`rules/13_scene_and_incident.md`)。

- 鉱夫はLv20〜30が中心。**元々体が強くないと務まらない仕事なので入る前から篩われている。** 腕の差はレベルではなく年数で付く
- 採掘・坑道整備・運搬・選鉱・精錬まで町の仕事(`towns/rockwell/09_rockwell_works.md`)
- 屑石は捨石丘陵へ運ばれる
- 峡谷とは別の鉱脈で、別の場所にある

## 町の気風

**掘る者と運ぶ者の町。**

- 外から来た者への当たりは柔らかい。素性より続けられるかで測られる
- 金額と危険手当の話は率直
- 怪我人は珍しくない。驚かれるのは怪我よりも無理をした経緯の方
- クロスロードの話題は荷・値段・街道事情が中心

## ファイルの線引き

- ロックウェル固有の設定は`towns/rockwell/`に置く。`world/crossroad/`へは書き足さない
- クロスロード側の既存設定は参照し、重複して書かない
- 灰岩街道・灰岩峡谷・忘れられた鉱山の本体は`world/crossroad/`
- ロックウェルのNPCは`towns/rockwell/`に置く(`characters/npcs/`はクロスロードの名簿と通り名一覧に直結しているため)
- `CLAUDE.md`のGM運用ルールはこの町でも共通
