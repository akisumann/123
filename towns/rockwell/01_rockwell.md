# ロックウェル

> **TL;DR:** 灰岩街道を南へ下りきった所にある鉱山町ロックウェル(街規模・人口6,000)の総合設定。街道そのものは比較的安全で、灰岩峡谷と忘れられた鉱山はそれぞれ別の脇道の先。自前の鉱脈で普通に栄えている。街道・峡谷・忘れられた鉱山はクロスロードと共有で、町固有の危険地域は町の先にある。クロスロードとファイルを分ける線引きもここ。

灰岩街道を、クロスロードから**南へ下りきった所**にある**鉱山町。** 「集落・都市生成ルール」(`world/07_settlement_generation.md`)上の**「街」規模**にあたる。

**普通に栄えている。** 自前の鉱脈は枯れておらず、仕事は年中ある。

- **規模**：街(定住人口およそ6,000人)。**クロスロード(3.5万人)のおよそ六分の一**
- **所属**：セントラル・ヘイヴン王国(`world/nations/15_central_haven_kingdom.md`)。**鉱山の採掘権も町の統治も、クロスロード領主家の管轄下にある**(`towns/rockwell/05_rockwell_facilities.md`)
- **産物**：**鉄・銅・銀・鉛・錫の鉱石と金属**(普通の金属が全種類出る。**魔法金属は出ない**)、石材、木炭。詳しくは`towns/rockwell/09_rockwell_works.md`
- **接続街道**：**灰岩街道の一本のみ**(クロスロード方面)。ほかは鉱山・坑道・山地へ向かう作業道で、**町から先はどこへも抜けない行き止まりである**

## 位置関係

```
クロスロード(都市)
   │
   │  灰岩街道(南へ伸びる主要街道・危険度 低〜中)
   │
   ├── 脇道 →  灰岩峡谷(危険地域 Lv40〜50)
   ├── 脇道 →  忘れられた鉱山(ダンジョン)
   │
   ↓  街道はそのまま南へ
   │
ロックウェル(街)
   │
   └→ 捨石丘陵 / 雷鳴山地(危険地域) / 大モグラ坑道(ダンジョン)
```

**街道そのものは整備されていて、比較的安全である**(`world/crossroad/11_crossroad_city.md`「接続街道」)。危険は街道から分かれる脇道の先にあり、**灰岩峡谷も忘れられた鉱山も、それぞれ別の脇道へ入った所**にある。**街道を通るぶんには、どちらの脇へも寄らない。**

**遠いのは距離である。** クロスロードとの行き来には日数がかかる。

**灰岩街道・灰岩峡谷・忘れられた鉱山は、どちらの町の持ち物でもない。** 一帯の地理として`world/crossroad/`にあるものを、両方が参照する(下記「ファイルの線引き」)。

**ロックウェル自身の危険地域とダンジョンは、町の先にある**(`towns/rockwell/03_rockwell_danger_zones.md`、`towns/rockwell/04_rockwell_mogura_tunnel.md`)。

## 自前の鉱山

**町が食っている本体。** 稼働中なので危険地域ではなく、坑口・巻き上げ・選鉱・精錬までが町の仕事である。**峡谷とは別の鉱脈で、別の場所にある。**

**冒険の場所ではない。** 農家が畑へ出るのと同じで、**働く人間が毎日そこへ行っている**だけである。**鉱夫はLv20〜30がメイン。** **元々体が強くないと務まらない仕事なので、入る前から篩われている。** そのうえ坑で体を使い続けるので、数字は一般の町人より上に来る。腕の差はレベルではなく年数で付く。**ここで事件を起こさないこと**(`rules/13_scene_and_incident.md`)。

**屑石は捨石丘陵へ運ばれる**(`towns/rockwell/03_rockwell_danger_zones.md`)。あの丘が今も育っているのはそのためである。

**持ち主はクロスロード領主家で、現場は代官が回している**(`towns/rockwell/05_rockwell_facilities.md`)。**採掘場と精錬施設の規模は`towns/rockwell/09_rockwell_works.md`。**

## 町の気風

**掘る者と運ぶ者の町である。** 商人も職人もいるが、どちらも鉱山の周りに付いた商売で、話題は最後まで石と天気と道の状態に戻ってくる。

- **外から来た者への当たりは柔らかい。** 素性より、続けられるかどうかで測られる
- **金の話は率直。** 危険な仕事に危険な額が付くのが当たり前なので、値切りも上乗せも表でやる
- **怪我人が日常にいる。** 落石も崩落も現に起きているため、驚かれるのは怪我そのものではなく、**無理をした経緯の方**である
- **街道の先は遠い。** クロスロードの話題は荷と値の話が中心で、街の事情に詳しい者は多くない

## ファイルの線引き(重要)

**ロックウェルの設定は`towns/`の下にしか置かない。`world/crossroad/`へは一行も書き足さない。**

- **クロスロードの設定をこちらへ写さない。** 参照で足りる。**同じ事実を二箇所に書かない**
- **共有している場所(灰岩街道・灰岩峡谷・忘れられた鉱山)は、どちらの持ち物でもない。** 本体は`world/crossroad/`にあり、**両方がそこを参照する側**にあたる。設定をこちらへコピーしない
- **クロスロード側の既存設定を、この町の都合で書き換えない。** 南区の素材供給・依頼の流れ・荷の経路などは、既にある通りに置く
- **名前ありのNPCを作る時は`towns/rockwell/`へ置く。** `characters/npcs/`はクロスロードの名簿(`CHARACTERS.md`・`tools/make_roster.py`)と通り名一覧(`world/crossroad/44_crossroad_nicknames.md`)に直結しているので、**混ぜると町の人間がクロスロードの住人として数えられてしまう**
- **`CLAUDE.md`の運用ルール(人数・観覧モード・検索プロトコル・戦闘計算)は、この町でもそのまま適用する。** 分けるのは設定の置き場所であって、進行のやり方ではない
