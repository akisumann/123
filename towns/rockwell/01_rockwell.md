# ロックウェル

> **TL;DR:** 鉱山町ロックウェル(街規模・人口6,000)の総合設定。灰岩街道を南へ下りきった所にある行き止まりの町で、遠いのは危険ではなく距離。未設定の一覧もここ。

灰岩街道を南へ下りきった所にある鉱山町。

| | |
|---|---|
| 規模 | 街。定住約6,000人(クロスロードの約1/6) |
| 管轄 | 町・鉱山ともクロスロード領主家。現地は代官(`05`) |
| 産物 | 鉄・銅・銀・鉛・錫、石材、木炭。**魔法金属は出ない**(`09`) |
| 街道 | 灰岩街道一本。町から先は作業道のみで、他都市へ抜けない |
| 固有の危険地域 | 捨石丘陵、雷鳴山地(`03`) |
| 固有のダンジョン | 大モグラ坑道(`04`) |

## 地理

```text
クロスロード ─灰岩街道─┬─脇道→ 灰岩峡谷(Lv40〜50)
                       ├─脇道→ 忘れられた鉱山
                       └→ ロックウェル ─→ 捨石丘陵 / 雷鳴山地 / 大モグラ坑道
```

街道は整備済みで比較的安全。危険は脇道の先にある。灰岩街道・灰岩峡谷・忘れられた鉱山の本体は`world/crossroad/`。

**往来に日数がかかる。** 派生：現場裁量が広い(`05`)／ギルドは自前査定でA級不在(`07`)／領主は見に来ない(`05`)／駆け出しはさざめき平原でなく捨石丘陵(`03`)。

## 鉱山

稼働中の通常産業。危険地域でも冒険地でもない。鉱夫はLv20〜30中心(体が強くないと務まらないため入る前に篩われる)。腕の差は年数で付く。屑石は捨石丘陵へ。峡谷とは別鉱脈。**ここで事件を起こさない。**

## 気風

掘る者と運ぶ者の町。外来者に柔らかく、金額の話は率直、怪我人は珍しくない。クロスロードの話題は荷・値段・街道事情。
