# ロックウェル

> **TL;DR:** 灰岩峡谷を越えた先にある鉱山町ロックウェル(街規模・人口2,500)の総合設定。自前の鉱脈で普通に栄えている。街道・峡谷・忘れられた鉱山はクロスロードと共有で、町固有の危険地域は町の先にある。クロスロードとファイルを分ける線引きもここ。

灰岩街道を、クロスロードから灰岩峡谷を越えてさらに先へ抜けた所にある**鉱山町。** 「集落・都市生成ルール」(`world/07_settlement_generation.md`)上の**「街」規模**にあたる。

**普通に栄えている。** 自前の鉱脈は枯れておらず、仕事は年中あり、人は足りていない。

- **規模**：街(定住人口およそ2,500人)
- **所属**：セントラル・ヘイヴン王国(`world/nations/15_central_haven_kingdom.md`)
- **産物**：鉱石、石材、木炭、金属素材
- **接続街道**：灰岩街道(クロスロード方面)ほか

## 位置関係

```
クロスロード(都市)
   │  灰岩街道
   ├─ 灰岩峡谷(危険地域)
   ├─ 忘れられた鉱山(ダンジョン)
   │
ロックウェル(街)
   │
   └→ 捨石丘陵 / 雷鳴山地(この町の危険地域)
```

**クロスロードから見ると、峡谷の向こう側である。** 行き来には灰岩街道で峡谷を越える必要があり、この街道の危険度が中〜高なのはそのためでもある(`world/crossroad/11_crossroad_city.md`「接続街道」)。**荷は通るが、人は気軽に往復しない。**

**灰岩街道・灰岩峡谷・忘れられた鉱山は、どちらの町の持ち物でもない。** 一帯の地理として`world/crossroad/`にあるものを、両方が参照する(下記「ファイルの線引き」)。

**ロックウェル自身の危険地域は、町の先にある**(`towns/rockwell/03_rockwell_danger_zones.md`)。

## 自前の鉱山

**町が食っている本体。** 稼働中なので危険地域ではなく、坑口・巻き上げ・選鉱・精錬までが町の仕事である。

**峡谷とは別の鉱脈で、別の場所にある。** 峡谷の採取と混同しないこと。

## 町の気風

**掘る者と運ぶ者の町である。** 商人も職人もいるが、どちらも鉱山の周りに付いた商売で、話題は最後まで石と天気と道の状態に戻ってくる。

- **働き手が足りていないので、外から来た者への当たりは柔らかい。** 素性より、続けられるかどうかで測られる
- **金の話は率直。** 危険な仕事に危険な額が付くのが当たり前なので、値切りも上乗せも表でやる
- **怪我人が日常にいる。** 落石も崩落も現に起きているため、驚かれるのは怪我そのものではなく、**無理をした経緯の方**である
- **峡谷の向こうは遠い。** クロスロードの話題は荷と値の話が中心で、街の事情に詳しい者は多くない

## ファイルの線引き(重要)

**ロックウェルの設定は`towns/`の下にしか置かない。`world/crossroad/`へは一行も書き足さない。**

- **クロスロードの設定をこちらへ写さない。** 参照で足りる。**同じ事実を二箇所に書かない**
- **共有している場所(灰岩街道・灰岩峡谷・忘れられた鉱山)は、どちらの持ち物でもない。** 本体は`world/crossroad/`にあり、**両方がそこを参照する側**にあたる。設定をこちらへコピーしない
- **クロスロード側の既存設定を、この町の都合で書き換えない。** 南区の素材供給・依頼の流れ・荷の経路などは、既にある通りに置く
- **名前ありのNPCを作る時は`towns/rockwell/`へ置く。** `characters/npcs/`はクロスロードの名簿(`CHARACTERS.md`・`tools/make_roster.py`)と通り名一覧(`world/crossroad/44_crossroad_nicknames.md`)に直結しているので、**混ぜると町の人間がクロスロードの住人として数えられてしまう**
- **`CLAUDE.md`の運用ルール(人数・観覧モード・検索プロトコル・戦闘計算)は、この町でもそのまま適用する。** 分けるのは設定の置き場所であって、進行のやり方ではない
