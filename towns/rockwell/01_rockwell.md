# ロックウェル

> **TL;DR:** 鉱山町ロックウェル(街規模・人口6,000)の総合設定。クロスロードから2〜3日、街道は2本(金属を出す灰岩街道と、坑木・炭が入る南東街道)。鉱山は領主家の物で運営は町、首長は現地上がりの町長。名ありNPCは10人枠。

灰岩街道を南へ下りきった所にある鉱山町。

| | |
|---|---|
| 規模 | 街。定住約6,000人 |
| 距離 | クロスロードから**2〜3日**。行くと決めて行く場所 |
| 首長 | **ガレス・ドルン**——元鉱夫の現地上がり(`06`) |
| 鉱山 | **クロスロード領主家の物**。運営は町が任されている(`05`) |
| 産物 | 鉄・銅・銀・鉛・錫、石材。**魔法金属は出ない**(`09`) |
| 街道 | 2本(下記) |
| 危険地域 | 捨石丘陵、雷鳴山地(`03`) |
| ダンジョン | 大モグラ坑道(`04`) |

## 街道

```text
クロスロード ─①灰岩街道(2〜3日)─→ ロックウェル ←─②南東街道─ 自国内の森林地帯
                                       │
                                       └→ 捨石丘陵 / 雷鳴山地 / 大モグラ坑道
```

| | 何が動くか |
|---|---|
| ① 灰岩街道 | クロスロード方面。**精錬した金属を出す。** 整備済みで比較的安全。危険は脇道の先(灰岩峡谷・忘れられた鉱山は`world/crossroad/`) |
| ② 南東街道 | 自国内の森林地帯へ。**坑木と、炭にできる良木が入る。** エターナル・グローブ方面へ向かい、国境は越えない |

**炭は外から入る物である。** 炉が魔法と炭の両方を要求するため(`09`)、**この街道が止まると炉も止まる。**

**往来に日数がかかる。** そこから派生して、町の裁量が広く(`05`)、ギルドは査定を自前で通す(`07`)。

## 自前の鉱山

稼働中の通常産業。危険地域でも冒険地でもなく、**ここで事件を起こさない**(`rules/13_scene_and_incident.md`)。

- 鉱夫はLv20〜30中心。体が強くないと務まらない仕事なので入る前に篩われる。腕の差は年数で付く
- 屑石は捨石丘陵へ。峡谷とは別鉱脈
- 掘る・選鉱・精錬までが町の仕事(`09`)

## 町の作り

**坑口から街道へ下る一本の坂。** 上が山、下が街道で、その間が町(`02`)。二本の街道は**坂の一番下で合流する**——金属が出て、坑木と炭が入るのは同じ場所である。

## 線引き

固有設定は`towns/rockwell/`のみに置き、`world/crossroad/`へ書き足さない。共有地理はあちらを参照。NPCもここへ置く(`characters/npcs/`はクロスロードの名簿に直結するため)。`CLAUDE.md`の運用ルールは共通。
