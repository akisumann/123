# スキルシステム

> **TL;DR:** 技術・才能を表す「スキル」の仕組みとレベル、習得の考え方。

## スキルとは

スキルとは、生物が習得した技術・技能・経験・才能を表す能力である。

戦闘技術だけでなく、生産・生活・知識・魔法・特殊能力などもスキルとして扱われる。

ステータスが「基礎能力」を表すのに対し、スキルは「身につけた技術」を表す。

## スキルレベル

各スキルには習熟度を表すスキルレベルが存在する。

現在の基準は以下の通りである。

| Lv | 習熟度 |
|---|---|
| Lv1 | 習得したばかり。基礎を理解している。 |
| Lv2 | 初心者。実戦で使い始められる。 |
| Lv3 | 一般的な使い手。 |
| Lv4 | 熟練者。安定して扱える。 |
| Lv5 | その分野の第一線。 |
| Lv6 | 達人級。高い完成度を持つ。 |
| Lv7 | 極めて優秀。限られた実力者。 |
| Lv8 | 超一流。その道の権威。 |
| Lv9 | 人類最高峰クラス。世界でも数少ない。 |
| Lv10 | 伝説級。その技術を極めた存在。 |

**Lv11以上は五龍専用の例外である。** 通常のキャラクターはLv10が上限で、五龍(`world/dragons/`)の固有スキルだけがLv11を持つ。ステータスの規格外ランクSS(`rules/02_status_system.md`)と同じ扱いで、**神話級の存在にのみ使う。**

## スキルの習得

スキルは、

- 学習
- 鍛錬
- 実戦経験
- 研究
- 師弟関係
- 種族特性
- 特殊な契約
- その他特殊な要因

などによって習得できる。

## スキルの成長

スキルは継続して使用・訓練することで成長する。

単純に戦闘を繰り返すだけでなく、その能力を意識的に磨き続けることが重要となる。

また、高レベルになるほど成長速度は遅くなる。

## スキル数

一人の人物が習得できるスキル数に明確な上限は存在しない。

しかし、高い習熟度を維持できるスキルは限られるため、多くの者は得意分野を中心に成長していく。

## レベルとの関係

キャラクター作成時は、スキルレベルの合計値をレベルの約半分を目安として構成する。

| レベル | スキルLv合計目安 |
|---|---|
| Lv20 | 約10 |
| Lv30 | 約15 |
| Lv40 | 約20 |
| Lv50 | 約25 |
| Lv60 | 約30 |
| Lv70 | 約35 |

これは設計上の目安であり、役割や個性によって多少前後してもよい。

## スキルの種類

スキルは用途によって様々な種類が存在する。

- 戦闘スキル
- 魔法スキル
- 生産スキル
- 探索スキル
- 支援スキル
- 生活スキル
- 学術スキル
- 特殊スキル

新しいスキルは、世界設定と矛盾しない限り自由に追加してよい。

## スキル設計方針

スキルはキャラクターの個性や役割を表現する重要な要素である。

同じレベル・同じステータスであっても、習得しているスキルによって得意分野や戦闘スタイルは大きく変化する。

### スキル名について

スキル名は、必ずしも汎用的・説明的な名前である必要はない。

世界共通で使われる一般的な名称でも、キャラクター固有の独特な名称でもよい。

例:

- 剣術
- 弓術
- 火魔法
- 索敵
- 隠密
- 治療
- 鍛冶
- 隠業飛翔
- 氷結舞踏
- 鉱脈喰い
- 雷弓一閃
- 境界渡り

汎用的な名前は分かりやすさに優れ、特殊な名前はキャラクターの個性や種族性を表現しやすい。

ただし、名前だけで効果が分かりにくい場合は、短い説明を添える。

## 運用方針

新たなキャラクター・魔物・種族を作成する際は、本スキルシステムを共通基準として使用する。

レベル・ステータスと合わせて、その存在の総合的な実力を決定する。
