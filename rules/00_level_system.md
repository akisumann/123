# レベルシステム

> **TL;DR:** 全生命の実力指標「レベル(1〜100)」の意味と、レベル帯ごとの強さの目安。Lv1〜9は基本的に子供の帯で、体を使う仕事をしていない大人でも15前後にはなる。レベルキャップは10刻みで才能により決まり、人間の平均は40〜50前後。

## レベルとは

レベルとは、この世界に存在する全ての生命が持つ実力の指標である。

レベルは生物・魔物を問わず共通の基準であり、成長や鍛錬によって上昇する。

レベルの上限は100である。

## レベルの役割

レベルは、その存在が持つ総合的な実力を表す。

ただし、勝敗はレベル以外でも動く。

実際の強さは、

- レベル
- ステータス
- スキル

の3項目を基準として決定される。

さらに、

- 魔法
- 装備
- 経験
- 戦術
- 相性
- 地形
- 種族特性
- 契約・加護
- その他の特殊能力

などが補助要素として戦闘結果に影響する。

## レベル帯の目安

| レベル | 目安 |
|---|---|
| Lv1〜10 | **子供。** 大人はまずここに収まらない(下記「大人の下限」) |
| Lv11〜20 | **一般の大人**・下級冒険者・一般兵士 |
| Lv21〜30 | 一人前の冒険者・熟練兵 |
| Lv31〜40 | ベテラン・地方の実力者 |
| Lv41〜50 | 地方上位・精鋭クラス |
| Lv51〜60 | 国家上位・騎士団長・宮廷魔導士・高ランク冒険者 |
| Lv61〜70 | 英雄級・国家の切り札 |
| Lv71〜80 | 大陸でも名の知れた超一流 |
| Lv81〜90 | 伝説級 |
| Lv91〜99 | 神話級 |
| Lv100 | 理論上の最高到達点 |

### 大人の下限

**Lv1〜9は基本的に子供の帯である。** 体を使う仕事をしていない大人でも、**15前後にはなる。**

日々の労働・移動・生活そのものが経験として積み上がるため、**成人してなお一桁に留まることはまずない。** 事務仕事しかしない者、店番だけの者、机に向かい続ける者も同様である。

## 世界における分布

- Lv1〜30が世界の大多数を占める。ただし**その下端は子供が占めており、大人はおおむねLv15から上に分布する。**
- Lv40以上は優れた実力者として知られ、地域社会でも高い評価を受ける。
- Lv50以上は希少だが、世界規模で見れば相応の数がいる。
- 小国・地方組織であっても、Lv50以上の実力者を最低1人以上抱えていることは珍しくない。
- 大国・巨大組織・宗教組織・魔法学園・騎士団などには、Lv50以上の実力者が複数所属している場合も多い。
- Lv60以上の英雄級は希少であり、国や組織を代表する切り札として扱われる。
- Lv70以上は世界でも限られた超一流の存在となる。

## レベルキャップ

すべての生命には、才能によって決まる個人のレベルキャップ(到達できるレベルの上限)が存在する。

レベルキャップは10段階(Lv10、Lv20、Lv30…Lv100)のいずれかに区切られており、どれだけ修行・実戦を積んでも、自分のキャップを超えてレベルが上がることはない。

キャップの高さは才能そのものであり、後天的な努力量だけでは決まらない。同じ修行量でもキャップがLv30の者とLv90の者がいる。

キャップに到達した者は、そこが実質的な完成形であり、以後は同じレベルのままステータス・スキル面での練度を磨き続けることになる。

### 人間のキャップ分布

人間の場合、レベルキャップがLv10程度しかない者はまずいない。人間の平均的なキャップはLv40〜50前後であり、これで通常の人生において困ることはほとんどない。

キャップに到達するにはそれ相応の修行・実戦経験が必要となるため、大半の人間はキャップへ到達する前に寿命を迎える。そのため「Lv1〜30が世界の大多数を占める」という分布は、キャップの低さによるものというより、単に大半の人間が生涯でそこまでの経験を積まないことに起因する。

自らのレベルキャップという上限を実際に意識し、悩まされるのは、冒険者・戦士・魔法使いなど、よほど濃密で多様な経験を積んだ一部の者だけである。

## レベル差

レベル差は戦闘結果へ大きく影響する。

しかし、レベルだけで勝敗が決定することはない。

ステータス・スキル・魔法・装備・戦術・相性・地形などによって格上へ対抗、あるいは格下へ敗北する可能性も存在する。

## 運用方針

レベルは世界共通の実力指標である。

新たな種族・国家・組織・魔物・キャラクターを追加する際は、本レベルシステムを基準として扱う。
