# ステータス・スキル → 性格/コミュ力 変換フォーマット

戦闘用に作られたステータス・スキルを、そのキャラクターの性格・雰囲気・対人関係での振る舞いを解釈するために読み替えるための補助フォーマット。

戦闘や判定のルールではなく、あくまで非戦闘シーン(会話・日常・関係構築)でキャラクターを演じる際の参考として使う。

## ステータス → 性格ステータス変換フォーマット

戦闘用ステータスをそのまま性格構築用ステータスとして読み替える。ランクは変更せず、同じ評価を別の意味に変換する。

例:

- HP：C → 性格HP：C → 肉体面の余裕・充実度が平均的。
- ATK：F → 性格ATK：F → 我の通しやすさが低く、意思はあっても前に出る形になりにくい。

### 性格ステータス変換表

| ステータス | 性格面での意味 |
|---|---|
| HP | 肉体面の余裕・充実度。身体の元気さ、健康感、生命力がどれだけ振る舞いに出るか。 |
| MP | 精神面の余裕・充実度。心の余裕、集中力、精神的な満たされ方がどれだけ態度に出るか。 |
| ATK | 我の通しやすさ。自分の意思・好意・提案をどれだけ外に出し、場に反映できるか。 |
| DEF | 我の堅牢さ。他人の感情・空気・圧力を受けても、自分の軸を保てる度合い。 |
| INT | 頭の良さ。理解力・分析力・思考力・学習能力。 |
| SPD | テンポ感・切り替えの速さ。反応、決断、会話、行動のテンポ。 |
| DEX | 立ち回りの器用さ。言動・距離感・空気読み・細かい調整のうまさ。 |

### ランク解釈

- **高い場合**：その要素が外から見て強く表れやすい。
- **低い場合**：その要素が弱い、または別の形で表れやすい。ただし、低い=人格的に劣るという意味ではない。

低い評価は「その行動を取らない」ではなく、「やろうとするが上手くいかない」と解釈すると特に活きる。例えばDEXが低いキャラは空気を読もうとしない/読めていないのではなく、読もうと頑張った結果ズレる・空回りする、という方が人間味と可愛げが出る。同様にATKが低いキャラは、自分の意思を通そうとした結果うまく言葉にできず引っ込めてしまう、という「挑戦して失敗する」動きの方が生きたキャラになる。

### 注意

- HPが低い＝根性がない、ではない。
- MPが低い＝心が弱い、ではない。
- ATKが低い＝消極的、ではない。
- DEFが低い＝冷たい、ではない。
- INTが低い＝魅力がない、ではない。
- SPDが低い＝鈍いだけ、ではない。
- DEXが低い＝ダメな人、ではない。

あくまで、元のステータス評価を使ってそのキャラの性格・雰囲気・行動の出方を構築するための変換ルールである。

## スキル → コミュ力スキル変換フォーマット

キャラクターの戦闘・探索・補助スキルを、似た性質を持つコミュニケーション能力へ変換するためのもの。スキル名やLvはそのまま参考にし、そのスキルが対人関係ではどのような形で表れるかを考える。

### 基本ルール

元スキルの効果をそのまま日常化するのではなく、性質・役割・使い方が近いコミュ力スキルへ読み替える。

例:

- ◇ 索敵 → 空気を読む／相手の様子に気づく
- ◇ 防御 → 相手を安心させる／場を落ち着かせる
- ◇ 拘束 → 話題を掴む／相手の意識を引き留める
- ◇ 回復 → 励ます／慰める／気持ちを立て直させる
- ◇ 転移 → 話題転換／気まずい場から逃がす

### 変換テンプレート

```
◇ 元スキル名　Lv〇
→ コミュ力スキル名　Lv〇
内容：対人関係では、〇〇として表れる。
```

### 変換例

- ◇ 鉱脈探知　Lv4 → 本音探知　Lv4：相手が何に価値を感じているか、会話の中から察知しやすい。
- ◇ 蜘蛛糸生成　Lv5 → 会話の糸口作り　Lv5：小さな話題を伸ばし、相手との接点を作るのが得意。
- ◇ トラップハウス構築　Lv7 → 居心地のいい空気作り　Lv7：相手が自然と長居してしまうような場の空気を作れる。
- ◇ 水盾形成　Lv5 → 安心感の壁　Lv5：相手の不安や攻撃的な空気を受け止め、場を落ち着かせる。
- ◇ 鳥状弾射出　Lv6 → 話題の投げかけ　Lv6：複数人に自然に話題を振り、会話を広げられる。

### 注意

コミュ力スキルは、元スキルの強さをそのまま引き継ぐ。ただし、戦闘能力ではなく、あくまで対人・会話・関係構築での表れ方として扱う。

スキルが強いほど万能になるのではなく、そのスキルに対応するコミュニケーションの癖が強く出る。

Lvが低いコミュ力スキルも、「そのアプローチを取らない」ではなく「そのアプローチを取ろうとするが上手くいかない」と解釈すると活きる。

## 運用方針

この変換フォーマットは、NPCの性格・対人関係の振る舞いを演じる際の参考ツールとして使う。戦闘判定(`rules/03_combat_system.md`)には一切影響しない。
