# 新規キャラクター生成フォーマット

> **TL;DR:** 新規キャラを作る共通フォーマット(核を一つに絞る・生活面・数値検算)。

## 目的

街、国家、組織、冒険、日常シーンなどへ登場する新規キャラクターを作成するための共通フォーマット。

キャラクターは能力だけでなく、世界で何をしている人物か、普段どのように暮らしているか、周囲とどのような関係を持つか、物語で何に使えるか、まで含めて作成する。

このフォーマットは今後新しく生成するキャラクターに適用する運用ルールであり、既存キャラクター(NPC)を遡って書き換えるものではない。

## 生成依頼用テンプレート

### 必須指定

- **所属・活動場所**：例：クロスロード西区、冒険者ギルド、職人区の工房
- **立場・職業**：例：門衛、娼婦、鍛冶師、冒険者、情報屋、商人
- **大まかな人物像**：例：無愛想だが面倒見がよい、研究熱心な変人、陽気な人気者

### 任意指定

名前、種族、性別、年齢、レベル、レベルキャップ、役割(戦闘、接客、生産、研究、情報収集、治療など)、外見、性格、能力・得意分野、日常生活、他者との関係、入れたい設定、避けたい設定。

名前の指定がない場合は世界観に合う名前を生成する。

## 生成方針

### 人物の核

最初に、その人物を一文で説明できる中心要素を決める。

例：街中の元客を動かせる犬獣人の娼婦、心まで変身させられる内気な幻術研究者、精霊と共に高級娼館を支える筆頭花魁、門前で旅人へ気さくに道案内する古参衛兵。

中心要素を増やしすぎず、主軸は一つに絞る。

### 生活を持たせる

キャラクターには仕事以外の日常を持たせる。どこで暮らしているか、休日に何をしているか、よく利用する店、友人や家族、趣味、金の使い道、将来の目標、小さな悩み。

すべてを設定する必要はないが、最低一つは日常的な要素を入れる。

### 世界との繋がり

キャラクター単独で完結させず、既存の街や組織と繋げる。

例：特定の酒場の常連、情報屋を連絡先にしている、冒険者ギルドへ仕事を出す、ミレーヌやクラリスと面識がある、職人区の工房から道具を仕入れている、大神殿へ定期的に参拝する。

ただし、重要人物全員と無理に繋げない。

## レベル設定

レベルは物語上の重要度ではなく、本人が積んだ経験と実力から決める(`rules/00_level_system.md`のレベル帯の目安と整合させる)。

| レベル | おおよその立場 |
|---|---|
| Lv1〜10 | 一般人・見習い・駆け出し |
| Lv11〜20 | 経験を積んだ一般人・下級冒険者 |
| Lv21〜30 | 一人前・熟練者 |
| Lv31〜40 | ベテラン・地方の実力者 |
| Lv41〜50 | 地方上位・精鋭 |
| Lv51〜60 | 国家上位 |
| Lv61〜70 | 英雄級 |
| Lv71以上 | 大陸規模の著名人・伝説級 |

非戦闘職でも、研究、生産、芸能、接客、情報、経営などで濃密な経験を積んでいれば高レベルになり得る。高レベルだから戦闘能力が高いとは限らない。

### レベルキャップ

必要に応じて、その人物が将来到達できる上限を設定する(`rules/00_level_system.md`のレベルキャップ制度)。現在レベルがキャップへ到達済みの場合は、「Lv40【上限】」のように表記する。

キャップ到達後もスキルの精度や技術は向上できるが、基礎的なレベルは上昇しない。

## ステータス生成規則

### 評価値

| ランク | 評価値 |
|---|---|
| SS | 規格外 |
| S | 25 |
| A | 16 |
| B | 9 |
| C | 4 |
| D | 1 |
| E | -1 |
| F | -4 |

七項目の評価値合計を、レベルのおおよそ±2以内に収める(`rules/02_status_system.md`)。

SSは五龍などの神話級存在にのみ使用し、通常のキャラクターには使用しない。

### ズレを防ぐ生成手順(暗算で最後にまとめて検算しない)

**「7項目・スキル5個を先に決めて、最後にまとめて検算する」進め方はズレの最大要因になる。マイナス評価値(E=-1、F=-4)が混じる暗算は、どのAIでも間違いやすい。** 代わりに、以下の順で**割り振りながら都度合計を書き出す**。

1. レベルを決める → 目標ステータス合計(レベル±2以内)と目標スキルLv合計(レベル÷2)を先に書き出す。
2. ステータスを1項目ずつ割り振り、割り振るたびに「これまでの合計」を書き足していく(7項目まとめて割り振ってから最後に1回で合計しない)。
3. 7項目終えたら合計と目標との差を確認し、ズレていれば1項目のランクを1段階だけ上下させて微調整する。
4. スキルも同様に1つずつLvを割り振りながら合計を書き足し、5個終えたら目標との差を確認する。
5. **最後に`python3 tools/check_character_stats.py <ファイルパス>`を実行し、機械的に検算する。** 暗算の検算に頼らない。ズレが出たら該当ファイルを開いて数値を修正し、再実行してOKになるまで繰り返す。

### 各項目

HP(体力・生命力・持久力)、MP(魔力量・魔法や特殊能力の維持力)、ATK(攻撃力・腕力・破壊能力)、DEF(耐久・防御・受け流し・装甲)、INT(知識・判断・分析・戦術)、SPD(移動速度・反応・瞬発力)、DEX(精密操作・器用さ・技術制御)。

### 配分方針

ステータスは均等にせず、その人物の特徴を表現する。

例：研究者ならINT・MP・DEXが高く、HP・ATK・SPDが低い。職人ならDEX・INT・HPが高く、MPやSPDは低くてもよい。社交や人脈が強みの人物でも、その背景に応じてINT・DEX・HPなどへ反映する。

弱点を消して万能型にしない。

## スキル生成規則

スキルは原則5個。スキルLv合計は、キャラクターレベルの約半分を目安とする(`rules/01_skill_system.md`)。

| キャラクターLv | スキルLv合計 |
|---|---|
| Lv20 | 約10 |
| Lv30 | 約15 |
| Lv40 | 約20 |
| Lv50 | 約25 |
| Lv60 | 約30 |

スキルは戦闘能力に限らない。接客、商売、芸能、研究、生産、情報収集、料理、人脈、魔法、種族能力、日常技術などもスキルとして扱う。

### スキルLvの目安

| Lv | 習熟度 |
|---|---|
| Lv1 | 習得したばかり |
| Lv2 | 初心者 |
| Lv3 | 一般的な使い手 |
| Lv4 | 熟練者 |
| Lv5 | 第一線 |
| Lv6 | 達人級 |
| Lv7 | 極めて優秀 |
| Lv8 | 超一流 |
| Lv9 | 人類最高峰 |
| Lv10 | 伝説級 |

## AI生成時の注意

- 指定されていない重要設定を勝手に増やしすぎない。
- 全員を特殊な血筋や選ばれた存在にしない。
- 高レベルを理由に万能な戦闘員へしない。
- 民間人には民間人としての能力を持たせる。
- 既存キャラクターの役割を奪わない。
- 既存組織の上位役職を勝手に与えない。
- 名前、種族、性格、能力を可能な限り既存人物と被らせない(`characters/`、`world/`を検索してから生成する。`CLAUDE.md`の「新しいNPC・組織・場所を出す前に」を参照)。
- 特徴は一つを主軸にし、補助的な特徴を一〜二個加える。
- 必ず仕事以外の日常を一つ以上持たせる。
- ステータスとスキルの合計は、暗算の検算に頼らず`python3 tools/check_character_stats.py <ファイルパス>`で機械的に検算する(上記「ズレを防ぐ生成手順」参照)。
- ユーザー指定と矛盾した場合は、ユーザー指定を優先する。
