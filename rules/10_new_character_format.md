# 新規キャラクター生成フォーマット

> **TL;DR:** 新規キャラを作る共通フォーマット(核を一つに絞る・生活面・数値検算)。

## 節の構成(見出しを揃える)

新規キャラクターのファイルは、次の見出しを**この名前で**使う。既存NPCの見出しを調べたところ、核となる節はほぼ揃っている一方、「その人が何者か」を書く節だけがプロフィール/概要/性格/人物像/人物/立ち位置の6種類に割れていた。読む側(AI)が毎回どれを探すか迷うため、これ以上増やさない。

| 見出し | 中身 | 必須 |
|---|---|---|
| `## 外見` | 見た目・服装・立ち振る舞い | ○ |
| `## ステータス` | 7項目のランク表＋合計の検算行 | ○ |
| `## スキル` | ◇形式で5個＋合計の検算行 | ○ |
| `## プロフィール` | **その人が何者か**(立場・来歴・性格) | ○ |
| `## 口調` | 話し方。一番大きな顔を一つ決め、どの条件でどの面が出るかを書く | ○ |
| `## 日常` | 普段の過ごし方。冒頭に`**行きつけ**：`の行を置く | ○ |
| `## よく接する人物` | 関係者への箇条書きリンク(相手側にも書く) | ○ |
| `## 装備` | 特筆すべき装備があれば | — |
| `## 街や組織での立場` | 周囲からどう扱われているか | — |

人物の核が特殊な場合(`## コア特性:〜`など)は追加してよいが、`## プロフィール`は省略しない。

## 目的

街、国家、組織、冒険、日常シーンなどへ登場する新規キャラクターを作成するための共通フォーマット。

キャラクターは能力だけでなく、世界で何をしている人物か、普段どのように暮らしているか、周囲とどのような関係を持つか、物語で何に使えるか、まで含めて作成する。

このフォーマットは今後新しく生成するキャラクターに適用する運用ルールであり、既存キャラクター(NPC)を遡って書き換えるものではない。

## 生成依頼用テンプレート

### 必須指定

- **所属・活動場所**：例：クロスロード西区、冒険者ギルド、職人区の工房
- **立場・職業**：例：門衛、娼婦、鍛冶師、冒険者、情報屋、商人
- **大まかな人物像**：例：無愛想だが面倒見がよい、研究熱心な変人、陽気な人気者

### 任意指定

名前、種族、性別、年齢、レベル、レベルキャップ、役割(戦闘、接客、生産、研究、情報収集、治療など)、外見、性格、能力・得意分野、日常生活、他者との関係、入れたい設定、避けたい設定。

名前の指定がない場合は世界観に合う名前を生成する。

## 生成方針

### 人物の核

最初に、その人物を一文で説明できる中心要素を決める。

例：街中の元客を動かせる犬獣人の娼婦、心まで変身させられる内気な幻術研究者、精霊と共に高級娼館を支える筆頭花魁、門前で旅人へ気さくに道案内する古参衛兵。

中心要素を増やしすぎず、主軸は一つに絞る。

### 日常欄に動作を書く時は、持ち場と揃える

**`## 日常`に書いた動作は、そのまま場面での行動として使われる。** 「意識して歩くようにしている」のような健康習慣のつもりの一文でも、AIはその人物を歩き回らせる。

- **持ち場を離れない人物に「歩く」「出かける」と書かない。** 一人で店を回している職人、詰所勤めの衛兵、住み込みの剣闘士など
- **`tools/routines.tsv`の行動型**(不動/定住/遊動)と食い違わせない
- **飾りの生活習慣を足さない。** 日常欄には、その人物が実際にやることだけを書く

### 生活を持たせる

キャラクターには仕事以外の日常を持たせる。どこで暮らしているか、休日に何をしているか、よく利用する店、友人や家族、趣味、金の使い道、将来の目標、小さな悩み。

すべてを設定する必要はないが、最低一つは日常的な要素を入れる。

### 世界との繋がり

キャラクター単独で完結させず、既存の街や組織と繋げる。

例：特定の酒場の常連、情報屋を連絡先にしている、冒険者ギルドへ仕事を出す、ミレーヌやクラリスと面識がある、職人区の工房から道具を仕入れている、大神殿へ定期的に参拝する。

ただし、重要人物全員と無理に繋げない。

## レベル設定

レベルは物語上の重要度ではなく、本人が積んだ経験と実力から決める(`rules/00_level_system.md`のレベル帯の目安と整合させる)。

| レベル | おおよその立場 |
|---|---|
| Lv1〜10 | 一般人・見習い・駆け出し |
| Lv11〜20 | 経験を積んだ一般人・下級冒険者 |
| Lv21〜30 | 一人前・熟練者 |
| Lv31〜40 | ベテラン・地方の実力者 |
| Lv41〜50 | 地方上位・精鋭 |
| Lv51〜60 | 国家上位 |
| Lv61〜70 | 英雄級 |
| Lv71以上 | 大陸規模の著名人・伝説級 |

非戦闘職でも、研究、生産、芸能、接客、情報、経営などで濃密な経験を積んでいれば高レベルになり得る。高レベルだから戦闘能力が高いとは限らない。

### レベルキャップ

必要に応じて、その人物が将来到達できる上限を設定する(`rules/00_level_system.md`のレベルキャップ制度)。現在レベルがキャップへ到達済みの場合は、「Lv40【上限】」のように表記する。

キャップ到達後もスキルの精度や技術は向上できるが、基礎的なレベルは上昇しない。

## ステータス生成規則

### 評価値

| ランク | 評価値 |
|---|---|
| SS | 規格外 |
| S | 25 |
| A | 16 |
| B | 9 |
| C | 4 |
| D | 1 |
| E | -1 |
| F | -4 |

七項目の評価値合計を、レベルのおおよそ±2以内に収める(`rules/02_status_system.md`)。

SSは五龍などの神話級存在にのみ使用し、通常のキャラクターには使用しない。

### ズレを防ぐ生成手順(数値はAIが決めない)

**AIに「ランクを割り振ってから検算して」と指示しても、実際にはランクを雰囲気で選び、あとから帳尻合わせの説明を付けるだけになりやすい。数値そのものをAIの判断に委ねず、`tools/generate_character_stats.py`に計算させる。**

1. レベルと、そのキャラクターの**得意→不得意の優先順位**(7項目全部を並び替えたもの)だけを決める。数値はまだ考えない。
2. 次を実行する(スキル名も分かっていれば渡す。省略すると仮名で出力される):
   ```
   python3 tools/generate_character_stats.py --level 18 \
     --stats SPD,INT,DEX,HP,DEF,ATK,MP \
     --skills 近道走破,荷物運搬術,顔利き,地理感覚,愛想笑い
   ```
3. 出力された**ランク・スキルLv・合計の数値はそのまま使う(変更しない)**。AIが書き足すのは、各項目の「内容」欄の理由文とスキルの説明文だけ。
4. 出力をキャラクターシートへそのまま貼り付ける。
5. 何らかの事情で数値を手で直した場合は、必ず`python3 tools/check_character_stats.py <ファイルパス>`で再検算し、OKになるまで直す。

既存キャラクターの後からの微調整(1項目だけランクを変える等、`check_character_stats.py`が既存ファイルのズレを検出した場合の修正)のように、生成ツールを使わず手で数値を触る場面では、`check_character_stats.py`による事後検算を必ず行う。

### 各項目

HP(体力・生命力・持久力)、MP(魔力量・魔法や特殊能力の維持力)、ATK(攻撃力・腕力・破壊能力)、DEF(耐久・防御・受け流し・装甲)、INT(知識・判断・分析・戦術)、SPD(移動速度・反応・瞬発力)、DEX(精密操作・器用さ・技術制御)。

### 配分方針

ステータスは均等にせず、その人物の特徴を表現する。

例：研究者ならINT・MP・DEXが高く、HP・ATK・SPDが低い。職人ならDEX・INT・HPが高く、MPやSPDは低くてもよい。社交や人脈が強みの人物でも、その背景に応じてINT・DEX・HPなどへ反映する。

弱点を消して万能型にしない。

### 排他ではなく条件で書く

そのキャラを特別に見せたい時、「街でここだけ」「他にできる者がいない」と書かない。**設備・技術・格といった条件で書く**(例:「張り台が要るので設備の無い店では手が出ない」)。排他で書くと世界の側が閉じるうえ、**中身を書かずに重要さだけ出せてしまう。**

### 強みを書いたら、弱点で釣り合いを取らない

強い所を書いた直後に「**ただし〜には弱い**」「**本当に危ないのは〜**」を付け足さない。**弱点は必要な場所に一度書けば足りる。**

釣り合いを取りにいくのはAIの癖で、書くたびに強みが打ち消され、**その人物の一番大きな顔がぼやける。** 弱点そのものを重く書くのも同じ——数字は既にステータス表にあるので、**文章で念を押す必要がない。**

**強い場面では強く書き切る。** 弱点が実際に効く場面が来たら、その時に書く。

### 既にある言葉を「〜というより」で上書きしない

ファイルが繰り返し使っている平易な言葉(のんびり、真面目、怖がり)を、後から「**〜というより正確には**」と精密そうな言い換えで否定しない。

**言い換えた側だけが読まれて、元の記述が死ぬ。** 実例——銀雪の口調欄が「のんびりというより深刻さの基準がずれている」と書いていた一方、同じファイルの日常・行きつけ・よく接する人物の4箇所は「のんびり」と書いていた。**進行時に口調欄だけを見れば、のんびり屋という一番大きな顔が消える。**

**両方成り立つなら両方書く**(「のんびり屋で、危機感が薄い」)。`tools/check_links.py`が、**否定された語が同じファイルに他2箇所以上ある場合**に警告する。

## スキル生成規則

スキルは原則5個。スキルLv合計は、キャラクターレベルの約半分を目安とする(`rules/01_skill_system.md`)。

| キャラクターLv | スキルLv合計 |
|---|---|
| Lv20 | 約10 |
| Lv30 | 約15 |
| Lv40 | 約20 |
| Lv50 | 約25 |
| Lv60 | 約30 |

スキルは戦闘能力に限らない。接客、商売、芸能、研究、生産、情報収集、料理、人脈、魔法、種族能力、日常技術などもスキルとして扱う。

### スキルLvの目安

| Lv | 習熟度 |
|---|---|
| Lv1 | 習得したばかり |
| Lv2 | 初心者 |
| Lv3 | 一般的な使い手 |
| Lv4 | 熟練者 |
| Lv5 | 第一線 |
| Lv6 | 達人級 |
| Lv7 | 極めて優秀 |
| Lv8 | 超一流 |
| Lv9 | 人類最高峰 |
| Lv10 | 伝説級 |

```
## 外見
体格、髪、目、服装、種族的特徴、全体的な印象を書く。外見指定がない場合も、役割や生活に合う範囲で簡潔に設定する。

| MP | 〇 | 理由 |
| ATK | 〇 | 理由 |
| DEF | 〇 | 理由 |
| INT | 〇 | 理由 |
| SPD | 〇 | 理由 |
| DEX | 〇 | 理由 |

- ◇ スキル名　Lv〇(説明)
- ◇ スキル名　Lv〇(説明)
- ◇ スキル名　Lv〇(説明)
- ◇ スキル名　Lv〇(説明)

スキルLv合計：〇〇(Lv〇〇の半分と一致)

## プロフィール
人物の経歴、性格、現在の仕事、能力を得た理由をまとめる。単なる能力説明ではなく、現在の生活へ至った経緯を入れる。

## 日常
普段の生活、休日の過ごし方、趣味、よく行く場所、周囲の人物との関係から、必要なものを書く。

## 街や組織での立場
その人物が周囲からどう見られているかを書く。正式な役職と、実際の影響力が異なる場合はその違いも記載する。
```

必要がなければ、スキルの細かな説明は付けない。説明を付ける場合も、各スキル一〜三文程度に留める。

## AI生成時の注意

- 指定されていない重要設定を勝手に増やしすぎない。
- 全員を特殊な血筋や選ばれた存在にしない。
- 高レベルを理由に万能な戦闘員へしない。
- 民間人には民間人としての能力を持たせる。
- 既存キャラクターの役割を奪わない。
- 既存組織の上位役職を勝手に与えない。
- 名前、種族、性格、能力を可能な限り既存人物と被らせない(`characters/`、`world/`を検索してから生成する。`CLAUDE.md`の「新しいNPC・組織・場所を出す前に」を参照)。
- 特徴は一つを主軸にし、補助的な特徴を一〜二個加える。
- 必ず仕事以外の日常を一つ以上持たせる。
- ステータス・スキルの数値は`tools/generate_character_stats.py`に計算させ、AIは優先順位(得意→不得意)だけを決める。手で数値を触った場合は`python3 tools/check_character_stats.py <ファイルパス>`で必ず機械的に検算する(上記「ズレを防ぐ生成手順」参照)。
- ユーザー指定と矛盾した場合は、ユーザー指定を優先する。
