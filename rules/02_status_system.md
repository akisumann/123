# ステータスシステム

> **TL;DR:** HP/MP/ATK/DEF/INT/SPD/DEXの7ステータスとランク評価値(S=25〜F=-4)。評価値は段階値(F=−2〜S=5)を符号付きで二乗して導き、7能力の合計を基礎Lv、±2補正で表示Lvとする。

## ステータスとは

ステータスは、生物が持つ基礎能力を数値化・評価したものである。

この世界では、レベルと並ぶ実力の基準として扱われ、戦闘・生産・日常生活など様々な場面へ影響する。

強さは主に

- レベル
- ステータス
- スキル

の三要素によって決定される。

## ステータス項目

### HP(Health Point)

生命力・体力・持久力を表す。

### MP(Mana Point)

保有する魔力量・魔力総量を表す。

### ATK(Attack)

攻撃能力を表す。筋力・破壊力・攻撃性能などを含む。

### DEF(Defense)

防御能力を表す。耐久力・装甲・受け流し・防御性能などを含む。

### INT(Intelligence)

知力・判断力・思考能力を表す。分析・戦術・知識・理解力などを含む。

### SPD(Speed)

速度・機動力を表す。移動速度・反応速度・瞬発力などを含む。

### DEX(Dexterity)

器用さ・精密性を表す。命中精度・手先の器用さ・制御能力・技術力などを含む。

## ステータスランク

各ステータスは以下の7段階で評価される。

| ランク | 評価値 | 目安 |
|---|---|---|
| S | 25 | 最高峰。その分野を代表する才能。 |
| A | 16 | 非常に優秀。第一線で活躍できる。 |
| B | 9 | 優秀。高い能力を持つ。 |
| C | 4 | 得意分野。平均より明確に優れる。 |
| D | 1 | 平均的。特別優れても劣ってもいない。 |
| E | -1 | 苦手。平均をやや下回る。 |
| F | -4 | ほとんど扱えない、あるいは極端に不得意。 |
| SS | 規格外(数値化しない) | Sをさらに超える例外ランク。五龍(`world/02_alvein_continent.md`)のような神話級(Lv90台)の存在にのみ使う、理論上限を持たない領域。通常のキャラクター設計では使用しない。 |

### 評価値の導き方(段階値を符号付きで二乗)

上表の評価値は、丸暗記しなくても次の手順で導ける。まず各ランクに**段階値**を割り当てる。

| ランク | F | E | D | C | B | A | S |
|---|---|---|---|---|---|---|---|
| 段階値 | −2 | −1 | 1 | 2 | 3 | 4 | 5 |

この段階値を、**符号を保ったまま二乗**したものが評価値になる。

```
評価値 = sgn(x) × x²
```

したがって F=−4、E=−1、D=1、C=4、B=9、A=16、S=25。上のランク表と一致する。プラス側は二乗で加速度的に伸び、上位ランクほど1つの差が重くなる。

## レベルとの関係

7能力(HP・MP・ATK・DEF・INT・SPD・DEX)の評価値を合計した値を、そのキャラクターの**基礎レベル**とする。

```
基礎Lv = HP + MP + ATK + DEF + INT + SPD + DEX
```

| Lv | 合計評価値 |
|---|---|
| Lv20 | 約20 |
| Lv35 | 約35 |
| Lv50 | 約50 |
| Lv65 | 約65 |

実際に表示するレベルは、実戦適性・能力同士の噛み合わせ・設定上の強弱を踏まえ、基礎レベルからおおむね±2の範囲で調整してよい(フレーバー補正)。

```
表示Lv = 基礎Lv + フレーバー補正   (フレーバー補正 ≈ −2〜+2)
```

これはあくまでキャラクター設計時の目安であり、完全に一致させる必要はない。概ね±2程度であれば許容範囲とする。

## ステータス設計方針

ステータスは万能型を作るためではなく、そのキャラクターらしさを表現するために存在する。

高い能力があれば、どこかに弱点を持つことも珍しくない。

役割・戦闘スタイル・種族・個性などを考慮しながら配分することを基本とする。

## 運用方針

新たなキャラクター・魔物・種族を作成する際は、本ステータスシステムを共通基準として使用する。

レベル・スキルと合わせて、その存在の実力を決定する。
