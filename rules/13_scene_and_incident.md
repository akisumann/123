# 場面と事件の出し方

> **TL;DR:** 場面と事件の出し方。出していいのは「その場で終わる日常」か「依頼票に書ける事件」だけで、意味ありげな予兆を置かない。各所のGM運用の禁止事項を集約。

## 大原則：中間を作らない

**場に出す物は、次の二つのどちらかである。**

| | 中身 | 例 |
|---|---|---|
| **日常** | その場で始まってその場で終わる。後を引かない | 世間話、荷崩れ、値切り、子供の喧嘩、店先のやり取り |
| **事件** | **出した時点で依頼票に書ける**。何が起きて、誰が困っていて、何をすれば片付くかが言える | 「行方不明者が三人。原因不明。捜索してほしい」 |

**この中間を作らない。** つまり——

> **「これは後で意味を持ちます」という顔をした物を置かない。**

小さな異変、意味ありげな小物、思わせぶりな一言、誰かの含みのある視線、原因の分からない小さな不調。**中身を決めないまま「事件の前日」の空気だけを出すのが、一番やってはいけない形である。**

## 自己点検

**出す前に、自分へ一つ聞く。**

> **「今これは何か」と聞かれて、答えられるか。**

- 答えが**「その場限りの日常」**なら出してよい。ただし**意味ありげに書かない**(下記)
- 答えが**「依頼票に書ける事件」**なら出してよい
- 答えが**「まだ決めていない」「後で決める」**なら、**出してはいけない**

**謎は禁止ではない。** 「原因が分かっていない」ことと「中身を決めていない」ことは別である。前者は事件として成立する(問題・被害・目的が言えている)。後者は成立していない。

## 日常を意味ありげに書かない

**日常の小物は普通に出してよい。** 壊れた樽、閉まっている店、機嫌の悪い店主、見慣れない旅人。**問題は、そこへカメラを寄せることである。**

- ✕ 樽が壊れている。**妙に真新しい割れ方をしている。**
- ◯ 樽が壊れている。店主が舌打ちして片付けている

**含みを持たせた時点で、読み手は事件の始まりだと受け取る。** 日常として出すなら、**日常の重さで書いて、そのまま次へ進む。**

## 集約した既存ルール

以下は各ファイルに書かれているものを一箇所へ集めたもの。原文はリンク先を参照。

| ルール | 出典 |
|---|---|
| **事件・依頼は、出した時点で依頼票に書ける形にする。** 「何か不穏な気配がある」で始めて中身を後から決めない | `CLAUDE.md`、`world/crossroad/75_scenario_seeds.md` |
| **討伐依頼のたびに裏の陰謀や調査要素を挟まない。** 大半は特別な背景を持たない間引き・素材調達で、**依頼票に書いてある通りのことが現地で起きているのが普通** | `world/14_adventurers_guild.md` |
| **異常事態(個体数の急増、縄張りの急拡大、出ないはずの魔物)は稀にだけ。** 討伐のたびに理由を作らない | `world/08_danger_zone_generation.md`、`world/14_adventurers_guild.md` |
| **散策に毎回オチ・報酬・戦闘・新しい陰謀を用意しない。** 世間話・軽い手伝い・噂話で十分。挟む頻度にも余白を残す | `world/crossroad/53_crossroad_wandering_events.md` |
| **伏線は消化すべきToDoではない。** 場面に困った時に引ける引き出しで、使わないまま放置してよい | `world/crossroad/75_scenario_seeds.md` |
| **一つの案件で「話を大きくする」拡張は0〜2回まで。** ただし**初手から大事件として出すのは全面的に有り**(拡張0回)。デカい案件は膨らませず、最初からその規模で出す | `CLAUDE.md` |
| **緊張感は既存の枠(五龍・国家・街の転機・危険地域・ダンジョン)から借りる。** 盛り上げのために裏設定や黒幕をその場で継ぎ足さない | `CLAUDE.md` |

## 誤解しないこと

**これは「話を動かすな」という規則ではない。**

- **大きな事件を起こしてよい。** ただし**最初からその規模で、中身を持った状態で**出す
- **未確認の新しい展開をその場で回してよい。** 一つ一つ許可を取る必要はない(`CLAUDE.md`「GM進行における物語進行の方針」)
- **「日々の暮らしの裏側で、また何かがゆっくり動き始めている」という温度感は使ってよい。** ただし**それを場面の中で予兆として演出しない。** 温度感は背景であって、出し物ではない
