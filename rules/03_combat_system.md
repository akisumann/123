# 判定・戦闘システム

> **TL;DR:** HPではなく「戦況値」で進める戦闘判定ルール(スキルLv d ステータスランク)。

## 基本思想

この世界では、戦闘はHPを削り合うものではなく、「戦況」をどれだけ有利に動かしたかによって進行する。

各キャラクターは毎ターン一つの行動を選択し、その結果が戦況へ反映される。

本システムは個人戦・パーティー戦・軍勢戦の全てで共通して使用できる。

## 基本ルール

1ターンにつき使用できる能力は以下の2つ。

- ステータス 1項目
- スキル 1つ

行動内容に最も適した組み合わせを選択して判定を行う。

例:

- 剣で斬る → ATK + 剣術
- 弓で狙撃する → DEX + 弓術
- 火魔法を放つ → MP + 火魔法
- 治療する → MP + 治療術
- 敵を索敵する → INT + 索敵
- 高速で移動する → SPD + 高速移動

## 判定方法

判定は **スキルLv d ステータスランク** で行う。

### ステータスランクと使用ダイス

| ランク | 使用ダイス |
|---|---|
| S | d7 |
| A | d6 |
| B | d5 |
| C | d4 |
| D | d3 |
| E | d2 |
| F | d1 |

### 判定例

- 剣術Lv4 × ATK:B → 4d5
- 弓術Lv5 × DEX:A → 5d6
- 火魔法Lv6 × MP:S → 6d7
- 索敵Lv3 × INT:C → 3d4
- 治療術Lv5 × MP:A → 5d6

判定で出たダイスの合計値を戦況変化値とする。

一般冒険者・NPCが武器・防具を装備している場合、品質に応じた補正を戦況変化値へ加える。

## 戦況変化値

戦況変化値とは、そのターンに戦況へ与えた影響を表す数値である。

攻撃だけではなく、

- 防御
- 回復
- 支援
- 妨害
- 索敵
- 工作
- 交渉
- 地形利用

など、あらゆる行動が戦況変化値として扱われる。

## 敵戦況値

敵には戦闘開始時に敵戦況値が設定される。

これは敵勢力が1ターンに発揮する圧力・脅威・戦力を表す。

| 敵 | 敵戦況値 |
|---|---|
| 小型魔物の群れ | 30 |
| 通常モンスター集団 | 50 |
| 大型魔物 | 80 |
| 強力なボス | 120 |
| 災害級存在 | 200以上 |

## ターン進行

1. 全員が行動を宣言する。
2. それぞれ判定を行う。
3. 全員の戦況変化値を合計する。
4. 敵戦況値との差分を求める。
5. AIが差分を基に、そのターンの戦況を描写する。

## 戦況差分

敵戦況値との差分は、戦況がどれだけ変化したかを表す。

差分そのものがダメージではない。AIは差分を参考に、その状況に最も自然なストーリーを構築する。

- **差分が小さい**: 戦況はほとんど変化しない。軽い攻防や小さな有利・不利程度として描写する。
- **差分が中程度**: 戦況が明確に変化する。敵を押し返す、味方が負傷する、包囲される、突破口を開くなど、その場に応じた展開となる。
- **差分が大きい**: 戦局が大きく動く。敵主力の崩壊、撤退、制圧、討伐、重要拠点の奪取など、決定的な出来事として描写する。

## AI運用ルール

AIは固定された結果表を使用しない。

敵戦況値との差分のみを基準とし、

- 戦場
- 敵の種類
- 味方の行動
- 地形
- 任務内容

などを考慮し、その場に最も自然な戦況変化をストーリーとして描写する。

差分が小さければ小さな変化、大きければ大きな変化となる。

## 戦闘終了

目的を達成した時点で戦闘は終了する。目的は戦闘によって異なる。

例:

- 敵の撃退
- ボス討伐
- 防衛成功
- 拠点制圧
- 救出成功
- 護衛完了
- 時間経過まで耐える
- 撤退成功

HPを管理するのではなく、戦況を管理することで、個人戦・パーティー戦・軍勢戦を同一ルールで処理することを目的とする。

## AI戦術ボーナス

判定は基本ルールに従って行う。

その後、プレイヤーの発想・戦術・状況利用が優れているとAIが判断した場合、戦況変化値へ追加補正を与えてよい。

### 補正の目安

**優れた戦術・状況利用: +5〜+10程度**

例:

- 相手の虚を突く。
- 弱点やコアへ攻撃を集中させる。
- 地形や天候を利用する。
- 敵の隙を突く。
- 仲間との連携がうまく決まる。
- 相手の行動を読んで先回りする。
- 魔法や能力を工夫して活用する。

**非常に優れた発想: +10〜+20程度**

例:

- 戦況そのものを覆す作戦を成功させる。
- 敵の習性や弱点を利用して大きな優位を築く。
- 一見不利な状況を知略によって逆転する。
- 周囲の環境や道具を巧みに利用する。
- 仲間との高度な連携によって決定的な成果を生み出す。

### AI裁定方針

この補正はキャラクター性能ではなく、プレイヤーの戦術や発想を評価するためのものである。

単純に高い能力を持つだけでは補正は発生しない。

逆に、レベルやステータスで劣っていても、優れた戦術や状況利用によって戦況を大きく動かせる可能性がある。

AIは状況・敵・地形・作戦内容を総合的に判断し、必要に応じて戦況変化値へ柔軟な補正を与えてよい。
