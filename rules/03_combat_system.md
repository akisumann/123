# 判定・戦闘システム

> **TL;DR:** HPではなく「戦況値」で進める戦闘判定ルール(スキルLv d ステータスランク)。

## 基本思想

この世界では、戦闘はHPを削り合うものではなく、「戦況」をどれだけ有利に動かしたかによって進行する。

各キャラクターは毎ターン一つの行動を選択し、その結果が戦況へ反映される。

本システムは個人戦・パーティー戦・軍勢戦の全てで共通して使用できる。

## 基本ルール

1ターンにつき使用できる能力は以下の2つ。

- ステータス 1項目
- スキル 1つ

行動内容に最も適した組み合わせを選択して判定を行う。

例:

- 剣で斬る → ATK + 剣術
- 弓で狙撃する → DEX + 弓術
- 火魔法を放つ → MP + 火魔法
- 治療する → MP + 治療術
- 敵を索敵する → INT + 索敵
- 高速で移動する → SPD + 高速移動

## 判定方法

判定は **スキルLv d ステータスランク** で行う。

### ステータスランクと使用ダイス

| ランク | 使用ダイス |
|---|---|
| S | d7 |
| A | d6 |
| B | d5 |
| C | d4 |
| D | d3 |
| E | d2 |
| F | d1 |

### 判定例

- 剣術Lv4 × ATK:B → 4d5
- 弓術Lv5 × DEX:A → 5d6
- 火魔法Lv6 × MP:S → 6d7
- 索敵Lv3 × INT:C → 3d4
- 治療術Lv5 × MP:A → 5d6

判定で出たダイスの合計値を戦況変化値とする。

一般冒険者・NPCが武器・防具を装備している場合、品質に応じた補正を戦況変化値へ加える。

## 戦況変化値

戦況変化値とは、そのターンに戦況へ与えた影響を表す数値である。

攻撃だけではなく、

- 防御
- 回復
- 支援
- 妨害
- 索敵
- 工作
- 交渉
- 地形利用

など、あらゆる行動が戦況変化値として扱われる。

## 敵戦況値

敵には戦闘開始時に敵戦況値が設定される。

これは敵勢力が1ターンに発揮する圧力・脅威・戦力を表す。

| 敵 | 敵戦況値 |
|---|---|
| 小型魔物の群れ | 30 |
| 通常モンスター集団 | 50 |
| 大型魔物 | 80 |
| 強力なボス | 120 |
| 災害級存在 | 200以上 |

### 敵戦況値は「舞台のLv帯」に合わせて選ぶ

上の表は敵の**見た目の分類**であって、強さの根拠ではない。「大型だから80」と分類だけで決めてはならない。**先に舞台のLv帯を確認し、そこから敵戦況値を決め、それに合う姿の敵を出す**——この順番で選ぶ。

| 舞台のLv帯 | 敵戦況値 | 釣り合う4人パーティーの1ターン合計 | 表のどの行に相当するか |
|---|---|---|---|
| Lv10〜20 | **30** | 1人9前後 × 4人 ≒ 36 | 小型魔物の群れ |
| Lv25〜35 | **50** | 1人12〜16 × 4人 ≒ 48〜64 | 通常モンスター集団 |
| Lv40〜50 | **80** | 1人20〜24 × 4人 ≒ 80〜96 | 大型魔物 |
| Lv55〜70 | **100** | 1人24〜28 × 4人 ≒ 96〜112 | 大型魔物〜ボスの中間 |
| (格上の単体) | **120** | 街最強クラス4人でようやく拮抗する数字 | 強力なボス |
| (五龍・国家級) | **200以上** | 4人では届かない。軍勢戦の領域 | 災害級存在 |

### この判定系は上で飽和する(数字を盛る前に必ず読む)

**Lv50とLv60で、1人あたりの出力はほとんど変わらない。** `characters/npcs/`の全員を実測した結果が下表である。

| Lv帯 | 1人1ターンの期待値(中央値) | 4人合計 |
|---|---|---|
| Lv21〜35 | 12.0 | 約48 |
| Lv36〜50 | 22.5 | 約90 |
| Lv51〜57 | 22.8 | 約91 |

理由は構造的なものである。スキルLv合計はレベルの半分程度を5つ前後に割り振るので(`rules/10_new_character_format.md`)、**最大スキルはLv7あたりで頭打ち**になり、ステータスの目も**S＝d7が上限**。したがって**1人1ターンの実質上限は 7d7 ≒ 28**で、4人でも112前後が天井になる。

このため、**敵戦況値120以上は「レベルを上げれば届く数字」ではない。** 頭数を増やす、装備補正を乗せる、AI戦術ボーナス(+5〜10)を積む、地形を使う——といった**判定の外側**で超える領域である。レベルだけを根拠に120や200を置くと、誰にも勝てない戦闘になる。

参考:街の最高レベルはヴァレリア(Lv57)、次いでザラ(Lv54)。Lv50台が数人いるだけで、Lv60以上の住人はいない。**Lv55〜70帯の舞台は、実際には「街の最上位が背伸びして挑む場所」**であり、余裕を持って通える者はいない。

**同じ敵戦況値を、単体で構成するか集団で構成するかは自由。** Lv25〜35の森に出る「大型の獣一頭」も、Lv40〜50の峡谷に出る「群れ」も、その舞台のLv帯に合った数字を割り当てる。**姿の大小はLv帯を超える根拠にならない。**

### 舞台ごとの対応(クロスロード周辺)

各ファイルの「主な危険度」「推奨レベル」をそのまま基準にする。

| 舞台 | Lv帯 | 敵戦況値 |
|---|---|---|
| さざめき平原(`world/crossroad/60_sazameki_plains.md`) | Lv10〜20 | 30 |
| 赤牙森林(`world/crossroad/61_red_fang_forest.md`) | Lv25〜35 | 50 |
| 苔むし地下遺構(`world/crossroad/65_dungeon_quest_board.md`) | Lv20〜30 | 30〜50 |
| 灰岩峡谷(`world/crossroad/62_grey_rock_canyon.md`) | Lv40〜50 | 80 |
| 灰岩坑道(`world/crossroad/65_dungeon_quest_board.md`) | Lv35〜45 | 50〜80 |
| 骨鳴り墓原(`world/crossroad/63_bone_toll_moor.md`) | Lv55〜65 | 100 |
| 星食いのダンジョン(`world/crossroad/65_dungeon_quest_board.md`) | Lv60〜70以上 | 100(奥の単体ボスのみ120) |
| 街道 | Lv帯を持たない(`world/crossroad/11_crossroad_city.md`) | 危険度低30／中50／高80を目安に、発生した脅威の規模で決める |

`world/08_danger_zone_generation.md`・`world/09_dungeon_generation.md`でその場に新しい舞台を起こした場合も、まずLv帯を決めてから上の対応で敵戦況値を引く。

### Lv帯を超える敵を出す時

**その地域に本来いない異常個体として、明示的に扱う。** 迷い込んだ上位個体、外から持ち込まれたもの、`world/crossroad/75_scenario_seeds.md`の案件が絡んでいるもの、などである。この場合、**遭遇した側が「ここに出るはずのないもの」と認識できるように描写する**こと。中級の採取地で当たり前のように上位の数字が出てくると、Lv帯という区分そのものが意味を失う。

### パーティー側が舞台のLv帯を大きく上回る場合

推奨Lv帯を超えた面子が入った時は、敵戦況値を引き上げてはならない。**そのまま押し切れるのが正しい結果**である(Lv25〜35の森へLv47が入れば、その森の敵は相手にならない)。手応えを出したいなら、敵を強くするのではなく、舞台の側を上のLv帯へ移す。

## ターン進行

1. 全員が行動を宣言する。
2. それぞれ判定を行う。
3. 全員の戦況変化値を合計する。
4. 敵戦況値との差分を求める。
5. AIが差分を基に、そのターンの戦況を描写する。

## 戦況差分

敵戦況値との差分は、戦況がどれだけ変化したかを表す。

差分そのものがダメージではない。AIは差分を参考に、その状況に最も自然なストーリーを構築する。

- **差分が小さい**: 戦況はほとんど変化しない。軽い攻防や小さな有利・不利程度として描写する。
- **差分が中程度**: 戦況が明確に変化する。敵を押し返す、味方が負傷する、包囲される、突破口を開くなど、その場に応じた展開となる。
- **差分が大きい**: 戦局が大きく動く。敵主力の崩壊、撤退、制圧、討伐、重要拠点の奪取など、決定的な出来事として描写する。

## AI運用ルール

AIは固定された結果表を使用しない。

敵戦況値との差分のみを基準とし、

- 戦場
- 敵の種類
- 味方の行動
- 地形
- 任務内容

などを考慮し、その場に最も自然な戦況変化をストーリーとして描写する。

差分が小さければ小さな変化、大きければ大きな変化となる。

## 戦闘終了

目的を達成した時点で戦闘は終了する。目的は戦闘によって異なる。

例:

- 敵の撃退
- ボス討伐
- 防衛成功
- 拠点制圧
- 救出成功
- 護衛完了
- 時間経過まで耐える
- 撤退成功

HPを管理するのではなく、戦況を管理することで、個人戦・パーティー戦・軍勢戦を同一ルールで処理することを目的とする。

## AI戦術ボーナス

判定は基本ルールに従って行う。

その後、プレイヤーの発想・戦術・状況利用が優れているとAIが判断した場合、戦況変化値へ追加補正を与えてよい。

### 補正の目安

**優れた戦術・状況利用: +5〜+10程度**

例:

- 相手の虚を突く。
- 弱点やコアへ攻撃を集中させる。
- 地形や天候を利用する。
- 敵の隙を突く。
- 仲間との連携がうまく決まる。
- 相手の行動を読んで先回りする。
- 魔法や能力を工夫して活用する。

**非常に優れた発想: +10〜+20程度**

例:

- 戦況そのものを覆す作戦を成功させる。
- 敵の習性や弱点を利用して大きな優位を築く。
- 一見不利な状況を知略によって逆転する。
- 周囲の環境や道具を巧みに利用する。
- 仲間との高度な連携によって決定的な成果を生み出す。

### AI裁定方針

この補正はキャラクター性能ではなく、プレイヤーの戦術や発想を評価するためのものである。

単純に高い能力を持つだけでは補正は発生しない。

逆に、レベルやステータスで劣っていても、優れた戦術や状況利用によって戦況を大きく動かせる可能性がある。

AIは状況・敵・地形・作戦内容を総合的に判断し、必要に応じて戦況変化値へ柔軟な補正を与えてよい。

## モブ味方の簡易戦力

名前あり(ステータス・スキルを持つキャラ)以外の、**数値を設定しない臨時の味方**(名もなき護衛・傭兵・衛兵・義勇兵など)は、いちいちステータス表を作らず、**レベルだけ決めて簡易ダイスを1本振る**。

モブにはステータスもスキルも無いため「得意・不得意」という概念がない。名前ありが得意ステータス＋看板スキルで“必殺の一手(最大)”を狙えるのに対し、モブは**そのレベルの平均的な一手**しか出せない。これは「全ステータスが平均ランク・全スキルが平均レベルのキャラが、何をしても同じ出目になる状態」を1本のダイスで表したものである。

- 例:Lv30の平均的なキャラは「ステータス全部C・スキルLv3を5個」(検算:C=4×7=28≒30、Lv3×5=15=30の半分)。このキャラはどの行動も **Lv3スキル × Cステータス ＝ 3d4** になる。これがLv30モブの1手。
- 名前ありの“必殺”はこれより上(例:Lv30の本職が主ステータスB×スキルLv5なら5d5=平均15)。モブはあくまで平均なので、その半分程度に収まる。

### レベル別モブダイス

| モブのレベル | 判定ダイス | 平均 |
|---|---|---|
| Lv20 | 3d3 | 6 |
| Lv30 | 3d4 | 7.5 |
| Lv40 | 4d4 | 10 |
| Lv45 | 4d5 | 12 |
| Lv50 | 5d5 | 15 |

中間・帯外のレベルは近い行を使う。役割(攻撃・防御・支援)を問わず、このダイス1本をそのターンの戦況変化値とする。

### 用途は戦闘に限らない

このモブダイスは戦闘の戦況変化値だけでなく、**そのレベル相応の力量が問われるあらゆる行為の判定に、そのまま使える**。

- 回復・治療(手当て、看護、薬の投与)
- 商売・交渉(店番、値付け、掛け合い、客あしらい)
- 運搬・作業・雑務(荷運び、設営、修理、片付け)
- 採取・生産・探索(素材集め、加工の手伝い、聞き込み、下調べ)
- その他、名もなき人手が担う諸々の仕事

いずれも、行為の内容に関わらず**そのレベルのモブダイス1本を振り、出目をその成果(戦況変化値に相当する“働きの大きさ”)とする**。得意・不得意が無いのは戦闘と同じで、モブはどんな仕事でも平均的な一手として処理する。

### 運用

- **初動の扱い**:接近・展開に取られる初動1ターンは、攻撃としての戦況変化値がほぼ乗らない(位置取り・防御などの小さな値に留まる)。数ターン戦うと、1体あたりの実効平均は素の値の7〜8割程度に下がる。奇襲・待ち伏せで初手から攻撃が通る状況なら、この割引はない。
- **まとめ振り**:同一レベルのモブが複数いる場合、ダイスをまとめて振ってよい(例:Lv30モブ3体＝3d4×3＝9d4)。分布は同じで手間だけ減る。
- **装備補正・AI戦術ボーナス**:名前ありと同様、装備品質やうまい連携・戦術には通常どおり補正を加えてよい。
- **人数ルール**:モブは`CLAUDE.md`「名前ありの味方5人以上を長時間まとめない」の人数には数えない。
