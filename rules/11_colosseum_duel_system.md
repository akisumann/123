# コロッセオ用・3ターン公開模擬決闘ルール

> **TL;DR:** コロッセオ公開試合用の、3ターンで決着する簡易決闘ルール。

## 概要

二人のキャラクターが、各自のステータスとスキルを使って三回勝負を行う簡易決闘方式。`world/crossroad/27_crossroad_colosseum.md`の公開試合で使用する。

数値だけで勝敗を決めるのではなく、各ターンの組み合わせに応じて戦闘描写を作る。

- 試合時間：全3ターン
- 形式：1対1
- 殺傷禁止の公開模擬決闘
- 外部からの戦術指示は原則なし
- 降参、戦闘不能、場外、拘束成立、審判停止で決着可能
- 基本的には第3ターン終了時の戦況値で勝敗を決める

## 判定に使うもの

各ターン、双方が以下を一つずつ選択する。

- ステータス：1項目
- スキル：1個

選んだステータスはダイスの種類、スキルLvは振るダイスの個数になる。

### ステータス別ダイス

| ランク | 使用ダイス |
|---|---|
| S | d7 |
| A | d6 |
| B | d5 |
| C | d4 |
| D | d3 |
| E | d2 |
| F | d1 |

SSは規格外のため、通常の公開模擬決闘では個別調整する。

### 判定例

ATK：Sのキャラクターが、Lv6のスキルを使う場合、6d7を振る。

SPD：Aのキャラクターが、Lv7のスキルを使う場合、7d6を振る。

## ステータスの使い分け

ステータスは行動内容に合うものを選ぶ。

| ステータス | 主な使用例 |
|---|---|
| HP | 消耗戦、耐久、無理を通す、立ち上がる |
| MP | 魔力出力、魔法維持、特殊能力の連続使用 |
| ATK | 打撃、斬撃、破壊、直接的な攻撃力 |
| DEF | 防御、固定、保持、姿勢を崩さない |
| INT | 読み合い、戦術、罠、能力解析 |
| SPD | 突進、回避、追撃、位置取り |
| DEX | 命中、精密攻撃、武器操作、細かな制御 |

同じ行動でも、描写によって使用ステータスが変わる。例えば、腕力による攻撃手段を持つキャラクターの場合：

- 力任せに殴る：ATK
- 相手を逃がさず固定する：DEF
- 正確に急所へ差し込む：DEX
- 一気に間合いを詰める：SPD

## 再使用制限

一度使ったステータスとスキルは、その試合中には再使用できない。同じスキルを別のステータスと組み合わせることも不可。

**禁止例**：第1ターンにATK+スキルAを使った場合、第2・第3ターンでは両方とも使用不可。

**許可例**：第1ターン：ATK+スキルA／第2ターン：SPD+スキルB／第3ターン：DEF+スキルC。

これにより、単純に最強技を三回繰り返すのではなく、キャラクターの複数の能力を使う試合になる。

## ターン進行

### 第1ターン：得意分野の正面衝突

両者の代表的な能力や、試合の主題になる技をぶつける。例：拳対突進、火力対防御、射撃対高速移動、怪力対受け流し。

### 第2ターン：対応・逆転

第1ターンで不利になった側が立て直したり、有利側が追撃したりする。例：追撃対装甲再生、範囲攻撃対回避、拘束対脱出、防御崩し対迎撃。

### 第3ターン：最終決着

残ったステータスとスキルを使い、勝敗へ直結する行動を行う。例：捕縛成立、場外攻撃、武器破壊、最後の一撃、戦闘不能、審判停止。

## 戦況値

各ターン、双方のダイス合計を比較する。高い側が、差分だけ戦況値を獲得する。

**例**：Aが25、Bが20なら、Aが5点獲得。次のターンでAが13、Bが20なら、Bが7点獲得。累計はA:5、B:7となる。

戦況値はHPそのものではなく、試合全体における優勢度を示す。

### 差分の目安

| 点差 | 戦闘描写 |
|---|---|
| 0 | 完全互角。同時に弾かれる、膠着する |
| 1〜2 | ごく僅かな優勢。軽い傷、位置有利 |
| 3〜5 | 明確な優勢。吹き飛ばす、装甲を破る |
| 6〜9 | 大きな優勢。場外寸前、武器損傷、拘束準備 |
| 10以上 | 決定的優勢。戦闘不能や即時決着もあり得る |

ただし、キャラクターのHP・DEF・能力特性を考慮して描写を調整する。高HP・高DEFの相手なら、大差をつけられても即座に倒れない場合がある。

## 観客の反応・会場の描写

ダイスの合計や戦況値だけを機械的に並べず、各ターンの結果には観客席や会場の様子を自然に添える(`world/crossroad/27_crossroad_colosseum.md`の「興行としての試合」「観客側の認識」を参照)。コロッセオの試合は戦闘であると同時に舞台でもあり、観客の反応込みで一つの決着として描写する。

### 差分に応じた反応の目安

| 点差 | 観客の反応の例 |
|---|---|
| 0 | 真っ向からの激突が拮抗し、会場が沸く。「互角だ、目が離せない!」息を呑む白熱した攻防 |
| 1〜2 | 軽いどよめき、拍手混じりのざわめき |
| 3〜5 | 歓声、指笛、「よっしゃ!」「今の見たか!」 |
| 6〜9 | 大歓声、地鳴りのような足踏み、実況役の絶叫 |
| 10以上 | 総立ち、しばしの静寂の後の爆発的な歓声 |

### 描写に混ぜてよい要素

- 実況・煽り役の掛け声(専属実況者ヴィヴィアナ・ラウドベル。`characters/npcs/24_viviana_loudbell.md`)
- 常連客・行商人・冒険者など観客層ごとの反応の違い
- カジノ(`world/crossroad/28_crossroad_casino.md`)で試合に賭けている客の一喜一憂
- 応援札や物販(`world/crossroad/27_crossroad_colosseum.md`の「出店と物販」)を手にした観客の様子
- 贔屓の選手が押されている時の悲鳴やため息、盛り返した時の歓声

これらはあくまで雰囲気描写であり、勝敗そのものはダイスの結果(戦況値)に従う。観客の反応が試合結果に影響することはない。

## 最終的な勝敗

第3ターン終了後、累計戦況値の高い側が勝利。

### 同点の場合

累計値が同点なら、以下の順に判定する。

1. 第3ターンで優勢だった側
2. 最終的に有利な状態だった側
3. 拘束、場外寸前、武器破壊など決着に近い側
4. それでも決まらなければ引き分け

## 早期決着

三ターン制が基本だが、以下の場合は途中で試合を終了できる。

- 明確な戦闘不能
- 降参
- 完全な場外
- 脱出不能な拘束
- 武器や戦闘手段の完全喪失
- 観客席や選手に重大な危険が発生
- 審判による強制停止

ただし、興行として三ターン戦わせたい場合は、致命的な大差でない限り第3ターンまで続行する。

## 簡易版

全3ターン。各ターン、「未使用のステータス1項目」+「未使用のスキル1個」を選択する。スキルLv＝ダイス個数。ステータスランク＝ダイスの面数(S=d7／A=d6／B=d5／C=d4／D=d3／E=d2／F=d1)。双方の合計値を比較し、高い側が差分だけ戦況値を獲得。3ターン終了時に戦況値が高い側の勝利。同点なら第3ターンの優勢、最終状態、拘束や場外状況で決着。同じステータス・スキルは一試合中に再使用不可。
